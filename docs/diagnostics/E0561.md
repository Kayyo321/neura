# E0561: incompatible default in an override or implementation

A caller inserts the default of the method its call names. An override or implementation may omit a literal `nil` default and inherit it. It must repeat every other default with the same value. Adding or changing a default gives E0561. Calls through either static type pass the shared default.

<!-- example: error: E0561 -->
```neura
let Shape = class (
    export let area = func(scale: int = 1) -> int => scale;
);

let Square = class : Shape (
    export let.override area = func(scale: int = 2) -> int => scale * 4;
);
```

Copy the base default:

<!-- example: check -->
```neura
let Shape = class (
    export let area = func(scale: int = 1) -> int => scale;
);

let Square = class : Shape (
    export let.override area = func(scale: int = 1) -> int => scale * 4;
);
```

See [Polymorphism](../lang/Polymorphism.md).
