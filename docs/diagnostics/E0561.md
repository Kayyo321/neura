# E0561: defaults differ from the overridden method

A caller inserts the default of the method its call names. An override, or a class method that implements an interface method, therefore gives the same parameters a default, with the same value, as the method it replaces. A call then means the same whatever the static type of its receiver.

<!-- example: error: E0561 -->
```neura
let Shape = class (
    export let area = func(scale: int = 1) -> int => scale;
);

let Square = class : Shape (
    export let.override area = func(scale: int = 2) -> int => scale * 4;
);
```

Copy the base default:

<!-- example: check -->
```neura
let Shape = class (
    export let area = func(scale: int = 1) -> int => scale;
);

let Square = class : Shape (
    export let.override area = func(scale: int = 1) -> int => scale * 4;
);
```

See [Polymorphism](../lang/Polymorphism.md).
