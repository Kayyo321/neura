# E1407: proof match does not cover every case

A match in a proof must cover each constructor that remains possible in the branch. The diagnostic lists the omitted cases.

<!-- example: error: E1407 -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: {
            match (flag) {
                true => {==},
            }
        };
);
```

Prove the equality for both Boolean cases.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: {
            match (flag) {
                true => {==},
                false => {==},
            }
        };
);
```
