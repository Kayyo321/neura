# E1027: capability used but not declared

A target's image may use the host services of the capability groups its `capabilities` list names, and those every target has (console, clock, entropy, process exit). `neura build --target` reads the host imports of the built image and reports `E1027` at the target's `entry` for each service whose group is not listed, or that the target's kind cannot have: a web target that reaches `neura.fs.*`, for example. A web target cannot import a service outside the web groups, or carry native code or callbacks. Add the group to `capabilities`, or remove the use.
