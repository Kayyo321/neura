# E0431: statement outside its context

`return` appears inside a function, `break` and `continue` inside a loop, and a local binding inside a block.

<!-- example: error: E0431 -->
```neura
let first = func(values: int[]) -> int {
    if (values.length == 0) {
        break;
    }
    return values[0];
};
```

Leave a function with `return`:

<!-- example: check -->
```neura
let first = func(values: int[]) -> int {
    if (values.length == 0) {
        return 0;
    }
    return values[0];
};
```
