# E0708: C import failed

A C import needs libclang, a header that parses, and only static libraries or object files to link.

<!-- diagnostic: not reproducible: it depends on libclang and on a C header -->

Install libclang (or name it with --libclang), fix the header's errors, and link a static library:

<!-- example: fragment: needs mathops.h and libmathops.a -->
```neura
let mathops = import:c("mathops.h", "libmathops.a");
```

See [Foreign interop](../lang/ForeignInterop.md).
