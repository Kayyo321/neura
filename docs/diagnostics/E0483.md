# E0483: argument supplied twice

Every parameter receives one value. A label names a parameter that a positional argument or an earlier label has already filled.

<!-- example: error: E0483 -->
```neura
let schedule = func(job: string, retries: int) -> string => job;
let first = schedule("backup", job: "restore");
```

Give each parameter one argument:

<!-- example: check -->
```neura
let schedule = func(job: string, retries: int) -> string => job;
let first = schedule("backup", retries: 2);
```
