# E0484: labels are not available for this call

Labels are resolved at compile time against the parameter names of the declaration a call names. Some calls have no such names, and take their arguments by position only:

- a call through a function value, whose type carries neither names nor defaults;
- a call of an intrinsic member such as `append`, `slice` or `equals`;
- an enum constructor, whose named payload is written `Variant { name: value }` instead;
- a call of a function with a variadic parameter, where labels must not decide which arguments are the variadic tail;
- a call that would pass a primitive reference (`&T`) argument out of parameter order.

<!-- example: error: E0484 -->
```neura
let twice = func(value: int) -> int => value * 2;
let apply = func(operation: func(int) -> int) -> int => operation(value: 4);
```

Pass the arguments in parameter order:

<!-- example: check -->
```neura
let twice = func(value: int) -> int => value * 2;
let apply = func(operation: func(int) -> int) -> int => operation(4);
```
