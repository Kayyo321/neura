# E0215: malformed class hook clause

A class hook clause is written after the `(` of a declared class and before its first member: a `|`, the word `get` or `set`, an optional `.override`, a `:`, an expression or a block, and a `;`. It takes no tags and no `export`. `neura check --fix` adds a missing `;` and removes an `export`.

<!-- example: error: E0215 -->
```neura
let Session = class (
    | got: instance;

    export let user: string = "";
);
```

Write `get` or `set`:

<!-- example: check -->
```neura
let Session = class (
    | get: instance;

    export let user: string = "";
);
```

See [class hooks](../design/Hooks030.md#class-hook-clauses).
