# E0214: parameter without a type

A parameter takes the type that follows its group of names, as in `func(a, b: int)`, where both `a` and `b` are `int`. A name at the end of the list, with no type after it, has no group to take a type from. Contextual typing of untyped lambda parameters is not defined yet, so an untyped parameter is always an error.

<!-- example: error: E0214 -->
```neura
let add = func(a: int, b, c) -> int {
    return a;
};
```

Write the type after the last name of the group:

<!-- example: check -->
```neura
let add = func(a: int, b, c: int) -> int {
    return a + b + c;
};
```

See [Core language](../lang/CoreLanguage.md#grouped-parameters).
