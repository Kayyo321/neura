# E0214: parameter without a type

A parameter takes the type that follows its group of names, as in `func(a, b: int)`, where both `a` and `b` are `int`. A name at the end of the list, with no type after it, has no group to take a type from.

Only a lambda may leave every parameter untyped, `func(a, b) => a + b`, and only where a function type is expected: as the argument of a parameter of function type, as the result of a function whose result is a function type, or as the value of a place with a function type ([Core language](../lang/CoreLanguage.md#function-values-and-closures)). A list that mixes typed and untyped parameters, an untyped list in a named declaration such as `let f = func(a) => a;`, and an untyped lambda without an expected function type are this error.

<!-- example: error: E0214 -->
```neura
let add = func(a: int, b, c) -> int {
    return a;
};
```

Write the type after the last name of the group:

<!-- example: check -->
```neura
let add = func(a: int, b, c: int) -> int {
    return a + b + c;
};
```

A lambda passed where a function type is expected may leave all of its parameters untyped:

<!-- example: check -->
```neura
let apply = func(f: func(int, int) -> int) -> int => f(3, 4);
let seven = apply(func(a, b) => a + b);
```

See [Core language](../lang/CoreLanguage.md#grouped-parameters).
