# E0495: invalid operands of ??

`left ?? right` gives `right` when `left` is a nil reference or `None`, so `left` is a class or interface reference or an `Optional<T>`. The expression has the type of the reference, or `T`, and `right` must be assignable to it: it is typed with that type as its expected type and is not converted. `??` is looser than `||`, so `ready || done ?? x` tests `ready || done`. The error is at the left operand, or at the fallback.

<!-- example: error: E0495 -->
```neura
let pick = func(count: int32) -> int32 => count ?? 0;
```

`??` applies to a value that may be absent:

<!-- example: check -->
```neura
let.promote _ = import:Std.Core.Optional;
let pick = func(amount: Optional<int64>) -> int64 => amount ?? 0;
```
