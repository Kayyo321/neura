# E0899: internal compiler error

An internal compiler error: a stage found an inconsistency that valid input cannot cause, such as a standard library without a module the compiler needs, or a NeuraIR invariant that does not hold.

<!-- diagnostic: not reproducible: only a compiler defect or a modified standard library causes it -->

Check that the standard library matches the compiler (`neura doctor`). If it does, report the error with the program that causes it:

<!-- example: check -->
```neura
let console = import:Std.Io.Console;
```
