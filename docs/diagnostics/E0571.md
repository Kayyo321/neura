# E0571: record field of a type a record cannot hold

A record's fields hold values whose equality, hash and text the record's generated members can compute and that never change: `bool`, the integer and floating-point types, `string`, fieldless enums, other records (the record being declared included), and tuples of those. A collection is mutable, a function has no value equality, and a class that is not a record, an interface, `class`, a primitive reference or `any` can refer to state that changes. A record may also hold a payload enum when every payload type is an eligible record field.

<!-- example: error: E0571 -->
```neura
let Tags = record (names: string[list]);
```

Hold a record, a tuple or an enum of eligible types, or declare the type as an `#Immutable` class and not as a record:

<!-- example: check -->
```neura
let Name = record (text: string);
let Tags = record (first: Name, second: Name);
```

See [Types](../lang/Types.md#records).
