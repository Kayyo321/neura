# E0508: member needs a receiver

An instance member is used through an instance: a static function or a static scope has no implicit receiver.

<!-- example: error: E0508 -->
```neura
let Counter = class (
    export let count: int = 0;
);
let read = Counter.count;
```

Read the member of an instance:

<!-- example: check -->
```neura
let Counter = class (
    export let count: int = 0;
);
let read = new Counter().count;
```
