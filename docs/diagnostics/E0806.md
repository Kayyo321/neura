# E0806: external function without a runtime binding

A function without a body in the image must have a runtime binding: a host service, a scheduler operation, or a native symbol, with one signature per host service.

<!-- diagnostic: not reproducible: checked source binds every external function; it needs hand-written NeuraIR -->

Build from source, so that each external function keeps the binding the standard library declares:

<!-- example: check -->
```neura
let console = import:Std.Io.Console;
```

See [Neuron conversion](../Backend.md).
