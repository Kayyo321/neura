# E0901: tag on a declaration it does not apply to

Each tag applies to some kinds of declaration only: `#Final` to classes and methods, `#Inline` to functions and methods, and so on. `neura tags <Name>` prints what a tag applies to.

<!-- example: error: E0901 -->
```neura
#Final
let limit: int32 = 10;
```

Put the tag on a declaration it applies to, or use what the binding needs; a constant is `const`:

<!-- example: check -->
```neura
#Final
let Point = class (
    export let x: int32 = 0;
);

const limit: int32 = 10;
```

See [Tags](../lang/Tags.md).
