# E0604: tasks combined with foreign code

A program that spawns tasks, or uses a scope, a channel, or another scheduler operation, cannot also use native code (`Std.DynamicForeign` or `import:c(...)`) yet: tasks and native calls cannot share an image.

<!-- example: error: E0604 -->
```neura
let foreign = import:Std.DynamicForeign.Linker;
let work = func(item: int) -> int => item * 2;
let run = func() {
    scope {
        spawn work(1);
    }
};
```

Split the program: keep the native calls in one program and the tasks in another, or call the work directly:

<!-- example: check -->
```neura
let foreign = import:Std.DynamicForeign.Linker;
let work = func(item: int) -> int => item * 2;
let run = func() {
    work(1);
};
```

See [Concurrency](../lang/Concurrency.md).
