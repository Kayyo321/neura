# E0520: duplicate accessor

A field has at most one `| get:` clause and at most one `| set:` clause, in either order.

<!-- example: error: E0520 -->
```neura
let Counter = class (
    export let count: int = 0;
        | get: count;
        | get: count + 1;
);
```

Keep one getter:

<!-- example: check -->
```neura
let Counter = class (
    export let count: int = 0;
        | get: count;
);
```

See [Types](../lang/Types.md#accessors).
