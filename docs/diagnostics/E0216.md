# E0216: class hook outside a declared class

Only a declared class, including a singleton or a generic class, can have class hook clauses. An interface, a module, an enum, and an anonymous class written in a type position cannot: a hook is a rule about the references of one named class.

<!-- example: error: E0216 -->
```neura
let Shape = interface (
    | get: instance;

    let area = func() -> int32;
);
```

Declare the hooks on a named class:

<!-- example: check -->
```neura
let Shape = interface (
    let area = func() -> int32;
);

let Square = class implements Shape (
    | get: instance;

    export let side: int32 = 1;
    export let area = func() -> int32 => side * side;
);
```

See [class hooks](../design/Hooks030.md#class-hook-clauses).
