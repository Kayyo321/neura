# E0256: malformed CSS module construct

CSS module selectors are already local. Use `:global(...)` with a parenthesized selector to preserve a global name.

<!-- example: error: E0256 -->
```neura
const Local = css.module { :global .dark { } };
```

<!-- example: fragment: stylesheet lowering is implemented after CSS parsing -->
```neura
const Local = css.module { :global(.dark) { } };
```
