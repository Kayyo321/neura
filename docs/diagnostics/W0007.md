# W0007: maybe-nil value for a non-nil contract

The `nil-argument` warning identifies passing or assigning a value that may be nil where the declaration promises a non-nil reference. A parameter without a nil default promises a non-nil argument. A field or module binding with a written non-nil initializer also carries that contract.

<!-- example: warning: W0007 -->
```neura
let Connection = class (
    export last ready: bool = true;
);

let is_ready = func(connection: Connection) -> bool {
    return connection.ready;
};

let inspect_connection = func() -> bool {
    return is_ready(nil);
};
```

Pass a live value, or check the argument before passing it. If the callee handles absence itself, give the parameter a default of `nil` and guard any dereference inside its body.

<!-- example: check -->
```neura
let Connection = class (
    export last ready: bool = true;
);

let is_ready = func(connection: Connection = nil) -> bool {
    return connection?.ready ?? false;
};

let inspect_connection = func() -> bool {
    return is_ready(nil);
};
```

Use `-Wno-nil-argument` to disable this warning. See [nil conditions](../lang/CoreLanguage.md#nil-conditions).
