# E0436: destructuring count mismatch

A destructuring declaration with a list of values after `=` has one value for each name, and its tuple annotation, when it has one, has one type for each name.

<!-- example: error: E0436 -->
```neura
let [width, height] = 640, 480, 3;
```

Give each name one value, or bind the extra value to a name of its own:

<!-- example: check -->
```neura
let [width, height, depth] = 640, 480, 3;
let [low, high]: [int, int] = 1, 9;
```

A single value after `=` is a tuple that is destructured instead; its arity mismatch is [E0426](E0426.md). See [Types](../lang/Types.md#tuples).
