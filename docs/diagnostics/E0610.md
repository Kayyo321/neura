# E0610: #NotThreadSafe class that promises sharing

The instances of a class marked `#NotThreadSafe`, or of a class that extends one, stay in the task that holds them: no task may give one to another. Such a class cannot also promise that tasks may share its instances, so it cannot be `#ThreadSafe` or `#Immutable` and cannot be a monitor, which has `#Synchronized` methods. On one declaration, `#NotThreadSafe` with `#ThreadSafe`, `#Immutable`, or `#Synchronized` is `E0907`; this error is for the promise made elsewhere: a `#Synchronized` method of the class, of a base, or of a subclass, or a subclass marked `#ThreadSafe` or `#Immutable`. The error is at the promise, with a label at the `#NotThreadSafe` tag.

<!-- example: error: E0610 -->
```neura
#NotThreadSafe
let Buffer = class (
    let size: int64 = 0;

    #Synchronized
    export let grow = func() -> int64 {
        size = size + 1;
        return size;
    };
);
```

Keep the instances in one task and drop the guard, or remove `#NotThreadSafe` to make the class a monitor:

<!-- example: check -->
```neura
#NotThreadSafe
let Buffer = class (
    let size: int64 = 0;

    export let grow = func() -> int64 {
        size = size + 1;
        return size;
    };
);
```

A task may still create and use an instance of its own. See [Tags](../lang/Tags.md#threadsafe-and-notthreadsafe) and [Concurrency](../lang/Concurrency.md#51-transferable-types).
