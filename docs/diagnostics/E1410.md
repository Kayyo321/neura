# E1410: law uses an impure or forbidden operation

A law may call only proof-admissible pure code. Reads of mutable globals, host or native calls, scheduler operations, and object identity are outside that subset.

<!-- example: error: E1410 -->
```neura
let Example = module (
    let flag = true;

    let reads_flag = func() -> bool => flag;

    let Stable = law (
        claim: { reads_flag() == true : bool };
    );
        | proof: {==};
);
```

Use a pure function with an immutable input or constant.

<!-- example: check -->
```neura
let Example = module (
    const flag = true;

    .Pure
    let reads_flag = func() -> bool => flag;

    let Stable = law (
        claim: { reads_flag() == true : bool };
    );
        | proof: {==};
);
```
