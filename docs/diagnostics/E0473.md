# E0473: using in a function that cannot return a close error

A `using` block closes its resource when the block is left, and `close` returns `Result<Unit>`. A failed close is returned from the function: combined with the value of a `return`, and on any other exit as the function's result. So `using` is written in a function or lambda whose result type is `Result<T>`. A generator returns its values through `yield`, so its body holds no `using` of its own; a lambda inside it may. The error labels the function's result type.

<!-- example: error: E0473 -->
```neura
let closeable = import:Std.Io.Closeable;
let.promote _ = import:Std.Core.Result;
let.promote _ = import:Std.Core.Unit;
let Resource = class implements closeable.Closeable (
    export let close = func -> Result<Unit> => Result<Unit>.Ok(Unit.Value);
);
let work = func() -> void {
    using (source = new Resource()) {
    }
};
```

Return a `Result`, or put the block in a lambda that returns one:

<!-- example: check -->
```neura
let closeable = import:Std.Io.Closeable;
let.promote _ = import:Std.Core.Result;
let.promote _ = import:Std.Core.Unit;
let Resource = class implements closeable.Closeable (
    export let close = func -> Result<Unit> => Result<Unit>.Ok(Unit.Value);
);
let work = func() -> Result<Unit> {
    using (source = new Resource()) {
    }
    return Result<Unit>.Ok(Unit.Value);
};
```
