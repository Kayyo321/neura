# E0518: accessor on a member that is not a field

Only an instance field can have accessor clauses. A function, a nested class, module, enum, or interface, a cast, and a type alias such as `let Kind = int;` cannot.

<!-- example: error: E0518 -->
```neura
let Shape = class (
    export let area = func -> int => 4;
        | get: 4;
);
```

Remove the clause; a function computes its value already:

<!-- example: check -->
```neura
let Shape = class (
    export let area = func -> int => 4;
);
```

See [Types](../lang/Types.md#accessors).
