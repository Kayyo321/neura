# E0485: default value is not a constant

A default is a literal constant of its parameter's type: a Boolean, integer, float or string literal, a numeric literal with unary `-`, `nil` for a class or interface type, or an enum variant without payload written with its enum (`Light.Red`). It contains no call, no `new`, no name of a binding and no other parameter. The compiler inserts it in each caller, so it must mean the same value everywhere and need no initialization.

<!-- example: error: E0485 -->
```neura
let limit = func -> int => 3;
let retry = func(times: int = limit()) -> int => times;
```

Use a literal, or an overload that computes the value:

<!-- example: check -->
```neura
let limit = func -> int => 3;
let retry = func(times: int) -> int => times
    or func -> int => retry(limit());
let again = retry();
```
