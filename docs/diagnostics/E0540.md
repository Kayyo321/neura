# E0540: `.override` on a class hook that overrides nothing

`.override` says that a clause replaces one the class inherits. When no base class has a clause of that kind, there is nothing to replace. `neura check --fix` removes `.override`.

<!-- example: error: E0540 -->
```neura
let Session = class (
    | get.override: instance;
);
```

Remove `.override`:

<!-- example: check -->
```neura
let Session = class (
    | get: instance;
);
```

See [class hooks](../design/Hooks030.md#class-hook-clauses).
