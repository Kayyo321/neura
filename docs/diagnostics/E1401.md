# E1401: reflexivity proof does not match its goal

A `{==}` proof closes an equality only when both sides reduce to the same value under the current hypotheses and pattern refinements. Compare the normalized sides and the first divergence in the diagnostic.

<!-- example: error: E1401 -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == false : bool };
    );
        | proof: {==};
);
```

State the equality that follows from the definitions.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```
