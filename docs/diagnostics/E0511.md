# E0511: invalid singleton

A singleton is declared at file or module level or as a static class member, has only abstract-free members and at most a zero-argument `init`, and is never destroyed.

<!-- example: error: E0511 -->
```neura
let Settings = singleton ();
destroy Settings;
```

A singleton lives for the whole run; reset its state through a method if it needs one:

<!-- example: check -->
```neura
let Settings = singleton (
    export let verbose: bool = false;
    export let reset = func() {
        verbose = false;
    };
);
Settings.reset();
```

See [Object lifecycle](../lang/ObjectLifecycle.md).
