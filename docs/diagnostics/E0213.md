# E0213: malformed binding clause

A `host(...)`, `callback(...)`, or `scheduler(...)` clause names a service or operation as a string and gives a version that is a positive `uint32`; the standard library uses these clauses to bind host services.

<!-- example: error: E0213 -->
```neura
let Clock = module (
    let now = func() -> int64 host("clock.now", 0);
);
```

Versions start at 1. Programs do not declare host bindings ([E0710](E0710.md)); the clause appears only in the standard library:

<!-- example: fragment: host bindings compile only in standard library modules (E0710) -->
```neura
let Clock = module (
    let now = func() -> int64 host("clock.now", 1);
);
```

See [Standard library design](../lang/Stdlib.md).
