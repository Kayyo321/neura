# E0427: invalid enum variant use

An enum variant is used qualified by its enum, and a variant with a payload is constructed with its payload.

<!-- example: error: E0427 -->
```neura
let Shape = enum (Circle(int), Square(int));
let unit = Shape.Circle;
```

Pass the payload:

<!-- example: check -->
```neura
let Shape = enum (Circle(int), Square(int));
let unit = Shape.Circle(1);
```

See [Types](../lang/Types.md).
