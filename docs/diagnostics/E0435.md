# E0435: parenthesized type after new

After `new`, an opening parenthesis always begins the constructor arguments of a target-typed `new`, so a class cannot be written in parentheses there.

<!-- example: error: E0435 -->
```neura
let Point = class (
    export let x: int = 0;
);
let origin = new (Point)();
```

Write the class without parentheses, or leave it out where the type is expected:

<!-- example: check -->
```neura
let Point = class (
    export let x: int = 0;
);
let origin = new Point();
let other: Point = new();
```

See [Object lifecycle](../lang/ObjectLifecycle.md#target-typed-new).
