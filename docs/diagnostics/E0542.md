# E0542: class hook that does not yield its class

Both clauses yield a reference of their class: the body is an expression of the class's type, or a block that returns one on every path or traps. A getter that only reads is written `| get: instance;`, and a setter that only admits is `| set: value;`.

<!-- example: error: E0542 -->
```neura
let Session = class (
    | get: {
        if (instance != nil) {
            return instance;
        }
    };
);
```

Return a reference on every path:

<!-- example: check -->
```neura
let Session = class (
    | get: {
        if (instance != nil) {
            return instance;
        }
        return nil;
    };
);
```
