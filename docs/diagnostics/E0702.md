# E0702: import of an internal standard library module

A standard library module under an `Internal` namespace is private to the library.

<!-- example: error: E0702 -->
```neura
let formatting = import:Std.Io.Internal.Formatting;
```

Import the public module that provides the operation:

<!-- example: check -->
```neura
let strings = import:Std.Text.Strings;
```

See [Standard library design](../lang/Stdlib.md).
