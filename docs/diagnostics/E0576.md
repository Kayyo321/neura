# E0576: invalid static requirement or call of one

A static function without a body in an interface is a static requirement: a plain signature that each implementing class declares as an exported static function. It is not generic, not variadic, not an overload group, has no parameter default and no host, kernel or scheduler binding. A requirement is called only through a type parameter whose bound requires it, `T.zero()`, or through the name of a class that implements it, `Money.zero()`: there is no dispatch on a run-time value, so it is not called through the interface's name or an interface-typed value, and it is not taken as a function value.

<!-- example: error: E0576 -->
```neura
let Additive = interface<T> (
    static let zero = func() -> T;
);
let start = func(value: Additive<int>) -> int => value.zero();
```

Call it through a type parameter bounded by the interface:

<!-- example: check -->
```neura
let Additive = interface<T> (
    static let zero = func() -> T;
);
let start = func<T: Additive<T>>() -> T => T.zero();
```
