# E0532: unexported field in a fields-only anonymous class

Only the methods of a class can use its unexported fields, so every field of an anonymous class without methods is exported.

<!-- example: error: E0532 -->
```neura
let point: class (let x: int = 0;) = new;
```

Export the field:

<!-- example: check -->
```neura
let point: class (export let x: int = 0;) = new;
let x = point.x;
```

A body with a method, accessors, or a `const` or `last` field is a class of its own, and like a declared class it can have unexported fields.

See [Anonymous classes](../lang/Types.md#anonymous-classes).
