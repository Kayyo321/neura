# E0453: an escaping closure requires explicit construction

A capturing callable that leaves its block must have an explicitly constructed environment.

<!-- example: error: E0453 -->
```neura
let offset_by = func(offset: int) -> func(int) -> int {
    return func(value: int) -> int => value + offset;
};
```

Construct the escaping closure with `new func`, or use `new bound(receiver.method)` for an escaping bound method.

<!-- example: check -->
```neura
let offset_by = func(offset: int) -> func(int) -> int {
    return new func(value: int) -> int => value + offset;
};
```
