# E1417: class invariant field is writable without its guard

A field governed by a class invariant must be encapsulated. Class invariants are planned for a later release.

<!-- diagnostic: not reproducible: class invariants are a Phase 3 feature -->

Keep an invariant-governed field private, expose a getter, or prove that every write through its setter preserves the invariant. This example keeps the field private.

<!-- example: check -->
```neura
let Switch = class (
    let enabled: bool = false;

    export let is_enabled = func() -> bool => enabled;
);
```

See [the laws design](../design/Laws031.md).
