# E1414: law dependencies form a cycle

A cycle in lemma dependencies cannot establish a proof. Structural induction has its own decrease check and cannot justify an arbitrary cycle.

<!-- example: error: E1414 -->
```neura
let Example = module (
    let First = law (
        claim: { true == true : bool };
    );
        | proof: Second();

    let Second = law (
        claim: { true == true : bool };
    );
        | proof: First();
);
```

Prove one of the equalities independently to break the cycle.

<!-- example: check -->
```neura
let Example = module (
    let First = law (
        claim: { true == true : bool };
    );
        | proof: {==};

    let Second = law (
        claim: { true == true : bool };
    );
        | proof: First();
);
```
