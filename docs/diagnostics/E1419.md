# E1419: independent proof checker disagrees with the compiler

This code is reserved for a discrepancy between the compiler and the independent checker. That checker is planned for a later release.

<!-- diagnostic: not reproducible: the independent proof checker is a Phase 3 feature -->

Use `neura prove` to run the proof checker in this release.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```

See [the laws design](../design/Laws031.md).
