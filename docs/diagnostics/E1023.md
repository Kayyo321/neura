# E1023: invalid target

A target needs a kind of `web`, `server` or `desktop` and a source package declared in the manifest. A desktop target also names a web target in its `ui` key.

<!-- diagnostic: not reproducible: the manifest model runs in its dedicated tests until project commands are wired -->
<!-- example: fragment: the ui package and the other target settings are declared elsewhere in neura.toml -->
```toml
[targets.web]
kind = "web"
package = "ui"
```
