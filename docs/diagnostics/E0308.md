# E0308: not a namespace

In a qualified name `a.b`, `a` must be a module, a class, an interface, an enum, or an import that names one.

<!-- example: error: E0308 -->
```neura
let limit = 10;
let value: limit.Item = 0;
```

Qualify a name only with a namespace:

<!-- example: check -->
```neura
let Store = module (
    export let Item = enum (Book, Pen);
);
let value: Store.Item = Store.Item.Book;
```

See [Modules and imports](../lang/Modules.md).
