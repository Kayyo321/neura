# E0319: invalid or repeated wire name

Give each mapped field or variant one nonempty string literal. Names must be unique among the fields of each record, among the variants of an enum, and within each named variant payload. Include members that keep their declared names when checking for a collision.

<!-- example: error: E0319 -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<User> { field User.name: "id"; };
```

<!-- example: check -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<User> { field User.name: "display_name"; };
```
