# E0310: misuse of the discard name '_'

`_` discards a value: a `let _ = value;` binding needs an initializer, declares nothing, and cannot be read or used as a member name.

<!-- example: error: E0310 -->
```neura
let _: int;
```

Give the discard a value to evaluate, or bind the value to a name:

<!-- example: check -->
```neura
let compute = func() -> int => 3;
let _ = compute();
```

See [Core language](../lang/CoreLanguage.md).
