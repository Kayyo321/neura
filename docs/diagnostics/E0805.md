# E0805: invalid entry point signature

The entry point is `main(string[]) -> ExitCode` as `Std.Program.Entry` declares it.

<!-- diagnostic: not reproducible: the override rules (E0502) reject another signature first; a damaged standard library is needed -->

Override `main` with the declared signature:

<!-- example: run -->
```neura
let console = import:Std.Io.Console;
let program = import:Std.Program;

export let Main = module : program.Entry (
    export let.override main = func(arguments: string[]) -> program.ExitCode {
        console.print_line("ready");
        return program.ExitCode.Ok;
    };
);
```

```text
ready
```

See [Standard library](../lang/StandardLibrary.md).
