# E0218: misplaced startup block

A startup block runs once per execution, so it is written only where its place in the program's startup order is fixed: among the top-level statements of a file or among the members of a module. It cannot be written in a function, a class, an interface, an enum, or a nested block.

<!-- example: error: E0218 -->
```neura
let prepare = func() -> void {
    static scope {
        let ready = true;
    }
};
```

Move the block to the top level of the file, or call the function from a block written there:

<!-- example: check -->
```neura
let prepare = func() -> void {
    let ready = true;
};

static scope {
    prepare();
}
```
