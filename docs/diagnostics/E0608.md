# E0608: #ThreadSafe function that is not task-safe

A function or method marked `#ThreadSafe` must be task-safe by the rule a spawned call follows: nothing it can call may use a reassignable module binding, a binding whose type is not transferable, a native request, or a function marked `#NotThreadSafe`. The error is at the tag, with the same call chain a spawn of the function would report. On a `#ThreadSafe` class, every exported method follows the rule.

<!-- example: error: E0608 -->
```neura
let limit: int32 = 10;

let current_limit = func() -> int32 {
    return limit;
};

#ThreadSafe
let clamp = func(value: int32) -> int32 {
    let most = current_limit();
    return value > most ? most : value;
};
```

Pass the state in, or read a `const` binding:

<!-- example: check -->
```neura
const limit: int32 = 10;

#ThreadSafe
let clamp = func(value: int32) -> int32 {
    return value > limit ? limit : value;
};
```
