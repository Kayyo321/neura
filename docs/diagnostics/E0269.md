# E0269: Unicode escape that is not a scalar value

A Unicode escape names a Unicode scalar value, U+0000 to U+D7FF or U+E000 to U+10FFFF, which a string encodes as UTF-8. A surrogate code point, `\u{D800}` to `\u{DFFF}`, and a value above `\u{10FFFF}` are rejected. The error is at the escape.

<!-- example: error: E0269 -->
```neura
let high = "\u{D83D}";
```

Write the code point itself, not a UTF-16 surrogate:

<!-- example: check -->
```neura
let smile = "\u{1F600}";
```

See [Core language](../lang/CoreLanguage.md#escapes).
