# E0449: a value type larger than its inline limit

A tuple is stored inline: its elements are a fixed run of one-word values in a frame slot, a parameter, a result, a field, a global or an element of an array or list, and a nested tuple or payload enum is flattened into the run. A payload enum is stored the same way: a `uint32` tag, then its payload words, which its variants share by type, so the enum has as many words of each type as the variant that needs the most of them. The run has at most 64 words. A tuple or enum type with more is `E0449`, and the error names the shape and its size, as in `[int32 x 65]` for a tuple of 65 `int32` elements, or the enum's name. A class, fieldless enum, string, array, list or function value is one word, whatever it refers to, so only the tuples and enums that hold it count it once.

The error is reported where the type is used, after generic code has been specialized, so each instance of a generic type is checked on its own.

An enum counts its tag and, for each type, the most words of that type one variant needs. Here `Narrow` needs 40 `int32` words and `Long` 30 `int64` words, so the enum has 71:

<!-- example: error: E0449 -->
```neura
let Wide = enum (
    Narrow([int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int,
            int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int, int]),
    Long([int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64,
          int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64, int64]),
    Nothing
);
```

Group the elements in a class, which is a reference, or split the tuple so that each part stays within the limit; for an enum, hold the payload of its largest variant in a class:
