# E0449: a value type larger than its inline limit

A tuple is stored inline: its elements are a fixed run of one-word values in a frame slot, a parameter, a result, a field, a global or an element of an array or list, and a nested tuple is flattened into the run. The run has at most 64 words. A tuple type with more is `E0449`, and the error names the shape and its size, as in `[int32 x 65]` for a tuple of 65 `int32` elements. A class, enum, string, array, list or function value is one word, whatever it refers to, so only the tuples that hold it count it once.

The error is reported where the type is used, after generic code has been specialized, so each instance of a generic type is checked on its own.
