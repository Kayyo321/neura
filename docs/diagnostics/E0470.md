# E0470: return in a startup block

A startup block is not a function: it returns nothing and runs to its end unless it traps. `return` in the block is an error. A `return` inside a lambda written in the block returns from the lambda and is accepted.

<!-- example: error: E0470 -->
```neura
let configured: bool = true;

static scope {
    if (configured) {
        return;
    }
    configured = true;
}
```

Write the condition around the work, or put the work in a function and call it from the block:

<!-- example: check -->
```neura
let configured: bool = true;

let configure = func() -> void {
    if (configured) {
        return;
    }
    configured = true;
};

static scope {
    configure();
}
```
