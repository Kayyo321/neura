# E0522: setter on a field named value

In a setter, `value` names the incoming value. A field that is itself named `value` would be hidden inside its setter, so it cannot have one.

<!-- example: error: E0522 -->
```neura
let Cell = class (
    export let value: int = 0;
        | set: value = value;
);
```

Rename the field:

<!-- example: check -->
```neura
let Cell = class (
    export let content: int = 0;
        | set: content = value;
        | get: content;
);
```

See [Types](../lang/Types.md#accessors).
