# E1409: law or proof term has the wrong type

Each side of an equality must have the annotated type. A proof term must establish the proposition required at its use.

<!-- example: error: E1409 -->
```neura
let Example = module (
    let State = enum ( Ready );
    let Bad = law (
        claim: { State.Ready == true : bool };
    );
        | proof: {==};
);
```

Give both sides the type in the annotation.

<!-- example: check -->
```neura
let Example = module (
    let State = enum ( Ready );
    let Bad = law (
        claim: { State.Ready == State.Ready : State };
    );
        | proof: {==};
);
```
