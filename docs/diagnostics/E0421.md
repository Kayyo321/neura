# E0421: not a type of the required kind

Where a type is required, the name must be a type, and of the kind the position needs: a class or interface for a bound, an interface after `implements`, a class for a base.

<!-- example: error: E0421 -->
```neura
let limit = 3;
let other: limit = 4;
```

Use a type:

<!-- example: check -->
```neura
let limit = 3;
let other: int32 = 4;
```

See [Types](../lang/Types.md).
