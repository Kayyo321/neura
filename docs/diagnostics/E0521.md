# E0521: setter on a constant field

A `const` field cannot change after construction, and a `last` field is assigned exactly once, so neither can have a `| set:` clause. A getter is allowed.

<!-- example: error: E0521 -->
```neura
let Config = class (
    export const name = "default";
        | get: name;
        | set: name = value;
);
```

Declare the field with `let`, or drop the setter:

<!-- example: check -->
```neura
let Config = class (
    export const name = "default";
        | get: name;
);
```

See [Types](../lang/Types.md#accessors).
