# E0220: malformed using statement

`using` at the start of a statement is the keyword of a scoped resource when it is followed by `(`, a name and `=`, or when its balanced `(...)` is directly followed by `{`. The form is `using (name = value) { ... }`: it binds one resource, with no type annotation, and its block takes no `;` after the `}`. A second resource after a comma, a value without a name, a missing block and a `;` after the block are rejected at the first wrong token.

<!-- example: error: E0220 -->
```neura
let closeable = import:Std.Io.Closeable;
let.promote _ = import:Std.Core.Result;
let.promote _ = import:Std.Core.Unit;
let Resource = class implements closeable.Closeable (
    export let close = func -> Result<Unit> => Result<Unit>.Ok(Unit.Value);
);
let both = func() -> Result<int> {
    using (a = new Resource(), b = new Resource()) {
    }
    return Result<int>.Ok(0);
};
```

Nest a second `using` for a second resource. The inner one is closed first:

<!-- example: check -->
```neura
let closeable = import:Std.Io.Closeable;
let.promote _ = import:Std.Core.Result;
let.promote _ = import:Std.Core.Unit;
let Resource = class implements closeable.Closeable (
    export let close = func -> Result<Unit> => Result<Unit>.Ok(Unit.Value);
);
let both = func() -> Result<int> {
    using (a = new Resource()) {
        using (b = new Resource()) {
        }
    }
    return Result<int>.Ok(0);
};
```

Everywhere else `using` is an ordinary name, so `using(config);` calls a function named `using`. See [Core language](../lang/CoreLanguage.md#using).
