# E0231: pattern form that is not supported

A `match` pattern holds `_`, a name, a variant pattern or a tuple pattern in each payload or element position. A literal, a range, a rest element such as `...rest`, and a type pattern `name: Type` are not patterns of 0.3.0. A type pattern is the whole pattern of a `match.is` arm. The error covers the form that is not supported.

<!-- example: error: E0231 -->
```neura
let Shape = enum (Dot, Line(int));
let length = func(shape: Shape) -> int => match (shape) {
    Shape.Line(1) => 1,
    _ => 0,
};
```

Bind the value and test it in a guard:

<!-- example: check -->
```neura
let Shape = enum (Dot, Line(int));
let length = func(shape: Shape) -> int => match (shape) {
    Shape.Line(n) if n == 1 => 1,
    _ => 0,
};
```
