# E0428: invalid primitive reference

A primitive reference (`&int`) refers to mutable storage of a Boolean, numeric, or string type; it is bound to a binding, field, or element, not to a value.

<!-- example: error: E0428 -->
```neura
let temporary: &int = 10;
```

Bind the reference to a mutable binding:

<!-- example: check -->
```neura
let storage: int = 10;
let alias: &int = storage;
```

See [Types](../lang/Types.md).
