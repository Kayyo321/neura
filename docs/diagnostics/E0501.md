# E0501: invalid static member

`static` declares a member of a class or an interface itself; a static member cannot use the instance (its fields and methods) or the class's type parameters, and is named through the type.

<!-- example: error: E0501 -->
```neura
let Record = class<T> (
    export static let read = func(value: T) -> T => value;
);
```

Make the function an instance method, or give it a type parameter of its own:

<!-- example: check -->
```neura
let Record = class<T> (
    export let read = func(value: T) -> T => value;
    export static let echo = func<U>(value: U) -> U => value;
);
```
