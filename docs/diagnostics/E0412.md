# E0412: invalid match arm

Each arm of a `match` names a different variant of the matched enum and binds every field of its payload, and a `_` arm comes last.

<!-- example: error: E0412 -->
```neura
let Light = enum (Red, Green);
let wait = func(light: Light) -> int {
    return match (light) {
        _ => 0,
        Light.Red => 30,
    };
};
```

Put the wildcard arm last:

<!-- example: check -->
```neura
let Light = enum (Red, Green);
let wait = func(light: Light) -> int {
    return match (light) {
        Light.Red => 30,
        _ => 0,
    };
};
```
