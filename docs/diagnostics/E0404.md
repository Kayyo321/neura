# E0404: local binding without an initializer

A local binding is initialized where it is declared.

<!-- example: error: E0404 -->
```neura
let count = func() -> int {
    let total: int;
    return 0;
};
```

Give it an initial value:

<!-- example: check -->
```neura
let count = func() -> int {
    let total: int = 0;
    return total;
};
```
