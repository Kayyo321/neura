# E0404: local binding without an initializer

A `let` or `const` local binding is initialized where it is declared. Only a `last` binding can be assigned later.

<!-- example: error: E0404 -->
```neura
let count = func() -> int {
    let total: int;
    return 0;
};
```

Give it an initial value:

<!-- example: check -->
```neura
let count = func() -> int {
    let total: int = 0;
    return total;
};
```

If the value is known only later, declare the binding `last` with a type, and assign it exactly once on every path before reading it:

<!-- example: check -->
```neura
let count = func(flag: bool) -> int {
    last total: int;
    if (flag) {
        total = 1;
    } else {
        total = 0;
    }
    return total;
};
```
