# E0448: a value type that contains itself

A tuple contains each of its elements, and an enum contains each payload of each of its variants. A value of a type that contains itself, directly or through other tuples and enums, would have no finite size. A class, list, array, string or function value is a reference, or keeps its storage separately, so a type that recurses only through one of them is finite.

<!-- diagnostic: not reproducible: the compiler does not report it yet. Tuples and payload enums are stored on the heap today, where a recursive enum runs correctly; the error is reported once they are stored inline (docs/design/Representation030.md) -->

The error names the enum, and its note gives the path from the enum back to itself, such as `Tree -> Tree.Branch.0: Tree`. Payloads are numbered from zero in declaration order.

Hold the link in a class, which is a reference:

<!-- example: check -->
```neura
let TreeLink = class(
    export last tree: Tree;

    export let init = func(value: Tree) {
        tree = value;
    };
);

let Tree = enum(Empty, Leaf(int), Branch { left: TreeLink, right: TreeLink });
```
