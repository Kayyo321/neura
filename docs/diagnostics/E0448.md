# E0448: a value type that contains itself

A tuple and a payload enum are stored inline: a value is a fixed run of words, its elements' or its payloads' words, wherever it lives. A tuple contains each of its elements, and an enum contains each payload of each of its variants. A value of a type that contains itself, directly or through other tuples and enums, would have no finite size. A class, list, array, string or function value is a reference, or keeps its storage separately, so a type that recurses only through one of them is finite.

The error is reported at the variant whose payload closes the cycle, after generic code has been specialized, so `Optional<Tree>` and a generic enum instantiated with itself are checked per instance. Its note gives the path from the enum back to itself, such as `Tree -> Tree.Branch.0: Tree`. Payloads are numbered from zero in declaration order, and a tuple element adds its position.

<!-- example: error: E0448 -->
```neura
let Tree = enum (Empty, Leaf(int), Branch { left: Tree, right: Tree });
```

Hold the link in a class, which is a reference:

<!-- example: check -->
```neura
let TreeLink = class(
    export last tree: Tree;

    export let init = func(value: Tree) {
        tree = value;
    };
);

let Tree = enum(Empty, Leaf(int), Branch { left: TreeLink, right: TreeLink });
```

A list of the enum is a reference too, so `Branch(Tree[list])` is finite.
