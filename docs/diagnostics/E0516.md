# E0516: accessor on a field that is not exported

Accessors control access from outside the class, so only an `export` field can have them. Inside its class an unexported field is always read and written directly.

<!-- example: error: E0516 -->
```neura
let Account = class (
    let balance: int64 = 0;
        | get: balance;
);
```

Export the field, or remove the accessors:

<!-- example: check -->
```neura
let Account = class (
    export let balance: int64 = 0;
        | get: balance;
);
```

See [Types](../lang/Types.md#accessors).
