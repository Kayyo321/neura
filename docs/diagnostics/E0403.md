# E0403: mismatched types

A value must have the type its context expects: a binding's annotation, a parameter, a function's result type, or the binding it is assigned to. Neura converts between types only with `as`.

<!-- example: error: E0403 -->
```neura
let count: int32 = true;
```

Give a value of the expected type, or convert one explicitly:

<!-- example: check -->
```neura
let count: int32 = 1;
let wide: int64 = count as int64;
```

See [Types](../lang/Types.md).
