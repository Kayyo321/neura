# E0606: invalid select

A `select` is a statement in a function body with at least one arm that waits, each a call of `send`, `receive`, `join`, or `wait`, and at most one `_` arm.

<!-- example: error: E0606 -->
```neura
let poll = func() {
    select {
        _ => {
        },
    }
};
```

Give the select an operation to wait for:

<!-- example: check -->
```neura
let channels = import:Std.Concurrent.Channel;
let poll = func(inbox: channels.Receiver<int>) {
    select {
        let message = inbox.receive() => {
        },
        _ => {
        },
    }
};
```

See [Concurrency](../lang/Concurrency.md).
