# E0422: expected a value

A value position needs a value; a module, a type, or a call of a function without a result is not one.

<!-- example: error: E0422 -->
```neura
let log = func(text: string) {};
let result = log("ready");
```

Call a function without a result as a statement of its own:

<!-- example: check -->
```neura
let log = func(text: string) {};
log("ready");
```

See [Modules and imports](../lang/Modules.md).
