# E1302: a class with two reflection policies

A class chooses what reflection keeps of it by implementing one marker interface of `Std.Reflect.Core.ReflectPolicy`: `Strip` keeps only its identity and layout, `Layout` adds its fields and constructors, and a class with neither keeps everything. A class that implements both markers, directly or through its bases, is rejected when the program reflects.

<!-- example: error: E1302 -->
```neura
let policies = import:Std.Reflect.Core.ReflectPolicy;
let types = import:Std.Reflect.Type.TypeDescriptor;

let Secret = class implements policies.Strip, policies.Layout ( );

let describe = func -> string => types.of<Secret>().name;
```

Keep one marker:

<!-- example: check -->
```neura
let policies = import:Std.Reflect.Core.ReflectPolicy;
let types = import:Std.Reflect.Type.TypeDescriptor;

let Secret = class implements policies.Strip ( );

let describe = func -> string => types.of<Secret>().name;
```

See [the reflection design](../design/Reflect030.md#the-descriptor-model).
