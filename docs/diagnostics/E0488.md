# E0488: invalid extension function

An extension function extends the type of its first parameter. That parameter cannot be variadic, and its type cannot be `void`, a function type, or a bare type parameter without a bound, which would make the function a member of every type.

<!-- example: error: E0488 -->
```neura
let.extension show = func<T>(value: T) -> T => value;
```

Extend one type, or a family of types through a generic one:

<!-- example: check -->
```neura
let.extension count = func<T>(items: T[list]) -> int => items.length;
let.extension twice = func(value: int) -> int => value * 2;
```
