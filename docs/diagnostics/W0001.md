# W0001: use of a deprecated declaration

A use of a `#Deprecated` declaration warns, with the version and reason the tag gives, and suggests the replacement that `use_instead` names. When that replacement resolves at the use, `neura check --fix` applies it. Uses inside the deprecated declaration itself and inside other deprecated code do not warn, and neither does a use under `#Allow(deprecated)`; `#Deny(deprecated)` makes the warning an error, and `-Wno-deprecated` hides it. Overriding a deprecated method warns too.

<!-- example: warning: W0001 -->
```neura
let Shapes = module (
    #Deprecated(as_of: "0.2.0", use_instead: area, reason: "it rounds the result")
    export let rough_area = func(width: int32) -> int32 {
        return width * width;
    };

    export let area = func(width: int32) -> int32 {
        return width * width;
    };
);

let total: int32 = Shapes.rough_area(3);
```

Use the replacement:

<!-- example: check -->
```neura
let Shapes = module (
    #Deprecated(as_of: "0.2.0", use_instead: area, reason: "it rounds the result")
    export let rough_area = func(width: int32) -> int32 {
        return width * width;
    };

    export let area = func(width: int32) -> int32 {
        return width * width;
    };
);

let total: int32 = Shapes.area(3);
```
