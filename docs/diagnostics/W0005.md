# W0005: setter that never stores its field

A setter (`| set: ...;`) runs for every write to its field from outside the class. A setter whose body never assigns the field makes such a write have no effect on it, which is rarely intended. The warning's name is `setter-never-stores`: `-Wno-setter-never-stores`, `#Allow(setter_never_stores)`, or `#Allow(W0005)` silences it, and `#Deny(W0005)` makes it an error.

<!-- example: warning: W0005 -->
```neura
let Gauge = class (
    export let level: int = 0;
        | get: level;
        | set: {
            let ignored = value;
        };
);
```

Assign the field in the setter, usually after checking the value:

<!-- example: check -->
```neura
let Gauge = class (
    export let level: int = 0;
        | get: level;
        | set: {
            if (value >= 0) {
                level = value;
            }
        };
);
```

To make the field read-only outside its class instead, remove the setter and keep only `| get: level;`. A setter that deliberately ignores writes can say so with `#Allow(setter_never_stores)` on the field.
