# E1404: concrete module leaves an inherited law unproven

A concrete module must supply a proof of every abstract law it inherits. The diagnostic identifies the inherited statement and suggests a `let.proof` stub.

<!-- example: error: E1404 -->
```neura
let Base = module (
    .Pure
    export let value = func() -> bool;

    export let AlwaysTrue = law (
        claim: { value() == true : bool };
    );
);

let Derived = module:Base (
    .Pure
    export let.override value = func() -> bool => true;
);
```

Supply a proof in the deriving module.

<!-- example: check -->
```neura
let Base = module (
    .Pure
    export let value = func() -> bool;

    export let AlwaysTrue = law (
        claim: { value() == true : bool };
    );
);

let Derived = module:Base (
    .Pure
    export let.override value = func() -> bool => true;

    let.proof AlwaysTrue: {==};
);
```
