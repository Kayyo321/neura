# E0447: a deferred 'last' binding that is not a local or an instance field

Only a local or an instance field can be declared `last` without a value. A module, file, or static `last` binding takes its value where it is declared, like a `const`.

<!-- example: error: E0447 -->
```neura
let Counter = class(
    static last limit: int;
);
```

Give it its value:

<!-- example: check -->
```neura
let Counter = class(
    static last limit: int = 10;
);
```

See [Core language](../lang/CoreLanguage.md#deferred-assignment).
