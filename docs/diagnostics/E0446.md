# E0446: a constructor that does not assign a 'last' field

Every `init` of a class must assign each of its `last` fields that has no value, exactly once, on every path that returns. A class with such a field and no `init` of its own is an error too.

<!-- example: error: E0446 -->
```neura
let Box = class(
    export last size: int;

    export let init = func(initial: int) {
        if (initial > 0) {
            size = initial;
        }
    };
);
```

Assign the field on every path:

<!-- example: check -->
```neura
let Box = class(
    export last size: int;

    export let init = func(initial: int) {
        if (initial > 0) {
            size = initial;
        } else {
            size = 0;
        }
    };
);
```

See [Object lifecycle](../lang/ObjectLifecycle.md#last-fields).
