# E0262: ..= statement whose destination is not a string

`..=` has two forms. In an expression, `start ..= stop` is an inclusive range. A statement that is exactly `place ..= text;` appends text to a string place. That statement requires a `string` destination and takes no step, so an integer destination and a stepped right side are rejected. The error is at the operator.

<!-- example: error: E0262 -->
```neura
let count = func(n: int) -> int {
    n ..= 5;
    return n;
};
```

To make an inclusive range, use it as a value:

<!-- example: check -->
```neura
let count = func(n: int) -> int {
    let numbers = n ..= 5;
    return numbers.length;
};
```

See [Collections](../lang/Collections.md#ranges).
