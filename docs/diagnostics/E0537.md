# E0537: constructor shorthand names no instance field

The shorthand `init = func(x, y: int) => set;` stores each parameter in the instance field of the same name. Each parameter must name an instance field that the class declares itself. An inherited field, a static member, a method, and a name the class does not declare cannot be set.

<!-- example: error: E0537 -->
```neura
let Point = class (
    export last x: int;

    export let init = func(x, y: int) => set;
);
```

Declare the field, or write the constructor as a block:

<!-- example: check -->
```neura
let Point = class (
    export last x: int;
    export last y: int;

    export let init = func(x, y: int) => set;
);
```

See [Object lifecycle](../lang/ObjectLifecycle.md#constructor-shorthand).
