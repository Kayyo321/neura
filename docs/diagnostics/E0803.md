# E0803: missing entry point

`neura build` makes an executable image, so the program needs an entry point: a module that overrides `Std.Program.Entry.main`.

<!-- example: error: E0803 -->
```neura
let greeting = "hello";
```

Add an entry point:

<!-- example: run -->
```neura
let console = import:Std.Io.Console;
let program = import:Std.Program;

export let Main = module : program.Entry (
    export let.override main = func(arguments: string[]) -> program.ExitCode {
        console.print_line("hello");
        return program.ExitCode.Ok;
    };
);
```

```text
hello
```

See [Standard library](../lang/StandardLibrary.md).
