# E0406: return does not match the function's result type

A `return` matches its function's result type: a function without a result type returns no value, and one with a result type returns a value.

<!-- example: error: E0406 -->
```neura
let label = func(text: string) {
    return text;
};
```

Declare the result type, or return without a value:

<!-- example: check -->
```neura
let label = func(text: string) -> string {
    return text;
};
```

See [Core language](../lang/CoreLanguage.md).
