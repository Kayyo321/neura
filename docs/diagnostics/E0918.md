# E0918: assignable field in an #Immutable class

Every instance field of a class marked `#Immutable` is declared with `last` or `const`, so that no field changes after construction.

<!-- example: error: E0918 -->
```neura
#Immutable
let Point = class (
    export last x: int32;
    export let y: int32 = 0;

    export let init = func(start: int32) {
        x = start;
    };
);
```

Declare the field with `last`, and assign it in the constructor:

<!-- example: check -->
```neura
#Immutable
let Point = class (
    export last x: int32;
    export last y: int32;

    export let init = func(start: int32) {
        x = start;
        y = 0;
    };
);
```

See [Tags](../lang/Tags.md#immutable) and [Types](../lang/Types.md#immutable-classes).
