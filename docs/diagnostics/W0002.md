# W0002: use of an experimental declaration

A use of an `#Experimental` declaration warns that it may change or disappear without a deprecation period. Uses inside experimental code do not warn. `#Allow(experimental)` on the code that opts in, or `-Wno-experimental`, silences it.

<!-- example: warning: W0002 -->
```neura
let Search = module (
    #Experimental(feature: "fuzzy-search")
    export let fuzzy = func(text: string) -> int32 {
        return text.byte_length;
    };
);

let score: int32 = Search.fuzzy("neura");
```

Opt in where the experimental declaration is used:

<!-- example: check -->
```neura
let Search = module (
    #Experimental(feature: "fuzzy-search")
    export let fuzzy = func(text: string) -> int32 {
        return text.byte_length;
    };
);

#Allow(experimental)
let score: int32 = Search.fuzzy("neura");
```
