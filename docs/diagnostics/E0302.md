# E0302: duplicate declaration

A file, module, class, interface, or enum declares each member name once.

<!-- example: error: E0302 -->
```neura
let Light = enum (Red, Red);
```

Rename one of the declarations:

<!-- example: check -->
```neura
let Light = enum (Red, Green);
```

To give a function several alternatives, declare them in one overload group joined with `or func`:

<!-- example: check -->
```neura
let area = func(side: int) -> int => side * side
    or func(width: int, height: int) -> int => width * height;
```
