# E0544: class hook that may suspend

A class hook runs as one event that starts and ends without its task being suspended. Its body cannot use the scheduler: a `scope` block, `spawn`, `select`, a channel operation, a guard, or a call of a function that may do any of these. The check runs on the linked program, so it follows calls into other modules.

<!-- example: error: E0544 -->
```neura
let settle = func() -> void {
    scope {
    }
};

let Session = class (
    | set: {
        settle();
        return value;
    };
);
```

Do the scheduling work outside the hook:

<!-- example: check -->
```neura
let settle = func() -> void {
    scope {
    }
};

let Session = class (
    | set: value;
);

let open = func() -> Session {
    settle();
    return nil;
};
```

See [class hooks](../design/Hooks030.md#recursion).
