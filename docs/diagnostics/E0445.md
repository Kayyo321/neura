# E0445: a 'last' field assigned outside 'init'

A `last` instance field declared without a value is assigned once, by each `init` of its class, as `name = value` or `instance.name = value`. Methods, closures, other classes, and other instances cannot assign it.

<!-- example: error: E0445 -->
```neura
let Box = class(
    export last size: int;

    export let init = func(initial: int) {
        size = initial;
    };

    export let grow = func {
        size = size + 1;
    };
);
```

Declare a field that changes with `let`:

<!-- example: check -->
```neura
let Box = class(
    export let size: int;

    export let init = func(initial: int) {
        size = initial;
    };

    export let grow = func {
        size = size + 1;
    };
);
```

See [Object lifecycle](../lang/ObjectLifecycle.md#last-fields).
