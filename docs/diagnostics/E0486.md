# E0486: invalid format specification in an interpolated string

The specification of a hole, `{value:specification}`, is checked when the program is compiled, against the hole's type, with the rules the [formatting library](../lang/StandardLibrary.md#console-formatting) applies at run time. The message is the library's message for the same error, and a label gives the reason. A width or precision written as a nested hole, `{value:>{width}}`, holds an integer.

The `c` presentation is not used in an interpolated string: the library checks it against the value when it runs, and a checked interpolated string does not fail to format.

<!-- example: error: E0486 -->
```neura
let count = 3;
let text = $"{count:.2}";
```

An integer takes no precision; a float does:

<!-- example: check -->
```neura
let count = 3;
let ratio = 0.25;
let text = $"{count:>4} {ratio:.2f}";
```

See [Core language](../lang/CoreLanguage.md#interpolated-strings).
