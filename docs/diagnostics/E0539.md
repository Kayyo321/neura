# E0539: class hook replaces an inherited one without `.override`

A class inherits each clause it does not declare from the nearest base class that declares it. A class that declares a clause its base already has, declared or inherited, writes `.override` after the word, so that replacing the base's rule is visible where it happens. `neura check --fix` inserts it.

<!-- example: error: E0539 -->
```neura
let Session = class (
    | set: value;
);

let Admin = class:Session (
    | set: value;
);
```

Mark the clause as replacing the inherited one:

<!-- example: check -->
```neura
let Session = class (
    | set: value;
);

let Admin = class:Session (
    | set.override: value;
);
```
