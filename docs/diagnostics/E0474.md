# E0474: using resource that cannot be closed

The value a `using` binds is a reference whose type implements `Std.Io.Closeable.Closeable`, so that the block can close it. A number, a string, a class that does not implement the interface, and a value written `nil` are rejected. A reference that is nil at run time fails with the nil-reference failure, and nothing is closed.

<!-- example: error: E0474 -->
```neura
let.promote _ = import:Std.Core.Result;
let work = func() -> Result<int> {
    using (count = 1) {
    }
    return Result<int>.Ok(0);
};
```

Bind an object whose class implements `Closeable`:

<!-- example: check -->
```neura
let closeable = import:Std.Io.Closeable;
let.promote _ = import:Std.Core.Result;
let.promote _ = import:Std.Core.Unit;
let Counter = class implements closeable.Closeable (
    export let close = func -> Result<Unit> => Result<Unit>.Ok(Unit.Value);
);
let work = func() -> Result<int> {
    using (count = new Counter()) {
    }
    return Result<int>.Ok(0);
};
```
