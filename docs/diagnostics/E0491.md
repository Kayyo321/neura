# E0491: unreachable match arm

An arm of a `match` with a guard, a nested pattern or a tuple pattern, or of a `match.is`, is never selected when the unguarded arms before it already match every value it matches: a repeated pattern, a pattern after one that covers it, or any arm after `_`. A guarded arm covers nothing, so the arms after it are not affected. The error labels the earlier arm that covers the unreachable one. A repeated arm in a match whose arms all have one level of bindings and no guard is still [E0412](E0412.md).

<!-- example: error: E0491 -->
```neura
let Light = enum (Red, Yellow, Green);
let pair = func(a: Light, b: Light) -> int => match ([a, b]) {
    [_, _] => 1,
    [Light.Red, _] => 2,
};
```

Remove the arm, or move it before the arms that cover it:

<!-- example: check -->
```neura
let Light = enum (Red, Yellow, Green);
let pair = func(a: Light, b: Light) -> int => match ([a, b]) {
    [Light.Red, _] => 2,
    [_, _] => 1,
};
```

See [Types](../lang/Types.md#enums).
