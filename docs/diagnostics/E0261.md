# E0261: malformed character literal

A character literal is one printable ASCII character other than `'` and `\`, or one escape, between single quotes on one line. The escapes are `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"`, `\xHH` with exactly two hexadecimal digits, and `\u{H}` up to `\u{FF}` ([E0268](E0268.md) and [E0269](E0269.md) cover a malformed `\u` escape). An empty literal, a literal with more than one character, a literal that the line or the file ends in, a raw tab or control byte, and any other escape are rejected. The error is at the literal, or at the escape.

<!-- example: error: E0261 -->
```neura
let word = 'ab';
```

Use double quotes for text, and an escape for a quote, a backslash or a control character:

<!-- example: check -->
```neura
let word = "ab";
let quote: byte = '\'';
let tab: byte = '\t';
```

See [Core language](../lang/CoreLanguage.md#character-literals).
