# E0303: duplicate parameter or field name

The parameters of a function, the type parameters of a generic declaration, and the fields of an enum variant's payload have distinct names.

<!-- example: error: E0303 -->
```neura
let area = func(side: int, side: int) -> int => side * side;
```

Give each parameter its own name:

<!-- example: check -->
```neura
let area = func(width: int, height: int) -> int => width * height;
```

See [Core language](../lang/CoreLanguage.md).
