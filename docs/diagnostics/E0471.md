# E0471: deferred call with a result

A deferred call runs when its block is left, where nothing can read what it returns, so its result type must be `void`. A call that returns any other type, a `Result` included, would lose its result silently. The error labels the callee's result type.

<!-- example: error: E0471 -->
```neura
let compute = func() -> int {
    return 1;
};
let work = func() -> void {
    defer compute();
};
```

Defer a function that handles the result itself:

<!-- example: check -->
```neura
let compute = func() -> int {
    return 1;
};
let record = func() -> void {
    let ignored = compute();
};
let work = func() -> void {
    defer record();
};
```

To close a `Std.Io.Closeable` resource, whose `close` returns `Result<Unit>`, use `using`, which returns a failed close from the function. See [Core language](../lang/CoreLanguage.md#defer).
