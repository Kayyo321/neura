# E0318: derivation mapping names no reachable member

Resolve the type and member named by the mapping from the scope of the derivation. A record field uses `field Record.field`, a named enum payload uses `field Enum.Variant.field`, and an enum variant uses `variant Enum.Variant`. The derived root must reach that record or enum.

<!-- example: error: E0318 -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<User> { field User.nick: "n"; };
```

<!-- example: check -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<User> { field User.name: "n"; };
```
