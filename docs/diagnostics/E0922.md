# E0922: override of a synchronized method that is not synchronized

A method that overrides a `#Synchronized` method is `#Synchronized` too. A call through the base class dispatches to the override, and it must run under the same guard as every other implementation.

<!-- example: error: E0922 -->
```neura
let Account = class (
    let balance: int64 = 0;

    #Synchronized
    export let deposit = func(amount: int64) -> int64 {
        balance = balance + amount;
        return balance;
    };
);

let Savings = class:Account (
    export let.override deposit = func(amount: int64) -> int64 {
        return amount;
    };
);
```

Mark the override `#Synchronized`:

<!-- example: check -->
```neura
let Account = class (
    let balance: int64 = 0;

    #Synchronized
    export let deposit = func(amount: int64) -> int64 {
        balance = balance + amount;
        return balance;
    };
);

let Savings = class:Account (
    #Synchronized
    export let.override deposit = func(amount: int64) -> int64 {
        return amount;
    };
);
```
