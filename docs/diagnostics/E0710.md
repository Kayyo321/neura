# E0710: invalid host or scheduler binding

Host bindings, host callbacks, and scheduler bindings connect the standard library to the runtime; only standard library modules declare them.

<!-- example: error: E0710 -->
```neura
let Tools = module (
    let handler = func(value: int64) -> int64 {
        return value;
    } callback("user.callback", 1);
);
```

Use the standard library module that provides the service; a program reaches native code through `Std.DynamicForeign` or `import:c(...)`:

<!-- example: check -->
```neura
let clock = import:Std.Time.SystemClock;
```

See [Standard library design](../lang/Stdlib.md).
