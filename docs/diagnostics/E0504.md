# E0504: interface not satisfied

A class that implements an interface declares each of its methods that has no default, exported, with the interface's signature.

<!-- example: error: E0504 -->
```neura
let Shape = interface (
    let area = func() -> int;
);
let Square = class implements Shape (
    export let side: int = 2;
);
```

Declare the method:

<!-- example: check -->
```neura
let Shape = interface (
    let area = func() -> int;
);
let Square = class implements Shape (
    export let side: int = 2;
    export let area = func() -> int => side * side;
);
```

See [Polymorphism](../lang/Polymorphism.md).
