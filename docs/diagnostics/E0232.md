# E0232: postfix ? that needs parentheses

A `?` after an expression is decided by the token that follows it. When that token is `.`, the `?` would have to propagate an error and then read a member, which is written with parentheses. The error is at the `?`. `r?.name`, with no space, is the token `?.` of optional access.

<!-- example: error: E0232 -->
```neura
let.promote _ = import:Std.Core.Result;
let Pet = class ( export let age: int = 0; );
let open = func(name: string) -> Result<Pet> => Result<Pet>.Ok(new Pet());
let age = func(name: string) -> Result<int> => Result<int>.Ok(open(name)? .age);
```

Propagate the error first, then read the member:

<!-- example: check -->
```neura
let.promote _ = import:Std.Core.Result;
let Pet = class ( export let age: int = 0; );
let open = func(name: string) -> Result<Pet> => Result<Pet>.Ok(new Pet());
let age = func(name: string) -> Result<int> => Result<int>.Ok((open(name)?).age);
```
