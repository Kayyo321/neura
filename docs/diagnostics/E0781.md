# E0781: kernel binding does not match its kernel

A kernel-bound function must be non-generic and its parameters and result must match the kernel's signature in the compiler's kernel table. The message gives the expected signature.

<!-- diagnostic: not reproducible: only a standard library module may declare a kernel binding -->

Declare the function with the signature that [Kernels](../runtime/Kernels.md) lists for the kernel; the generated `Std.Internal.Kernels` modules already do:

<!-- example: fragment: a declaration inside a standard library module -->
```neura
export let crc32 = func(bytes: uint8[list]) -> uint32 kernel("neura.digest.crc32", 1);
```

See [Kernels](../runtime/Kernels.md).
