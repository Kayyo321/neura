# E0572: copy construction of a value that is not a record

`new with(source) { field: value }` copies a record: its type is the source's type, which must be a record. A class, an interface, `class`, `nil` and a value of a type parameter are not record types, even when the value at run time is a record, and the form is never target-typed.

<!-- example: error: E0572 -->
```neura
let Shape = class (
    export let label: string = "shape";
);
let shape = new Shape();
let copy = new with(shape) { };
```

Construct the class with `new`, or declare the type as a record:

<!-- example: check -->
```neura
let Shape = record (label: string);
let shape = new Shape("shape");
let copy = new with(shape) { label: "circle" };
```

See [Types](../lang/Types.md#copy-construction).
