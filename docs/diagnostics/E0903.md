# E0903: missing tag argument

A tag argument without a default must be given.

<!-- example: error: E0903 -->
```neura
#Since
let count = func() -> int32 {
    return 1;
};
```

Give the argument:

<!-- example: check -->
```neura
#Since("0.2.0")
let count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
