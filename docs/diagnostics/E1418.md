# E1418: mutable reference escapes an invariant field

An exported method cannot hand out a mutable alias to an invariant-governed field. Class invariants are planned for a later release.

<!-- diagnostic: not reproducible: class invariants are a Phase 3 feature -->

Return a value instead of a mutable reference to the field.

<!-- example: check -->
```neura
let Counter = class (
    let count: int32 = 0;

    export let read = func() -> int32 => count;
);
```

See [the laws design](../design/Laws031.md).
