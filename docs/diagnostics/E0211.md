# E0211: malformed scope statement

A `scope` statement names one scope or none: `scope (name) { }` or `scope { }`.

<!-- example: error: E0211 -->
```neura
let run = func() {
    scope (first, second) {
    }
};
```

Name at most one scope; nest scopes to have two:

<!-- example: check -->
```neura
let run = func() {
    scope (outer) {
        scope (inner) {
        }
    }
};
```

See [Concurrency](../lang/Concurrency.md).
