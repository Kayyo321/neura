# E0916: result tag on a function without a result

`#NoDiscard` on a function or method asks callers to use its result, so the function must return one.

<!-- example: error: E0916 -->
```neura
#NoDiscard
let log = func(message: string) -> void {
};
```

Remove the tag, or return a value that callers must check:

<!-- example: check -->
```neura
#NoDiscard
let log = func(message: string) -> bool {
    return message.byte_length > 0;
};
```
