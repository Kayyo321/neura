# E0498: any at a boundary that would box it

An `any` is four inline words. It is not the result of a spawned call, a parallel item, a callback's argument or result, or a host call's argument, because those boundaries would box it into an object the program did not ask for. An `any` given to a task or sent on a channel is not [transferable](../lang/Types.md#transferable-types) and is [E0602](E0602.md).

<!-- example: error: E0498 -->
```neura
let work = func() -> any => 1;
let run = func() {
    scope {
        let task = spawn work();
    }
};
```

Match the value first and return what it holds:

<!-- example: check -->
```neura
let work = func() -> int64 => 1;
let run = func() {
    scope {
        let task = spawn work();
    }
};
```

See [Types](../lang/Types.md#the-type-any).
