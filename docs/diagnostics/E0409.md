# E0409: ambiguous overload or cast

When several alternatives of an overload group, or several casts, accept the arguments and none is a better match than the others, the call is ambiguous.

<!-- example: error: E0409 -->
```neura
let identify = func(value: int16) -> bool => true
    or func(value: int64) -> bool => false;
let use = func() -> bool => identify(2);
```

Give the argument the type of the alternative you mean:

<!-- example: check -->
```neura
let identify = func(value: int16) -> bool => true
    or func(value: int64) -> bool => false;
let use = func() -> bool => identify(2 as int64);
```
