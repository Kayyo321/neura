# E0704: invalid import declaration

An import initializes an unannotated module-level binding; `let.promote` takes an import alias, and a wildcard import is promoted with `let.promote _`.

<!-- example: error: E0704 -->
```neura
let.promote time = import:Std.Time.*;
```

Promote the wildcard into `_`:

<!-- example: check -->
```neura
let.promote _ = import:Std.Time.*;
```

See [Modules and imports](../lang/Modules.md).
