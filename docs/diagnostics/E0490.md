# E0490: pattern that cannot match

A `match.is` pattern names a type that the subject's value never has. A scalar or string pattern matches a value of exactly that resolved type, so on an `int32` subject only `int32` (or `int`) can match; no conversion, `let.as` cast or parsing takes part. A class pattern on a class subject must be related to the subject's class, as a base or a derived class; an interface pattern always can match. `nil` never matches a scalar or a string. The message names the subject's type.

<!-- example: error: E0490 -->
```neura
let width = func(x: int32) -> int32 => match.is (x) {
    v: int32 => v,
    int64 => 0,
};
```

Remove the arm, or convert the value before matching it:

<!-- example: check -->
```neura
let width = func(x: int32) -> int32 => match.is (x) {
    v: int32 => v,
};
```

See [Types](../lang/Types.md#object-casts).
