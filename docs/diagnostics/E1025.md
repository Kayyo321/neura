# E1025: path outside the project

Write paths relative to the manifest with slash separators. Source roots, assets and vendored archives stay inside the project. A directory named by an external dependency's `path` is outside it.

<!-- diagnostic: not reproducible: the manifest model runs in its dedicated tests until project commands are wired -->
<!-- example: fragment: this belongs in a project manifest -->
```toml
[packages.ui]
root = "ui"
assets = ["ui/assets"]
```
