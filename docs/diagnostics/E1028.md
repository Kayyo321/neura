# E1028: limit out of range

Use a [limit for the target kind](../design/Projects030.md#the-project-manifest). Each bound is at least 1 and at most the maximum in the [limit table](../design/Apps030.md#finite-limits).

<!-- diagnostic: not reproducible: the manifest model runs in its dedicated tests until project commands are wired -->
<!-- example: fragment: the server target is declared elsewhere in neura.toml -->
```toml
[targets.server.limits]
S-1 = 16
```
