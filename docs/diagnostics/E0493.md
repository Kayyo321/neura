# E0493: operation is not defined for any

The only operations on an `any` are to copy it, pass, return and store it, test it with `is`, and match it with `match.is`. Arithmetic, comparison with `==`, member access, `as`, the value members `equals`, `hash_code` and `to_string`, and formatting, including an argument of an untyped variadic parameter `...` and an interpolated string hole, are not defined for it. Match the value first: the arm's binding has the type it tests.

<!-- example: error: E0493 -->
```neura
let read = func(v: any) -> int64 => v as int64;
```

Match the value instead:

<!-- example: check -->
```neura
let read = func(v: any) -> int64 => match.is (v) {
    count: int64 => count,
    _ => 0,
};
```
