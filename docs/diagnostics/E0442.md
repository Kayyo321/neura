# E0442: a deferred 'last' binding assigned in a loop

A `last` binding declared without a value cannot be assigned inside a loop that does not also contain its declaration, because the loop could run the assignment more than once. This holds even when a `break` follows the assignment.

<!-- example: error: E0442 -->
```neura
let first = func(values: int[]) -> int {
    last found: int;
    for (let value: int in values) {
        found = value;
        break;
    }
    return 0;
};
```

Declare the binding inside the loop, or compute the value with `let` and bind it once after the loop:

<!-- example: check -->
```neura
let first = func(values: int[]) -> int {
    let candidate = -1;
    for (let value: int in values) {
        candidate = value;
        break;
    }
    last found: int;
    found = candidate;
    return found;
};
```
