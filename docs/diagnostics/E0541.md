# E0541: class hook on a class with synchronized methods

A class hook reads or admits a reference outside any guard, so a class whose instances are guarded by `#Synchronized` methods cannot declare one: neither a class with such a method nor a class whose base has one. A class that inherits a hook cannot add a `#Synchronized` method either.

<!-- example: error: E0541 -->
```neura
let Account = class (
    | get: instance;

    let balance: int32 = 0;

    #Synchronized
    export let deposit = func(amount: int32) {
        balance += amount;
    };
);
```

Validate in the synchronized methods instead:

<!-- example: check -->
```neura
let Account = class (
    let balance: int32 = 0;

    #Synchronized
    export let deposit = func(amount: int32) {
        if (amount > 0) {
            balance += amount;
        }
    };
);
```

See [Types](../lang/Types.md#class-hooks).
