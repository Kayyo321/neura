# E0304: unknown name

A name must refer to a binding, parameter, or declaration that is visible where it is used; for a qualified name, each part must be a member that is visible from there.

<!-- example: error: E0304 -->
```neura
let total = func(count: int) -> int {
    return cuont;
};
```

Correct the spelling, or declare or import the name. The compiler suggests a visible name with a similar spelling:

<!-- example: check -->
```neura
let total = func(count: int) -> int {
    return count;
};
```

See [Modules and imports](../lang/Modules.md).
