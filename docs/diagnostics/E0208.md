# E0208: type annotation on a definition

A declaration that defines a class, an interface, a module, or an enum has no type annotation: the definition is its type.

<!-- example: error: E0208 -->
```neura
let Light: int = enum (Red, Green);
```

Remove the annotation:

<!-- example: check -->
```neura
let Light = enum (Red, Green);
```

See [Types](../lang/Types.md).
