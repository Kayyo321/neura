# E1416: closed unit contains an abstract law

A closed module must prove every law it declares. Inheritable modules can declare obligations that a concrete descendant later fulfills.

<!-- example: error: E1416 -->
```neura
const Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
);
```

Include a proof in the closed module.

<!-- example: check -->
```neura
const Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```
