# E0510: field is read-only outside its class

A field whose accessors include `| get:` but no `| set:` is read-only outside its class: an assignment, a compound assignment, or `++` and `--` through an instance needs a setter. Inside the declaring class the field is plain storage and stays writable.

<!-- example: error: E0510 -->
```neura
let Ticket = class (
    export let code = "XY729H08";
        | get: code;
);
let ticket = new Ticket();
ticket.code = "AB12";
```

Change the field through a method of its class, or declare a setter:

<!-- example: check -->
```neura
let Ticket = class (
    export let code = "XY729H08";
        | get: code;

    export let reissue = func(next: string) {
        code = next;
    };
);
let ticket = new Ticket();
ticket.reissue("AB12");
```
