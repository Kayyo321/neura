# E0434: function without a body

Only a member of a class, interface, or module can be declared without a body, and a function without a body cannot be called.

<!-- example: error: E0434 -->
```neura
let area = func(side: int) -> int;
```

Give the function a body:

<!-- example: check -->
```neura
let area = func(side: int) -> int => side * side;
```

See [Polymorphism](../lang/Polymorphism.md).
