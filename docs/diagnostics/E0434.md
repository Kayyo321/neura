# E0434: function without a body

Only a member of a class, interface, or module can be declared without a body, and a function without a body cannot be called.

<!-- example: error: E0434 -->
```neura
let area = func(side: int) -> int;
```

Give the function a body:

<!-- example: check -->
```neura
let area = func(side: int) -> int => side * side;
```

A call through a module of a function that the module, and every module it inherits, leaves without a body is rejected when the image is built. Here the entry module `Site` inherits `main` from `Server`, and `main` calls `serve`, which neither module implements:

<!-- example: error: E0434 -->
```neura
let program = import:Std.Program;

let Server = module:program.Entry (
    export let serve = func(path: string) -> string;

    export let.override main = func(args: string[]) -> program.ExitCode {
        serve("/");
        return program.ExitCode.Ok;
    };
);

let Site = module:Server ();
```

Implement the requirement in the module the call goes through:

<!-- example: check -->
```neura
let program = import:Std.Program;

let Server = module:program.Entry (
    export let serve = func(path: string) -> string;

    export let.override main = func(args: string[]) -> program.ExitCode {
        serve("/");
        return program.ExitCode.Ok;
    };
);

let Site = module:Server (
    export let.override serve = func(path: string) -> string => "served " + path;
);
```

See [Polymorphism](../lang/Polymorphism.md) and [Modules](../lang/Modules.md#interfaces-and-inheritance).
