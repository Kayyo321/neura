# E0904: duplicate tag argument

Each argument of a tag is given at most once, by position or by name.

<!-- example: error: E0904 -->
```neura
#Deprecated(reason: "it is slow", reason: "it rounds")
let old_count = func() -> int32 {
    return 1;
};
```

Give it once:

<!-- example: check -->
```neura
#Deprecated(reason: "it is slow and it rounds")
let old_count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
