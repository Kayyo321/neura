# E0517: accessor on a static field

Accessors serve instance fields. A `static` field belongs to its class and cannot have `| get:` or `| set:` clauses.

<!-- example: error: E0517 -->
```neura
let Limits = class (
    export static let calls: int = 0;
        | get: calls;
);
```

Expose a static field through a static function:

<!-- example: check -->
```neura
let Limits = class (
    static let calls: int = 0;

    export static let call_count = func -> int => calls;
);
```

See [Types](../lang/Types.md#accessors).
