# E0451: an array escapes its owner

An activation array and its backing arrays must remain live for every use. A function may return an array it creates, transferring it to the caller.

<!-- example: error: E0451 -->
```neura
let alias = func(items: int[]) -> int[] {
    return items;
};
```

Create a fresh array for the result, or use a list when storage must outlive the activation.

<!-- example: check -->
```neura
let copy_pair = func(items: int[]) -> int[] {
    return [items[0], items[1]];
};
```
