# E0908: reserved tag

A reserved tag names a promise, such as purity or memoization, that the compiler does not check or keep yet. Writing it is an error, so that no program relies on a guarantee that does not hold. The error names what to write instead; `neura tags` lists every reserved tag with its alternative.

<!-- example: error: E0908 -->
```neura
#Memoize
let fibonacci = func(n: int64) -> int64 {
    if (n < 2) {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
};
```

Leave the tag out and do what it describes explicitly; here, a loop computes the value without repeated calls:

<!-- example: check -->
```neura
let fibonacci = func(n: int64) -> int64 {
    let previous: int64 = 0;
    let current: int64 = 1;
    for (let i: int64 = 0; i < n; i += 1) {
        let next: int64 = previous + current;
        previous = current;
        current = next;
    }
    return previous;
};
```
