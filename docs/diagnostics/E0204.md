# E0204: expected an expression

An expression was required, such as the value after `=` or an operand of an operator, but the next token cannot begin one.

<!-- example: error: E0204 -->
```neura
let count: int32 = ;
```

Write the value:

<!-- example: check -->
```neura
let count: int32 = 0;
```

See [Core language](../lang/CoreLanguage.md).
