# E0315: ambiguous extension function

More than one enabled extension function of the called name accepts the receiver. The call is an error whatever the order of the imports and however the receiver types relate, so adding a set or a more specific declaration elsewhere never silently changes which function a call reaches. The error lists each candidate with the set that enables it.

<!-- example: error: E0315 -->
```neura
// The file and the module each enable their own extension functions.
let.extension shout = func(text: string) -> string => text + "!";

let Texts = module (
    let.extension shout = func(text: string) -> string => text + "?";
    export let loud = "ready".shout();
);
```

Call one of them as an ordinary function, or, for a set, through its alias, as in `words.shout("ready")`:

<!-- example: check -->
```neura
let.extension shout = func(text: string) -> string => text + "!";

let Texts = module (
    let.extension ask = func(text: string) -> string => text + "?";
    export let loud = shout("ready") + "ready".ask();
);
```
