# E0513: reference field not definitely bound

A primitive reference field is bound exactly once before it is read: by its initializer, or by every path of every constructor, outside loops.

<!-- example: error: E0513 -->
```neura
let View = class (
    let value: &int;
    let init = func(storage: &int, bind: bool) {
        if (bind) {
            value = storage;
        }
    };
);
```

Bind the field on every path through the constructor:

<!-- example: check -->
```neura
let View = class (
    let value: &int;
    let init = func(storage: &int) {
        value = storage;
    };
);
```
