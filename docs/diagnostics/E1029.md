# E1029: bundle cannot be written

A bundle is written and read only when every file is listed in `bundle.json` with its digest and size, no file exceeds `W-1`, no file is source, and a web bundle holds only what a browser may run. `neura build --target` reports `E1029` for the file or import at fault. `neura run`, `neura package` and the hosts report it for a bundle directory with an unlisted, missing or changed file or a `bundle.json` that is not canonical, and `neura run` and `neura package` for a bundle marked `dev` by `neura dev`. Rebuild the bundle with `neura build`, or remove what the message names.
