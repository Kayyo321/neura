# E0263: range or chain of the wrong shape

An integer range has exactly two bounds and an optional step: `start .. stop`, `start ..= stop`, and either with `: step`. A third bound, and `..=` combined with `..` in one range, are rejected at the second operator.

<!-- example: error: E0263 -->
```neura
let numbers = func() -> int[] => 0 ..= 2 .. 4;
```

Write one range, with a step if the elements should skip:

<!-- example: check -->
```neura
let numbers = func() -> int[] => 0 ..= 4 : 2;
```

See [Collections](../lang/Collections.md#ranges).
