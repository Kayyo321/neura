# E0263: range or chain of the wrong shape

An integer range has exactly two bounds and an optional step: `start .. stop`, `start ..= stop`, and either with `: step`. A third bound, and `..=` combined with `..` in one range, are rejected at the second operator. A [string chain](../lang/CoreLanguage.md#string-chains) `a .. b .. c` takes no step (rejected at the colon), never uses `..=` in an expression (rejected at the operator), and is not grouped by braces, which group ranges only.

<!-- example: error: E0263 -->
```neura
let numbers = func() -> int[] => 0 ..= 2 .. 4;
```

Write one range, with a step if the elements should skip:

<!-- example: check -->
```neura
let numbers = func() -> int[] => 0 ..= 4 : 2;
```

`..=` appends text only as a statement:

<!-- example: error: E0263 -->
```neura
let shout = func(text: string) -> string => text ..= "!";
```

<!-- example: check -->
```neura
let shout = func(text: string) -> string => text .. "!";
```

See [Collections](../lang/Collections.md#ranges).
