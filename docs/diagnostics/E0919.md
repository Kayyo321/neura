# E0919: field of a mutable type in an #Immutable class

Every instance field of a class marked `#Immutable` has an immutable type: `bool`, a number, `string`, a tuple or enum whose parts are immutable, or a class marked `#Immutable`. A `last` field that holds a list cannot be assigned again, but the list can change, so the value would.

<!-- example: error: E0919 -->
```neura
#Immutable
let Path = class (
    export last name: string;
    export last steps: int32[list];

    export let init = func(label: string) {
        name = label;
        steps = [];
    };
);
```

Hold an immutable value instead, such as an `#Immutable` class or a tuple:

<!-- example: check -->
```neura
#Immutable
let Step = class (
    export last length: int32;

    export let init = func(value: int32) {
        length = value;
    };
);

#Immutable
let Path = class (
    export last name: string;
    export last first: Step;

    export let init = func(label: string) {
        name = label;
        first = new Step(1);
    };
);
```
