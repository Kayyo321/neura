# E0920: #Immutable class with a base or subclass that is not #Immutable

A class marked `#Immutable` extends only `#Immutable` classes, and every class that extends it is `#Immutable` too: a value of the base type may be an instance of any subclass, and an inherited field could change.

<!-- example: error: E0920 -->
```neura
#Immutable
let Shape = class (
    export const sides: int32 = 0;
);

let Polygon = class:Shape (
    export let corners: int32 = 3;
);
```

Mark the subclass `#Immutable`, which makes its own fields follow the rule:

<!-- example: check -->
```neura
#Immutable
let Shape = class (
    export const sides: int32 = 0;
);

#Immutable
let Polygon = class:Shape (
    export const corners: int32 = 3;
);
```

See [Tags](../lang/Tags.md#immutable) and [Types](../lang/Types.md#immutable-classes).
