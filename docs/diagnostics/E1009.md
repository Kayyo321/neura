# E1009: key of the wrong type

Every iteration key is a string or a fixed-width integer.

<!-- example: error: E1009 -->
```neura
let view = html(items: float64[]) { @for (let item in items; key: item) { <p>{item}</p> } };
```

<!-- example: check -->
```neura
let view = html(items: int32[]) { @for (let item in items; key: item) { <p>{item}</p> } };
```
