# E0906: duplicate tag

A declaration carries each tag once, except the tags that `neura tags` marks repeatable, such as `#Author` and `#Allow`.

<!-- example: error: E0906 -->
```neura
#Deprecated
#Deprecated(as_of: "0.2.0")
let old_count = func() -> int32 {
    return 1;
};
```

Keep one of them:

<!-- example: check -->
```neura
#Deprecated(as_of: "0.2.0")
let old_count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
