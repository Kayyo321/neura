# E0206: invalid type syntax

A type has at most one `&` prefix: a primitive reference to a primitive reference is not a type.

A record's `implements` that the file ends after, `let P = record implements` as an editor buffer may hold it, is a type list without its first type and is `E0206` too; the declarations before it are kept.

<!-- example: error: E0206 -->
```neura
let bump = func(counter: &(&int)) {
    counter = counter + 1;
};
```

Use one `&`:

<!-- example: check -->
```neura
let bump = func(counter: &int) {
    counter = counter + 1;
};
```

See [Types](../lang/Types.md).
