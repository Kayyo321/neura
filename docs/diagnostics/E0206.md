# E0206: invalid type syntax

A type has at most one `&` prefix: a primitive reference to a primitive reference is not a type.

<!-- example: error: E0206 -->
```neura
let bump = func(counter: &(&int)) {
    counter = counter + 1;
};
```

Use one `&`:

<!-- example: check -->
```neura
let bump = func(counter: &int) {
    counter = counter + 1;
};
```

See [Types](../lang/Types.md).
