# E1402: rewrite motive does not match its goal

The rewrite motive with the evidence equation’s source side in every hole must equal the current goal. Forward `rewrite` uses the left side as its source, and `rewrite.rev` uses the right side.

<!-- example: error: E1402 -->
```neura
let Example = module (
    export let Reflexive = law (
        given identity: { true == true : bool };
        claim: { true == true : bool };
    );
        | proof: {
            rewrite identity in { _ == false : bool };
            {==}
        };
);
```

Use a motive whose instantiated proposition is the current goal.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        given identity: { true == true : bool };
        claim: { true == true : bool };
    );
        | proof: {
            rewrite identity in { _ == true : bool };
            {==}
        };
);
```
