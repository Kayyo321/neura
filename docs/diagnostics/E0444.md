# E0444: a deferred 'last' binding without a type

A `last` binding takes its type from its value. One that is declared without a value, to be assigned later, must state its type.

<!-- example: error: E0444 -->
```neura
let make = func() -> int {
    last base;
    base = 1;
    return base;
};
```

Give it a type, or its value now:

<!-- example: check -->
```neura
let make = func() -> int {
    last base: int;
    base = 1;
    last next = base + 1;
    return next;
};
```

See [Core language](../lang/CoreLanguage.md#deferred-assignment).
