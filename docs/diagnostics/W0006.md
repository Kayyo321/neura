# W0006: access through a reference that may be nil

A member access, method call, or implicit dereference can trap when its receiver is nil. The compiler reports `nil-access` when a declaration or a reachable value supplies evidence that nil can reach the receiver.

<!-- example: warning: W0006 -->
```neura
let Connection = class (
    export last ready: bool = true;
);

let is_ready = func(connection: Connection = nil) -> bool {
    return connection.ready;
};
```

Guard the use with a nil condition. A successful condition proves the local or parameter non-nil inside the branch.

<!-- example: check -->
```neura
let Connection = class (
    export last ready: bool = true;
);

let is_ready = func(connection: Connection = nil) -> bool {
    if (connection) {
        return connection.ready;
    }
    return false;
};
```

Use `?.` when the caller should receive an Optional result. For a field that can change, copy it once in an `if` initializer and test the copy. Use `-Wno-nil-access` to disable this warning. See [nil conditions](../lang/CoreLanguage.md#nil-conditions).
