# E0492: value cannot be held in any

An `any` holds a `bool`, a sized integer, a `float16`, `bfloat16`, `float32` or `float64`, a `string`, a class or interface reference, or nil. An array, a list, a tuple, an enum (including `Optional` and `Result`), a function value and a primitive reference cannot be packed into one. A value whose type is a type parameter is checked when the generic function is instantiated, and the error then also labels the instantiating call.

<!-- example: error: E0492 -->
```neura
let v: any = [1, 2];
```

Hold the value in a class and pack the reference:

<!-- example: check -->
```neura
let Pair = class ( export let values: int32[] = [1, 2]; );
let v: any = new Pair();
```
