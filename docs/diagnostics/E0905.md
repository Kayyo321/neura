# E0905: tag argument of the wrong type

A tag argument is a literal of the type its signature gives: a string, an integer, a bool, a number, a name, or a warning. A list is accepted only by a parameter that takes any number of values, and an integer must fit in 64 bits.

<!-- example: error: E0905 -->
```neura
#Inline(always: "yes")
let twice = func(value: int32) -> int32 {
    return value + value;
};
```

Write a literal of the expected type:

<!-- example: check -->
```neura
#Inline(always: true)
let twice = func(value: int32) -> int32 {
    return value + value;
};
```
