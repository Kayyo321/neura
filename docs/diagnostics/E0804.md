# E0804: more than one entry point

A program has one entry point: only one module overrides `Std.Program.Entry.main`.

<!-- example: error: E0804 -->
```neura
let program = import:Std.Program;

export let First = module : program.Entry (
    export let.override main = func(arguments: string[]) -> program.ExitCode {
        return program.ExitCode.Ok;
    };
);
export let Second = module : program.Entry (
    export let.override main = func(arguments: string[]) -> program.ExitCode {
        return program.ExitCode.Ok;
    };
);
```

Keep one entry module, and call the other's work from it:

<!-- example: run -->
```neura
let console = import:Std.Io.Console;
let program = import:Std.Program;

export let Main = module : program.Entry (
    export let.override main = func(arguments: string[]) -> program.ExitCode {
        console.print_line("ready");
        return program.ExitCode.Ok;
    };
);
```

```text
ready
```
