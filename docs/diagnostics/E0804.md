# E0804: more than one entry point

A program has one entry point: only one module overrides `Std.Program.Entry.main`.

<!-- example: error: E0804 -->
```neura
let program = import:Std.Program;

export let First = module : program.Entry (
    export let.override main = func(args: string[]) -> program.ExitCode {
        return program.ExitCode.Ok;
    };
);
export let Second = module : program.Entry (
    export let.override main = func(args: string[]) -> program.ExitCode {
        return program.ExitCode.Ok;
    };
);
```

Keep one entry module, and call the other's work from it:

<!-- example: run -->
```neura
let console = import:Std.Io.Console;
let program = import:Std.Program;

export let Main = module : program.Entry (
    export let.override main = func(args: string[]) -> program.ExitCode {
        console.print_line("ready");
        return program.ExitCode.Ok;
    };
);
```

```text
ready
```

A module that overrides `main` can itself be inherited, as a library module that supplies `main` is: the entry point is then `main` of the one module of that line that no other module inherits. Two such modules are two entry points:

<!-- example: error: E0804 -->
```neura
let program = import:Std.Program;

let Server = module:program.Entry (
    export let.override main = func(args: string[]) -> program.ExitCode {
        return program.ExitCode.Ok;
    };
);

let First = module:Server ();
let Second = module:Server ();
```

See [Standard library](../lang/StandardLibrary.md) and [Modules](../lang/Modules.md#interfaces-and-inheritance).
