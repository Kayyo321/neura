# E0574: invalid virtual accessor

`.virtual` and `.override` after the word of an accessor clause mark an accessor that subclasses may override and an override of it. They have no meaning in an interface, whose properties always reach the receiver's class.

<!-- example: error: E0574 -->
```neura
let Named = interface (
    let name: string;
        | get.virtual;
);
```

Write the clause of an interface property without them:

<!-- example: check -->
```neura
let Named = interface (
    let name: string;
        | get;
);
```

See [Polymorphism](../lang/Polymorphism.md#interface-properties).
