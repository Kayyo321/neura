# E0574: invalid virtual accessor

`| get.virtual:` and `| set.virtual:` mark an accessor of a class field as a slot that subclasses may override, and `| get.override:` and `| set.override:` override it. A clause is one or the other, not both, and `.virtual` has no meaning in an interface, whose properties always reach the receiver's class.

<!-- example: error: E0574 -->
```neura
let Shape = class (
    export let label: string = "shape";
        | get.virtual.override: label;
);
```

Mark the base clause `.virtual`, and the subclass's clause `.override`:

<!-- example: check -->
```neura
let Shape = class (
    export let label: string = "shape";
        | get.virtual: label;
);
let Circle = class : Shape (
    export let.override label: string;
        | get.override: "circle of " + label;
);
```

See [Polymorphism](../lang/Polymorphism.md#virtual-accessors).
