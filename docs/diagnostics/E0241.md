# E0241: unterminated template or stylesheet

An inline `html` factory or `css` stylesheet needs a closing `}` after its body.

<!-- example: error: E0241 -->
```neura
let ready = html() {
    <p>Ready</p>
```

Close any quoted values, comments, and nested constructs, then write the closing `}`.

<!-- example: fragment: this step implements source framing before HTML factory parsing -->
```neura
let ready = html() {
    <p>Ready</p>
};
```
