# E0545: hooked class storage without an initializer

A declaration of a class type whose class has a `set` hook, declared or inherited, needs an initializer: without one its default nil would be an admission the source does not show. This applies to instance and static fields; a global or a local without an initializer is already an error (`E0404`). A deferred `last` binding has no default and is exempt. `= nil` is an initializer, which the hook admits when the declaration runs.

<!-- example: error: E0545 -->
```neura
let Session = class (
    | set: value;
);

let Holder = class (
    export let session: Session;
);
```

Initialize it, knowing that the setter now runs:

<!-- example: check -->
```neura
let Session = class (
    | set: value;
);

let Holder = class (
    export let session: Session = nil;
);
```
