# E0531: anonymous class uses an enclosing type parameter

An anonymous class is not generic, and it is not part of the generic function or class that encloses it, so the types of its fields cannot use that declaration's type parameters.

<!-- example: error: E0531 -->
```neura
let wrap = func<T>(value: T) -> int {
    let box: class (export let item: T;) = new;
    return 0;
};
```

Declare a generic class and use it with the type parameter:

<!-- example: check -->
```neura
let Box = class<T> (
    export let item: T;
);
let wrap = func<T>(value: T) -> Box<T> {
    let box: Box<T> = new;
    box.item = value;
    return box;
};
```

See [Anonymous classes](../lang/Types.md#anonymous-classes).
