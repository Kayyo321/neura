# E0441: a deferred 'last' binding read before it is assigned

A `last` binding declared without a value can be read only where every path to the read has assigned it. A `last` field without a value can be read in `init` only after `init` assigns it.

<!-- example: error: E0441 -->
```neura
let pick = func(flag: bool) -> int {
    last x: int;
    if (flag) {
        x = 1;
    }
    return x;
};
```

Assign it on the path that skipped the assignment:

<!-- example: check -->
```neura
let pick = func(flag: bool) -> int {
    last x: int;
    if (flag) {
        x = 1;
    } else {
        x = 0;
    }
    return x;
};
```

See [Core language](../lang/CoreLanguage.md#deferred-assignment).
