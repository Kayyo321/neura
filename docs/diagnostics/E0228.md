# E0228: malformed extension declaration or extension import

`let.extension name = func(receiver: T, ...)` declares an extension function in a file or a module, and `let.extensions alias = import:Module;` imports a module and enables its extension functions ([Modules](../lang/Modules.md#extension-sets)). The error is at the word after `let.` and names what is wrong:

- `let.extension` on something that is not a function, on a function without a parameter, in a class or a block, or with `static`;
- `let.extensions` on something that is not a module import, in a block, or with `promote`, a wildcard, `_` as the alias, `const`, or a C header.

<!-- example: error: E0228 -->
```neura
let Box = class (
    export let.extension twice = func(value: int) -> int => value * 2;
);
```

Declare the extension function in a file or a module:

<!-- example: check -->
```neura
let Numbers = module (
    export let.extension twice = func(value: int) -> int => value * 2;
    export let four = func -> int => 2.twice();
);
```

See [Modules](../lang/Modules.md#extension-sets).
