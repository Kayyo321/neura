# E0433: invalid overload group

The alternatives of an overload group have bodies, fixed arity, no type parameters, and distinct parameter types; an overload group is called directly, not used as a value.

<!-- example: error: E0433 -->
```neura
let identify = func(value: int) -> int => value
    or func(other: int32) -> bool => other == 0;
```

Give each alternative its own parameter types (`int` is `int32`):

<!-- example: check -->
```neura
let identify = func(value: int32) -> int => value
    or func(other: int64) -> bool => other == 0;
```

See [Core language](../lang/CoreLanguage.md).
