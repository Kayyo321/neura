# E0102: invalid UTF-8

A source file is UTF-8 text; a byte that does not begin or continue a valid UTF-8 sequence is rejected, even in a comment or a string.

<!-- diagnostic: not reproducible: a Markdown page cannot hold the invalid bytes; the UI test tests/ui/lexer/invalid-utf8.nra reproduces it -->

Save the file as UTF-8. Most editors convert a file from another encoding, such as Latin-1, when it is saved with an explicit encoding:

<!-- example: check -->
```neura
// Prices in euros: 5 €.
let price = 5;
```
