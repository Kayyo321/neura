# E0523: accessor on a primitive reference field

A field of a primitive reference type such as `&int` aliases storage elsewhere, and cannot have accessors.

<!-- example: error: E0523 -->
```neura
let Tracker = class (
    export let target: &int;
        | get: target;

    export let init = func(target: &int) {
        instance.target = target;
    };
);
```

Store the value in a plain field:

<!-- example: check -->
```neura
let Tracker = class (
    export let target: int = 0;
        | get: target;
);
```

See [Types](../lang/Types.md#accessors).
