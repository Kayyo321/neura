# E0301: duplicate local binding

A scope binds a name once; a second binding of the same name in the same scope is an error, whether it is a local, a destructured name, a select binding, or a match binding.

<!-- example: error: E0301 -->
```neura
let total = func() -> int {
    let count = 1;
    let count = 2;
    return count;
};
```

Assign to the first binding, or give the second one another name:

<!-- example: check -->
```neura
let total = func() -> int {
    let count = 1;
    count = 2;
    return count;
};
```

See [Core language](../lang/CoreLanguage.md).
