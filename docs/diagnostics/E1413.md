# E1413: recursive proof does not decrease

A recursive proof call must use a strictly smaller structural subterm. The diagnostic labels the recursive call that did not decrease.

<!-- example: error: E1413 -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: Reflexive(flag);
);
```

Close this equality directly, without recursion.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: {==};
);
```
