# E0497: ? outside a function that returns a Result

The postfix `?` returns an error from the innermost enclosing function or lambda, so that function's result type must be a `Result`: written, or given by a lambda's expected function type. It is never inferred from a body that contains `?`. A file or module statement, a global or field initializer, a constructor, a destructor, and a function with another result type have no such result. The error labels the function's result type, or says that the context has none.

<!-- example: error: E0497 -->
```neura
let.promote _ = import:Std.Core.Result;
let parse = func(text: string) -> Result<int> => Result<int>.Ok(1);
let read = func(text: string) -> int {
    return parse(text)?;
};
```

Return a `Result`, or handle the result with `match`:

<!-- example: check -->
```neura
let.promote _ = import:Std.Core.Result;
let parse = func(text: string) -> Result<int> => Result<int>.Ok(1);
let read = func(text: string) -> int => match (parse(text)) {
    Result.Ok(value) => value,
    Result.Err(_) => 0,
};
```
