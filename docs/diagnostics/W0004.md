# W0004: #Inline(always: true) function that cannot be inlined

`#Inline(always: true)` sets the function's inlining directive to always, which lifts the size budget of the `inline-calls` optimization pass. The pass still refuses a function that may trap, calls another function, is recursive, allocates, touches the heap or module state, or belongs to a program that uses tasks, because inlining it would change a trap's location, the frames, or the task schedule. The optimizer then warns once for the tag, with its reason. `neura check` does not optimize and does not report it; `build`, `emit-ir`, and `test` do unless `--no-optimize` is given.

<!-- example: warning: W0004 -->
```neura
#Inline(always: true)
let factorial = func(value: int64) -> int64 {
    if (value <= 1) {
        return 1;
    }
    return value * factorial(value - 1);
};
```

Inline only functions that the pass can inline, and leave the others to their call:

<!-- example: check -->
```neura
#Inline(always: true)
let is_even = func(value: int64) -> bool {
    return (value & 1) == 0;
};

let factorial = func(value: int64) -> int64 {
    if (value <= 1) {
        return 1;
    }
    return value * factorial(value - 1);
};
```
