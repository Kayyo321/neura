# E0227: malformed interpolated string

An interpolated string, `$"text {hole} text"`, is one line. Outside its holes it has the escapes of a string literal, and `{{` and `}}` are single braces. A hole is `{expression}` or `{expression:specification}`; the first `:` outside parentheses, brackets and braces begins the specification. The error names what is wrong:

- an empty hole, `{}`;
- a single `}` outside a hole, which closes nothing: double it to write a brace;
- a bracket in a hole that closes nothing, or that is not closed before the hole's `}`;
- a comment in a hole;
- a conditional at the top of a hole, whose `:` would begin the specification: parenthesize it, `{(ok ? 1 : 2)}`;
- a nested width or precision hole with a specification of its own;
- a `"` in a specification;
- interpolated strings nested deeper than eight.

A literal or a hole that the line ends is `E0103`, not this error.

<!-- example: error: E0227 -->
```neura
let ok = true;
let text = $"{ok ? 1 : 2}";
```

Parenthesize the conditional:

<!-- example: check -->
```neura
let ok = true;
let text = $"{(ok ? 1 : 2)} {{braces}}";
```
