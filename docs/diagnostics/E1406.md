# E1406: override invalidates an inherited proof

When an override replaces a function body used by an inherited proof, the compiler checks the proof against the new body. A failing check means the inherited statement needs a new proof or a corrected implementation.

<!-- example: error: E1406 -->
```neura
let Base = module (
    .Pure
    export let value = func() -> bool => true;

    export let AlwaysTrue = law (
        claim: { value() == true : bool };
    );
        | proof: {==};
);

let Derived = module:Base (
    .Pure
    export let.override value = func() -> bool => false;
);
```

Restore the behavior the inherited statement requires.

<!-- example: check -->
```neura
let Base = module (
    .Pure
    export let value = func() -> bool => true;

    export let AlwaysTrue = law (
        claim: { value() == true : bool };
    );
        | proof: {==};
);

let Derived = module:Base (
    .Pure
    export let.override value = func() -> bool => true;
);
```
