# E0482: unknown argument label

A label names a parameter of the function the call names. No parameter has the written name. The error suggests the closest name among the parameters the call has not filled yet.

<!-- example: error: E0482 -->
```neura
let schedule = func(job: string, retries: int) -> string => job;
let first = schedule("backup", retrys: 3);
```

Use the parameter's name:

<!-- example: check -->
```neura
let schedule = func(job: string, retries: int) -> string => job;
let first = schedule("backup", retries: 3);
```
