# E0267: typeof without a value or a type

`typeof(...)` takes one operand in parentheses: a value, whose type it describes, or a type. `typeof` without parentheses, empty parentheses, and an operand that has no type, such as a call of a `void` function, a module, or the name of a function that is not called, are rejected. The error is at `typeof` or at the operand.

<!-- example: error: E0267 -->
```neura
let console = import:Std.Io.Console;

let check = func { let info = typeof(console); };
```

Pass a value or a type:

<!-- example: check -->
```neura
let check = func {
    let count = 3;
    let of_value = typeof(count);
    let of_type = typeof(string);
};
```

See [Core language](../lang/CoreLanguage.md#typeof).
