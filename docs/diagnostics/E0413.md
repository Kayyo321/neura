# E0413: operator not defined for the operand type

An operator applies only to the operand types that define it: `%` and the bitwise operators to integers, ordering to numbers and strings, arithmetic to numbers of one type.

<!-- example: error: E0413 -->
```neura
let remainder: float64 = 7.5 % 2.0;
```

Use an operation that the type has, or convert the operands:

<!-- example: check -->
```neura
let remainder: int32 = 7 % 2;
```

See [Numbers](../lang/Numbers.md).
