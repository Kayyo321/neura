# E0253: malformed stylesheet

Close the indicated CSS string, comment, URL or delimiter. The diagnostic points to the token that cannot close or balance.

<!-- example: error: E0253 -->
```neura
const Local = css { .row { color: red; ] } };
```

<!-- example: fragment: stylesheet lowering is implemented after CSS parsing -->
```neura
const Local = css { .row { color: red; } };
```
