# E0505: type cannot be constructed

`new` constructs a concrete class: not an interface, not the umbrella type `class`, not a singleton, and not a class with an interface method it does not implement.

<!-- example: error: E0505 -->
```neura
let value = new class();
```

Construct a declared class:

<!-- example: check -->
```neura
let Point = class (
    export let x: int = 0;
);
let value = new Point();
```

See [Object lifecycle](../lang/ObjectLifecycle.md).
