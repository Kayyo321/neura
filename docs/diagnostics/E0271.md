# E0271: dot tag without a name or group

A dot that introduces a tag must be followed by a tag name or by `[` and a group of tags.

<!-- example: error: E0271 -->
```neura
.
let count = 1;
```

Give the tag a name:

<!-- example: check -->
```neura
.Note("Initial count")
let count = 1;
```

See [Tags](../lang/Tags.md).
