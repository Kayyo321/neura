# E0515: field is write-only outside its class

A field whose accessors include `| set:` but no `| get:` is write-only outside its class: reading it through an instance, or updating it with a compound assignment or `++` and `--`, needs a getter. Inside the declaring class the field is plain storage and stays readable.

<!-- example: error: E0515 -->
```neura
let Sink = class (
    export let level: int = 0;
        | set: level = value;
);
let sink = new Sink();
let current = sink.level;
```

Declare a getter, or only assign the field from outside:

<!-- example: check -->
```neura
let Sink = class (
    export let level: int = 0;
        | set: level = value;
        | get: level;
);
let sink = new Sink();
sink.level = 3;
let current = sink.level;
```
