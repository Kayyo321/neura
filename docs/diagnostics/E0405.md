# E0405: missing return

A function whose result type is not `void` returns a value, or traps, on every path through its body.

<!-- example: error: E0405 -->
```neura
let sign = func(value: int) -> int {
    if (value > 0) {
        return 1;
    }
};
```

Return a value on the paths that fall off the end:

<!-- example: check -->
```neura
let sign = func(value: int) -> int {
    if (value > 0) {
        return 1;
    }
    return 0;
};
```
