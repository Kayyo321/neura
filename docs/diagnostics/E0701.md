# E0701: unresolved import

An import names a module that exists: a standard library module, a module in a source root, a NeuraIR artifact, or a library that a standard module needs.

<!-- example: error: E0701 -->
```neura
let console = import:Std.Io.Consol;
```

Correct the module name; the compiler suggests a module with a similar name:

<!-- example: check -->
```neura
let console = import:Std.Io.Console;
```

See [Modules and imports](../lang/Modules.md).
