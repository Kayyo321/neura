# E1033: package cannot be built here

`neura package` wraps a built bundle for delivery on the system that runs the tool. It reports `E1033` at the target's `kind` when the request cannot be met here: a format of another system (`.dmg` is built on macOS, `.msix` on Windows), `--sign`, which Neura 0.3.0 does not do on Linux, a web target (a web bundle is delivered as its directory), a target whose bundle has not been built, or a desktop target without its `packaging.icon` or without the pinned Electron engine (`NEURA_DESKTOP_ENGINE`). Provide what the message names, or build the package on the system it is for.
