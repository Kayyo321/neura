# E0410: non-exhaustive match

A `match` on an enum without a `_` arm has an arm for every variant.

<!-- example: error: E0410 -->
```neura
let Light = enum (Red, Yellow, Green);
let wait = func(light: Light) -> int {
    return match (light) {
        Light.Red => 30,
    };
};
```

Add the missing arms, or a `_` arm last for the variants you do not list:

<!-- example: check -->
```neura
let Light = enum (Red, Yellow, Green);
let wait = func(light: Light) -> int {
    return match (light) {
        Light.Red => 30,
        Light.Yellow => 5,
        Light.Green => 0,
    };
};
```

With a wildcard:

<!-- example: check -->
```neura
let Light = enum (Red, Yellow, Green);
let wait = func(light: Light) -> int {
    return match (light) {
        Light.Red => 30,
        _ => 0,
    };
};
```
