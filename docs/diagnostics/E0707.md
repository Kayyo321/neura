# E0707: conflicting NeuraIR artifact

Artifacts and sources linked into one program must agree: one definition per file, one native library per image, the same standard library files, and no source compiled both directly and inside an artifact.

<!-- diagnostic: not reproducible: it needs two NeuraIR artifacts -->

Build the artifacts from the same sources and standard library, and pass each source once:

<!-- example: fragment: imports an artifact built separately -->
```neura
let store = import "store.nir".Store;
```

See [Modules and imports](../lang/Modules.md#prebuilt-neurair-modules).
