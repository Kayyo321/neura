# E0249: malformed control block

An HTML template uses parenthesized conditions and a key for every loop.

<!-- example: error: E0249 -->
```neura
let view = html() { @if done { <p>Done</p> } };
```

<!-- example: fragment: application form lowering is implemented after template parsing -->
```neura
let view = html() { @if (true) { <p>Done</p> } };
```
