# E0802: type without a circuit representation

Every value in the circuit needs a representation that IRtoNeuronConversion defines: an integer of a given width and signedness, a floating-point format, or another value type.

<!-- diagnostic: not reproducible: NeuraIR lowering gives every checked value a representation (it lowers byte to uint8); only hand-written NeuraIR reaches conversion without one -->

Use a sized type, such as `uint8` for a byte:

<!-- example: check -->
```neura
let program = import:Std.Program;

export let Main = module : program.Entry (
    export let.override main = func(arguments: string[]) -> program.ExitCode {
        let mask: uint8 = 1;
        return program.ExitCode.Ok;
    };
);
```

See [Numbers](../lang/Numbers.md).
