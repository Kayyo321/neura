# E1300: a type that Std.Reflect.Proxy cannot proxy

`Std.Reflect.Proxy.DynamicProxy.create<I>(handler)` makes an object that implements the interface `I` by sending every call to `handler`. The compiler synthesizes the class when it builds the program, so `I` must be an interface whose requirements are instance methods that are neither generic nor variadic. A class, an interface that requires a property or has a static requirement, and an interface with a generic or variadic method are rejected at the call of `create`.

<!-- example: error: E1300 -->
```neura
let proxies = import:Std.Reflect.Proxy.DynamicProxy;
let variants = import:Std.Reflect.Dynamic.Variant;

let Plain = class ( );

let Handler = class implements proxies.InvocationHandler (
    export let invoke = func(context: proxies.MethodCallContext) -> variants.Variant => variants.of(0 as int32);
);

let make = func -> Plain => proxies.create<Plain>(new Handler());
```

Proxy an interface of plain methods:

<!-- example: check -->
```neura
let proxies = import:Std.Reflect.Proxy.DynamicProxy;
let variants = import:Std.Reflect.Dynamic.Variant;

let Named = interface (
    export let name = func -> string;
);

let Handler = class implements proxies.InvocationHandler (
    export let invoke = func(context: proxies.MethodCallContext) -> variants.Variant => variants.of("n");
);

let make = func -> Named => proxies.create<Named>(new Handler());
```
