# E0407: wrong number of arguments

A call passes one argument per parameter, or at least one per fixed parameter when the function is variadic.

<!-- example: error: E0407 -->
```neura
let add = func(a: int, b: int) -> int => a + b;
let three = add(1);
```

Pass every argument:

<!-- example: check -->
```neura
let add = func(a: int, b: int) -> int => a + b;
let three = add(1, 2);
```

See [Core language](../lang/CoreLanguage.md).
