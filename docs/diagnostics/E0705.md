# E0705: imported file does not declare the module

An imported file declares the module its path names: `import:Shop.Cart` reads `shop/cart.nra`, which declares `Cart`.

<!-- diagnostic: not reproducible: it needs a second source file -->

Declare the module in the file, under the name the path gives:

<!-- example: check -->
```neura
export let Cart = module (
    export let size = 0;
);
```

See [Modules and imports](../lang/Modules.md).
