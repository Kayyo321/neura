# E1405: law statement cannot be overridden

An inherited law keeps its statement in every derived module, and a law declaration cannot use `let.override`.

<!-- example: error: E1405 -->
```neura
let Example = module (
    export let.override Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```

Declare a new law with `let`. Use `let.proof` when fulfilling an inherited statement.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```
