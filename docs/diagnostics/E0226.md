# E0226: default value on a parameter that takes none

A default is written `name: Type = constant` and belongs to one parameter of a named function, method or constructor. These parameters take none:

- a group of several names, `func(x, y: int = 1)`, where the default would belong to every name: split the group, `x: int, y: int = 1`;
- every parameter of a function with a variadic parameter, because which arguments form the variadic tail must not depend on what a caller leaves out;
- a primitive reference parameter (`&T`), which is bound to a place of the caller;
- a parameter whose type mentions a type parameter;
- a parameter of a lambda, which is called through a function value that carries no defaults;
- an enum payload field;
- a parameter of a host, kernel, scheduler or callback binding.

<!-- example: error: E0226 -->
```neura
let Point = class (
    export let x: int;
    export let y: int;
    export let init = func(x, y: int = 0) => set;
);
```

Give the default to one parameter:

<!-- example: check -->
```neura
let Point = class (
    export let x: int;
    export let y: int;
    export let init = func(x: int, y: int = 0) => set;
);
let origin = new Point(0);
```
