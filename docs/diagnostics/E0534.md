# E0534: anonymous class copies from separately compiled modules

Each separately compiled NeuraIR module that writes a fields-only anonymous class has its own copy of that class. A program that imports two such modules keeps both copies, and they are different types even though their fields are the same. A module compiled from source in the same program, or one that imports the other's artifact, shares a single class.

<!-- diagnostic: not reproducible: it needs two separately compiled NeuraIR artifacts -->

Declare the shape as a named class in one module, and use that class in both:

<!-- example: check -->
```neura
let Shapes = module (
    export let Point = class (
        export let x: int = 0;
        export let y: int = 0;
    );
);
```

See [Anonymous classes](../lang/Types.md#anonymous-classes) and [Modules and imports](../lang/Modules.md#prebuilt-neurair-modules).
