# E0534: untyped field in a fields-only anonymous class

The names and types of its fields are what identify a fields-only anonymous class, so each field has a type annotation.

<!-- example: error: E0534 -->
```neura
let point: class (export let x = 0;) = new;
```

Write the type of the field:

<!-- example: check -->
```neura
let point: class (export let x: int = 0;) = new;
```

A body with a method, accessors, or a `const` or `last` field is a class of its own, identified by where it is written, so its fields can take their types from their initializers:

<!-- example: check -->
```neura
let counter: class (
    export let count = 0;
        | get: count;
) = new;
```

See [Anonymous classes](../lang/Types.md#anonymous-classes).
