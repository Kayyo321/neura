# E0573: invalid interface property

An interface requires a property with `let name: T;` followed by `| get;`, and optionally `| set;`, in either order. The property declares no storage, so it takes no initializer, and its clauses have no body: the class that implements the interface supplies the value. A property is declared with `let`, never with `last`, `const` or `static`, and it needs `| get;`: a property that can only be written is not supported. An interface member written as a binding without clauses is a property missing its `| get;`.

<!-- example: error: E0573 -->
```neura
let Named = interface (
    let name: string;
        | get: "unnamed";
);
```

Write the clause without a body, and the value in the class:

<!-- example: check -->
```neura
let Named = interface (
    let name: string;
        | get;
);
let User = class implements Named (
    export let name: string = "unnamed";
);
```
