# E0401: assignment to a constant binding

A binding declared with `const` keeps the value it was initialized with; a later assignment to it, including `+=` and `++`, is an error. A binding or field declared `last` with a value is assigned once, by its declaration, so assigning it again is the same error, reported as `cannot assign twice`. A `last` binding declared without a value has its own rules ([E0440](E0440.md)).

<!-- example: error: E0401 -->
```neura
let next = func() -> int {
    const start = 1;
    start = 2;
    return start;
};
```

If the value is meant to change, declare the binding with `let`:

<!-- example: check -->
```neura
let next = func() -> int {
    let start = 1;
    start = 2;
    return start;
};
```

If it is not, bind the new value to a name of its own:

<!-- example: check -->
```neura
let next = func() -> int {
    const start = 1;
    const restart = start + 1;
    return restart;
};
```

See [Core language](../lang/CoreLanguage.md).
