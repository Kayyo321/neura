# E0401: assignment to a constant binding

A binding declared with `const` keeps the value it was initialized with; a later assignment to it, including `+=` and `++`, is an error.

<!-- example: error: E0401 -->
```neura
let next = func() -> int {
    const start = 1;
    start = 2;
    return start;
};
```

If the value is meant to change, declare the binding with `let`:

<!-- example: check -->
```neura
let next = func() -> int {
    let start = 1;
    start = 2;
    return start;
};
```

If it is not, bind the new value to a name of its own:

<!-- example: check -->
```neura
let next = func() -> int {
    const start = 1;
    const restart = start + 1;
    return restart;
};
```
