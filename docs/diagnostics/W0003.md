# W0003: discarded result of a #NoDiscard call

An expression statement that calls a `#NoDiscard` function or method, or any function whose result type is a `#NoDiscard` class, interface, or enum, discards a result the declaration says must be used. Bind it to `_` to discard it on purpose.

<!-- example: warning: W0003 -->
```neura
let Files = module (
    #NoDiscard(reason: "the result says whether the write happened")
    export let write = func(text: string) -> bool {
        return text.byte_length > 0;
    };
);

let save = func() -> void {
    Files.write("data");
};
```

Use the result, or discard it on purpose with `let _ =`:

<!-- example: check -->
```neura
let Files = module (
    #NoDiscard(reason: "the result says whether the write happened")
    export let write = func(text: string) -> bool {
        return text.byte_length > 0;
    };
);

let save = func() -> void {
    let _ = Files.write("data");
};
```
