# E0782: unknown kernel or kernel ABI version

A kernel binding must name a kernel, at an ABI version, that this compiler's kernel table contains.

<!-- diagnostic: not reproducible: only a standard library module may declare a kernel binding -->

Use a name and version from [Kernels](../runtime/Kernels.md), or regenerate the declarations with `scripts/gen-kernels.py` after changing a kernel header:

<!-- example: fragment: a declaration inside a standard library module -->
```neura
export let crc32 = func(bytes: uint8[list]) -> uint32 kernel("neura.digest.crc32", 1);
```

See [Kernels](../runtime/Kernels.md).
