# E0202: unexpected token

The parser found a token where the grammar requires another one, such as `:` between a parameter's name and its type, or a name after `let`.

<!-- example: error: E0202 -->
```neura
let scale = func(int value) -> int => value * 2;
```

Write the construct as the grammar has it. A parameter is its name, `:`, and its type:

<!-- example: check -->
```neura
let scale = func(value: int) -> int => value * 2;
```

See [Core language](../lang/CoreLanguage.md).
