# E0900: unknown tag

A tag must be one of the registered tags that `neura tags` lists. Tag names are PascalCase, and a misspelled name is an error rather than being ignored. When a registered name is close, the error suggests it, and `neura check --fix` applies the suggestion.

<!-- example: error: E0900 -->
```neura
#Depricated(use_instead: "count")
let old_count = func() -> int32 {
    return 1;
};
```

Spell the tag as registered:

<!-- example: check -->
```neura
#Deprecated(use_instead: "count")
let old_count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
