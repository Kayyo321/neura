# E0478: return with a value in a generator

A generator's values come from `yield`. `return;` ends the generator, as the end of its body does, and `return value;` is rejected. The suggested edit, `yield value; return;`, changes what the generator produces, so it is offered as a suggestion that may be incorrect.

<!-- example: error: E0478 -->
```neura
let numbers = iterator() -> int {
    yield 1;
    return 2;
};
```

Yield the value, then end the generator:

<!-- example: check -->
```neura
let numbers = iterator() -> int {
    yield 1;
    yield 2;
    return;
};
```
