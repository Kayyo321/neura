# E0902: unknown or misplaced tag argument

A tag takes the arguments its signature names, positionally in that order or as `name: value`. A name it does not have, an argument after the last one it takes, and a positional argument after a named one are errors.

<!-- example: error: E0902 -->
```neura
#Deprecated(since: "0.1.0")
let old_count = func() -> int32 {
    return 1;
};
```

Use the argument's name from the signature, which `neura tags Deprecated` prints:

<!-- example: check -->
```neura
#Deprecated(as_of: "0.1.0")
let old_count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
