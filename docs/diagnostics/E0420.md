# E0420: target-typed new without a class to construct

`new` without a class constructs the type that its value must have, so that type must be known and must be a concrete class: not an interface, the umbrella type `class`, a singleton, a type parameter, or a type that is not a class.

<!-- example: error: E0420 -->
```neura
let Point = class (
    export let x: int = 0;
);
let origin = new;
```

Give the binding a type, or name the class after `new`:

<!-- example: check -->
```neura
let Point = class (
    export let x: int = 0;
);
let origin: Point = new;
let other = new Point();
```

The expected type comes from the annotation of the binding or field that `new` initializes, the place an assignment stores to, the declared result type of a `return`, the parameter of a call argument, and the element type of a typed collection. See [Object lifecycle](../lang/ObjectLifecycle.md#target-typed-new).
