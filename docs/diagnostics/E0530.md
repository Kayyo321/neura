# E0530: anonymous class field initializer that never runs

A fields-only anonymous class takes its field initializers from the class body written as the annotation of the `let`, `const`, or `last` binding that a `new` initializes. A field initializer written in any other occurrence, such as a parameter, a result type, or an element type, would never run.

<!-- example: error: E0530 -->
```neura
let describe = func(point: class (export let x: int = 0;)) -> int {
    return point.x;
};
```

Leave the initializer out where the class is only a type, and write it where a binding is initialized with `new`:

<!-- example: check -->
```neura
let describe = func(point: class (export let x: int;)) -> int {
    return point.x;
};
let origin: class (export let x: int = 0;) = new;
let x = describe(origin);
```

See [Anonymous classes](../lang/Types.md#anonymous-classes).
