# E0222: yield outside a generator

`yield` is a statement only directly in the body of an `iterator`. The body of a `func` or lambda nested in a generator is not the generator's body, and an ordinary function has none. There, `yield` followed by a name, a literal or `new` is rejected; in any other position `yield` is an ordinary name. The error labels the enclosing function.

<!-- example: error: E0222 -->
```neura
let plain = func(value: int) -> void {
    yield value;
};
```

Make the function a generator:

<!-- example: check -->
```neura
let values = iterator(value: int) -> int {
    yield value;
};
```

See [Core language](../lang/CoreLanguage.md#generators).
