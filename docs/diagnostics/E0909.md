# E0909: tags without a declaration

Tags precede a declaration: a `let` or `const` binding, which includes functions, classes, modules, interfaces, and enums, a member, an enum variant, or a parameter. They cannot precede a statement such as a loop, a destructuring declaration, or the discard name `_`.

<!-- example: error: E0909 -->
```neura
let count_to = func(limit: int32) -> int32 {
    let total: int32 = 0;
    #Todo("use a closed form")
    while (total < limit) {
        total += 1;
    }
    return total;
};
```

Put the tag on the declaration that contains the statement:

<!-- example: check -->
```neura
#Todo("use a closed form")
let count_to = func(limit: int32) -> int32 {
    let total: int32 = 0;
    while (total < limit) {
        total += 1;
    }
    return total;
};
```
