# E0423: expression is not callable

Only a function, a function value, or a method can be called.

<!-- example: error: E0423 -->
```neura
let count = 3;
let twice = count(2);
```

Call a function:

<!-- example: check -->
```neura
let count = func(times: int) -> int => times * 3;
let twice = count(2);
```

See [Core language](../lang/CoreLanguage.md).
