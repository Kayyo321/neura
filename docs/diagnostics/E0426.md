# E0426: tuple arity mismatch

A tuple has a fixed number of elements: a tuple literal and a destructuring declaration have one element per element of the tuple type.

<!-- example: error: E0426 -->
```neura
let pair = func() -> [int, bool] {
    return [1, true];
};
let [value] = pair();
```

Bind every element, discarding the ones you do not need:

<!-- example: check -->
```neura
let pair = func() -> [int, bool] {
    return [1, true];
};
let [value, _] = pair();
```
