# E0450: a list literal without new

A list is constructed with `new`. A bare list literal or range is an array, so where a list is expected, such as a binding annotated with a list type, a field, an argument, a result, or an element of another list, the literal needs `new`. `neura check --fix` inserts it and keeps the literal, its comments and its order.

<!-- example: error: E0450 -->
```neura
let names: string[list] = ["Ada", "Lin"];
```

Construct the list with `new`:

<!-- example: check -->
```neura
let names: string[list] = new(["Ada", "Lin"]);
let empty: string[list] = new;
let counts: int[list] = new(0 .. 4);
let rows: int[list][list] = new([new([1, 2]), new([3])]);
let typed = new int[list]([1, 2, 3]);
let array: int[] = [1, 2, 3];
```

A bare literal where an array is expected stays an array. Each nested list needs its own `new`. A list that is already a value, such as the result of a call, needs none.

See [Arrays and lists](../lang/Collections.md#construction-and-length).
