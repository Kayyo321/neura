# E0266: is not narrowing inside an && chain

`if (x is not name: T) A else B` binds `name` in `B`, where the test is known to have failed. Inside an `&&` chain, the `else` branch runs when any conjunct is false, so nothing proves that the type test failed, and the narrowing is rejected. The error is at `not`.

<!-- example: error: E0266 -->
```neura
let Shape = class ( export let sides: int = 0; );
let Circle = class : Shape ( export let radius: int = 1; );

let radius = func(shape: Shape, ready: bool) -> int {
    if (shape is not circle: Circle && ready) {
        return 0;
    }
    return 1;
};
```

Make `is not` the whole condition, or test with `is` and bind in the true branch:

<!-- example: check -->
```neura
let Shape = class ( export let sides: int = 0; );
let Circle = class : Shape ( export let radius: int = 1; );

let radius = func(shape: Shape, ready: bool) -> int {
    if (shape is circle: Circle && ready) {
        return circle.radius;
    }
    return 0;
};
```
