# E1408: invalid witness for a constructor or contradiction proof

A contradiction needs evidence of impossibility, such as an equality between distinct constructors. An `absurd` step needs a witness of `Empty`. An `inject` step needs an equality between constructors with corresponding fields.

<!-- example: error: E1408 -->
```neura
let Example = module (
    export let Reflexive = law (
        given identity: { true == true : bool };
        claim: { true == true : bool };
    );
        | proof: {
            absurd identity;
        };
);
```

Use reflexivity when the goal is a reflexive equality.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        given identity: { true == true : bool };
        claim: { true == true : bool };
    );
        | proof: {==};
);
```
