# E1100: string chain operand that is not a string

A string chain `a .. b .. c` joins text: every operand must be a `string`, and nothing is converted implicitly. An operand of another type, including an integer before or after a string, is rejected at that operand. Every binary operator binds more tightly than `..`, so `a .. b == c` joins the `bool` of `b == c` and is rejected too.

<!-- example: error: E1100 -->
```neura
let label = func(count: int) -> string => "count: " .. count;
```

Convert the value to text with `to_string()`, or parenthesize the chain when an operator should apply to the joined text:

<!-- example: check -->
```neura
let label = func(count: int) -> string => "count: " .. count.to_string();
let same = func(a: string, b: string, c: string) -> bool => (a .. b) == c;
```

See [Core language](../lang/CoreLanguage.md#string-chains).
