# E0503: invalid inheritance

A class extends one non-generic class, an interface extends interfaces, a module extends a module that is not constant, and a singleton is not extended; inheritance cannot form a cycle.

<!-- example: error: E0503 -->
```neura
let Box = class<T> (
    export let value: T;
);
let Labeled = class : Box (
);
```

Hold the generic class in a field instead of extending it:

<!-- example: check -->
```neura
let Box = class<T> (
    export let value: T;
);
let Labeled = class (
    export let box: Box<string>;
    export let label: string = "";
);
```

See [Polymorphism](../lang/Polymorphism.md).
