# E1421: law feature unavailable

The release supports module-level proofs over the Phase 1 types. Features such as generic laws, independent verification, or trap propositions require a later phase.

<!-- example: error: E1421 -->
```neura
let Example = module (
    let Generic = law<T> (
        for value: T;
        claim: { value == value : T };
    );
        | proof: {==};
);
```

State a law over a supported concrete type.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: {==};
);
```

See [the laws design](../design/Laws031.md).
