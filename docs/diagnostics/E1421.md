# E1421: law feature unavailable

The release supports module-level proofs over the Phase 1 types. Generic laws, trap and outcome propositions, and trusted standard library axioms require later phases. An axiom in user source reports [E1420](E1420.md).

<!-- example: error: E1421 -->
```neura
let Example = module (
    let Generic = law<T> (
        for value: T;
        claim: { value == value : T };
    );
        | proof: {==};
);
```

State a law over a supported concrete type.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: {==};
);
```

See [the laws design](../design/Laws031.md).
