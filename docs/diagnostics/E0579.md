# E0579: unknown or misplaced derivation

Declare a codec as a member of a file or module. Import `Std.Encoding.Json` and use its `Codec<T>` declaration as the generator. A user interface or class with the same name has a different identity.

<!-- example: error: E0579 -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.JsonValue<User>;
```

<!-- example: check -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<User>;
```
