# E0205: declaration without a type or an initializer

A binding needs a type annotation, an initializer, or both; with neither, its type is unknown.

<!-- example: error: E0205 -->
```neura
let count;
```

Give it an initial value, from which its type is inferred, or a type as well:

<!-- example: check -->
```neura
let count = 0;
let limit: int64 = 100;
```

See [Core language](../lang/CoreLanguage.md).
