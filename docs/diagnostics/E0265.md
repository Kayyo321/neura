# E0265: narrowing binding outside the condition of an if

A narrowing `x is name: T` binds `name` only where the test is known to have succeeded: as the whole condition of an `if` (an `else if` included), or as an operand of the `&&` chain that is the whole condition, outside parentheses. Anywhere else, including under `!` or `not`, as an operand of `||`, of `? :` or of a call, and in the conditions of `while`, `do` and `for`, the binding is rejected. The error is at the name.

<!-- example: error: E0265 -->
```neura
let Shape = class ( export let sides: int = 0; );
let Circle = class : Shape ( export let radius: int = 1; );

let radius = func(shape: Shape, fallback: bool) -> int {
    if (shape is circle: Circle || fallback) {
        return 1;
    }
    return 0;
};
```

Make the narrowing a top-level conjunct, or test with `is` and narrow in an `if` inside. In a loop, narrow inside the body:

<!-- example: check -->
```neura
let Shape = class ( export let sides: int = 0; );
let Circle = class : Shape ( export let radius: int = 1; );

let total = func(shapes: Shape[]) -> int {
    let sum = 0;
    for (let shape: Shape in shapes) {
        if (shape is circle: Circle && circle.radius > 0) {
            sum = sum + circle.radius;
        }
    }
    return sum;
};
```
