# E0472: defer or using outside a function

`defer` and `using` run their work when a block of a function body is left. File-level statements are not in a function body, so neither statement is accepted there. Inside a function, a lambda, a constructor or a destructor, both are accepted at any block depth.

<!-- example: error: E0472 -->
```neura
let cleanup = func() -> void {};
defer cleanup();
```

Move the statements into a function:

<!-- example: check -->
```neura
let cleanup = func() -> void {};
let run = func() -> void {
    defer cleanup();
};
```

See [Core language](../lang/CoreLanguage.md#defer).
