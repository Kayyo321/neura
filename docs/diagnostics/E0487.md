# E0487: invalid nameof operand

`nameof(path)` is the declared name of the declaration a path resolves to. Its operand is a name or a dotted path, with type arguments where a generic type is applied: a local, a parameter, a function or an overload group, a field, a method, a class, an interface, an enum, a variant, a module, a type parameter, or an import alias. A built-in type has no declaration to name, and a literal, a call, an index or any other expression is not a name.

<!-- example: error: E0487 -->
```neura
let total = func -> int => 1;
let text = nameof(total());
```

Name the declaration:

<!-- example: check -->
```neura
let total = func -> int => 1;
let text = nameof(total);
```

See [Core language](../lang/CoreLanguage.md#nameof).
