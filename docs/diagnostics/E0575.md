# E0575: invalid accessor override

A subclass overrides a virtual accessor with `export let.override name: T;` followed by `| get.override:`, `| set.override:` or both. The declaration names an exported field of a base class, repeats its type exactly, takes no initializer and declares no field. Each `.override` clause needs a slot of its kind in a base: a clause marked `.virtual`, or one that already overrides one. An ordinary field's clause cannot be `.override`, and every clause under `let.override` must be.

<!-- example: error: E0575 -->
```neura
let Shape = class (
    export let label: string = "shape";
        | get: label;
);
let Circle = class : Shape (
    export let.override label: string;
        | get.override: "circle";
);
```

Mark the base clause `.virtual`:

<!-- example: check -->
```neura
let Shape = class (
    export let label: string = "shape";
        | get.virtual: label;
);
let Circle = class : Shape (
    export let.override label: string;
        | get.override: "circle";
);
```

See [Polymorphism](../lang/Polymorphism.md#virtual-accessors).
