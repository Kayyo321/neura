# E0570: invalid record declaration

A record is declared by its components, each written `name: Type`. A component takes no default value and no `export`, `let`, `last`, `const` or `static`: every component becomes an exported `last` field and a parameter of the generated constructor. A record needs at least one component, and a component cannot be named `init`, `deinit`, `equals`, `hash_code`, `to_string` or `instance`, the names of the members a record already has, nor take the name of its record, which the generated `equals` uses for the type.

<!-- example: error: E0570 -->
```neura
let Point = record (x: int = 0, y: int);
```

Remove the part, or declare a class when the type needs it:

<!-- example: check -->
```neura
let Point = record (x: int, y: int);
let origin = new Point(0, 0);
```

See [Types](../lang/Types.md#records).
