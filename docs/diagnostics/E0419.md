# E0419: explicit type arguments required

A generic function used as a value, and a variant of a generic enum, need explicit type arguments: the compiler does not infer them there.

<!-- example: error: E0419 -->
```neura
let identity = func<T>(value: T) -> T => value;
let same = identity;
```

Call it with type arguments, in a function value of the type you need:

<!-- example: check -->
```neura
let identity = func<T>(value: T) -> T => value;
let same = func(value: int32) -> int32 => identity<int32>(value);
```

See [Polymorphism](../lang/Polymorphism.md).
