# E0419: explicit type arguments required

A generic function used as a value, and a variant of a generic enum, need explicit type arguments: the compiler does not infer them there. A call of a generic function infers its type arguments from its arguments and from the type it is expected to have, and is this error when a type parameter is left unsolved, such as one that only an empty collection literal, `nil` or a result without an expected type would give.

<!-- example: error: E0419 -->
```neura
let empty = func<T>() -> T[list] => new;
let use = func {
    let items = empty();
};
```

Give the call an expected type, or write the type arguments:

<!-- example: check -->
```neura
let empty = func<T>() -> T[list] => new;
let use = func {
    let items: int[list] = empty();
    let names = empty<string>();
};
```

A function value is not inferred:

<!-- example: error: E0419 -->
```neura
let identity = func<T>(value: T) -> T => value;
let same = identity;
```

Call it with type arguments, in a function value of the type you need:

<!-- example: check -->
```neura
let identity = func<T>(value: T) -> T => value;
let same = func(value: int32) -> int32 => identity<int32>(value);
```
