# E0243: nesting a browser would repair

Put each element where a browser leaves it in the tree without moving nodes or inserting tags.

<!-- example: error: E0243 -->
```neura
let view = html() { <table><tr></tr></table> };
```

<!-- example: check -->
```neura
let view = html() { <table><tbody><tr></tr></tbody></table> };
```
