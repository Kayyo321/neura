# E0452: a primitive borrow escapes its owner

A reference to a local or value parameter ends with that binding's region.

<!-- example: error: E0452 -->
```neura
let escape = func(value: int) -> &int {
    return value;
};
```

Keep the borrow in the activation, or take the address of a field in an explicitly constructed owner.

<!-- example: check -->
```neura
let Cell = class (
    export let value: int = 0;
);

let make = func -> &int {
    last cell: Cell = new;
    return cell.value;
};
```
