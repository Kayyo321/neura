# E0915: unknown warning in a tag

`#Allow` and `#Deny` name warnings by name (`deprecated`, with `_` for `-`) or by code (`W0001`). `neura explain --list` prints the warnings with their names.

<!-- example: error: E0915 -->
```neura
#Allow(deprecate)
let count = func() -> int32 {
    return 1;
};
```

Name a warning that exists:

<!-- example: check -->
```neura
#Allow(deprecated)
let count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
