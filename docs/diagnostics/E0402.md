# E0402: invalid assignment target

An assignment stores into a mutable binding, a field, or an element; a lambda cannot reassign a binding it captured, because it holds a copy.

<!-- example: error: E0402 -->
```neura
let counter = func() -> func() -> int {
    let count = 0;
    return func() -> int {
        count = count + 1;
        return count;
    };
};
```

Keep the changing state in an object that the lambda captures; the lambda and its creator share the object:

<!-- example: check -->
```neura
let Count = class (
    export let value: int = 0;
);
let counter = func() -> func() -> int {
    let count = new Count();
    return func() -> int {
        count.value = count.value + 1;
        return count.value;
    };
};
```
