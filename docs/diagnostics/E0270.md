# E0270: string literal escapes that are not valid UTF-8

A string holds UTF-8 text. A `\xHH` escape writes one byte, so the bytes of a string literal's escapes and characters must together form valid UTF-8: `"\xC3\xA9"` is `"é"`. A literal whose bytes are not valid UTF-8, such as a lone `"\xE9"`, is rejected at the literal, with a label at the escape where the first invalid sequence starts.

<!-- example: error: E0270 -->
```neura
let accent = "caf\xE9";
```

Write the code point with a Unicode escape, or give every byte of its UTF-8 sequence:

<!-- example: check -->
```neura
let accent = "caf\u{E9}";
let same = "caf\xC3\xA9";
```

For bytes that are not text, use a `byte[]` instead of a string.

See [Core language](../lang/CoreLanguage.md#escapes).
