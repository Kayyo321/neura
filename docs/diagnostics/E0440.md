# E0440: a deferred 'last' binding assigned twice

A `last` binding declared without a value, `last x: T;`, is assigned exactly once. An assignment on a path where it may already be assigned is an error, and so is `+=` or `++` after its assignment.

<!-- example: error: E0440 -->
```neura
let main = func() -> int {
    last x: int;
    x = 10;
    x = 20;
    return x;
};
```

Assign it once on each path:

<!-- example: check -->
```neura
let main = func(flag: bool) -> int {
    last x: int;
    if (flag) {
        x = 10;
    } else {
        x = 20;
    }
    return x;
};
```

If the value is meant to change, declare it with `let` and an initial value:

<!-- example: check -->
```neura
let main = func() -> int {
    let x: int = 10;
    x = 20;
    return x;
};
```
