# E1024: entry module without the required entry

A target's `entry` names the module the bundle starts. In Neura 0.3.0 the entry is a program module (`module:program.Entry` with `main`) in a file of the target's package: a package root `ui` holds the module `Ui.Main` in `ui/main.nra`, as an import root would. `neura build --target` reports `E1024` at the `entry` value when no such file exists in the package. The `start` and `serve` entry functions of the project design are not checked yet.

```toml

kind = "web"
package = "ui"
entry = "Ui.Main"
capabilities = ["ui"]
```
