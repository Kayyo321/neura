# E0104: invalid escape or character in a string literal

Inside a string literal, a backslash starts one of the escapes `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"`, `\xHH` with exactly two hexadecimal digits, and `\u{H}` ([escapes](../lang/CoreLanguage.md#escapes)); any other escape, a `\x` without two hexadecimal digits, and a raw null byte are errors. A malformed `\u` escape is [E0268](E0268.md) or [E0269](E0269.md).

<!-- example: error: E0104 -->
```neura
let folder = "C:\data";
```

Escape the backslash itself:

<!-- example: check -->
```neura
let folder = "C:\\data";
```

See [Core language](../lang/CoreLanguage.md).
