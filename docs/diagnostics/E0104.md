# E0104: invalid escape or character in a string literal

Inside a string literal, a backslash starts one of the escapes `\n`, `\r`, `\t`, `\\`, and `\"`; any other escape, and a null byte, are errors.

<!-- example: error: E0104 -->
```neura
let folder = "C:\data";
```

Escape the backslash itself:

<!-- example: check -->
```neura
let folder = "C:\\data";
```

See [Core language](../lang/CoreLanguage.md).
