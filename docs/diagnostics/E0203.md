# E0203: unclosed delimiter

Every `(`, `[`, and `{` needs its matching closing delimiter; the error points where the closer was expected and labels the opening one.

<!-- example: error: E0203 -->
```neura
let total = (1 + 2;
```

Close the delimiter where the expression it groups ends:

<!-- example: check -->
```neura
let total = (1 + 2);
```

See [Core language](../lang/CoreLanguage.md).
