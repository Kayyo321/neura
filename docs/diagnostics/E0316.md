# E0316: extension function used without a call

An extension function may be called as a member of its receiver, `value.name(...)`, but `value.name` without a call is not a value: an extension function is not a bound method.

<!-- example: error: E0316 -->
```neura
let Texts = module (
    export let.extension shout = func(text: string) -> string => text + "!";
    export let loud = "a".shout;
);
```

Call it, or use the function itself as a value:

<!-- example: check -->
```neura
let Texts = module (
    export let.extension shout = func(text: string) -> string => text + "!";
    export let loud = "a".shout();
    export let function: func(string) -> string = shout;
);
```

See [Modules](../lang/Modules.md#extension-sets).
