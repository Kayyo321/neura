# E0907: conflicting tags

Some tags contradict each other on one declaration: `#Inline` and `#NoInline`, `#Final` and `#Sealed`, `#Hot` and `#Cold`, `#Likely` and `#Unlikely`, `#Stable` and `#Experimental`, `#ThreadSafe`, `#Immutable`, or `#Synchronized` and `#NotThreadSafe`, `#Blocking` and `#NonBlocking`, `#Unroll` and `#NoUnroll`, and an `#Allow` and a `#Deny` of the same warning.

<!-- example: error: E0907 -->
```neura
#[Inline(always: true), NoInline]
let twice = func(value: int32) -> int32 {
    return value + value;
};
```

Keep the one you mean:

<!-- example: check -->
```neura
#NoInline
let twice = func(value: int32) -> int32 {
    return value + value;
};
```
