# E1012: not a class of the CSS module

`class_name` and `keyframes_name` take one string literal that names a class or a keyframes rule declared in the `css.module` constant they are called on. The compiler replaces the call with the scoped name, so the argument cannot be computed at run time.

<!-- example: error: E1012 -->
```neura
const Local = css.module { .row { color: red; } };

let name = Local.class_name("rwo");
```

<!-- example: check -->
```neura
const Local = css.module { .row { color: red; } };

let name = Local.class_name("row");
```
