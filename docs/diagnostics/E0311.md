# E0311: reserved name

The module namespace `Std` belongs to the standard library; a program cannot declare a module named `Std`.

<!-- example: error: E0311 -->
```neura
let Std = module (
    export let version = 1;
);
```

Name the module after the program:

<!-- example: check -->
```neura
let Shop = module (
    export let version = 1;
);
```

See [Modules and imports](../lang/Modules.md).
