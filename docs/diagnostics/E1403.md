# E1403: proof leaves a goal undischarged

A proof must close every goal on every reachable branch. Read the remaining goal and the hypotheses in the diagnostic before adding the missing step.

<!-- example: error: E1403 -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {};
);
```

Close the equality with reflexivity.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```
