# E0207: misplaced variadic parameter

A variadic parameter (`...`) collects the remaining arguments, so it is the last parameter, and only a named function declares one.

<!-- example: error: E0207 -->
```neura
let log = func(parts: ..., level: int) {};
```

Move the variadic parameter last:

<!-- example: check -->
```neura
let log = func(level: int, parts: ...) {};
```

See [Core language](../lang/CoreLanguage.md).
