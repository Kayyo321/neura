# E0415: invalid conversion

`as` converts between numeric types, between an enum and its integer value, and through a declared cast; `is` tests class reference types. Other conversions do not exist.

<!-- example: error: E0415 -->
```neura
let flag: int32 = true as int32;
```

Write the conversion as an expression of its own:

<!-- example: check -->
```neura
let on = true;
let flag: int32 = on ? 1 : 0;
```

See [Types](../lang/Types.md).
