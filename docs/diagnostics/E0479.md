# E0479: escaping capturing generator without new

A generator that reads outer bindings keeps them in its state, which lives as long as the sequences it makes. Like a capturing function value, a capturing generator that leaves the call that creates it, by being returned, stored or retained, is written with `new`, so that it owns its captures instead of borrowing them from that call's frame. A generator that captures nothing needs no `new`.

<!-- example: error: E0479 -->
```neura
let sequence = import:Std.Collections.Sequence;
let make = func(base: int) -> func() -> sequence.Sequence<int> {
    return iterator() -> int {
        yield base;
    };
};
```

Construct an owned generator:

<!-- example: check -->
```neura
let sequence = import:Std.Collections.Sequence;
let make = func(base: int) -> func() -> sequence.Sequence<int> {
    return new iterator() -> int {
        yield base;
    };
};
```

See [Core language](../lang/CoreLanguage.md#generators) and [`E0453`](E0453.md), the same rule for function values.
