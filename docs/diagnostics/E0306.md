# E0306: use before declaration

A top-level statement or initializer runs in source order, so it cannot read a binding of the same file or module that is declared after it.

<!-- example: error: E0306 -->
```neura
let doubled = limit * 2;
let limit = 10;
```

Move the declaration above its first use:

<!-- example: check -->
```neura
let limit = 10;
let doubled = limit * 2;
```

A function body can use a later declaration, because it runs only when it is called:

<!-- example: check -->
```neura
let doubled = func() -> int => limit * 2;
let limit = 10;
```
