# E0524: reference to a field with accessors

Outside its class, a field with accessors is read and written only through its getter and setter, so a primitive reference such as an `&int` parameter cannot alias its storage.

<!-- example: error: E0524 -->
```neura
let bump = func(target: &int) {
    target += 1;
};
let Counter = class (
    export let count: int = 0;
        | get: count;
        | set: count = value;
);
let counter = new Counter();
bump(counter.count);
```

Copy the value into a local, pass that, and assign it back:

<!-- example: check -->
```neura
let bump = func(target: &int) {
    target += 1;
};
let Counter = class (
    export let count: int = 0;
        | get: count;
        | set: count = value;
);
let counter = new Counter();
let count = counter.count;
bump(count);
counter.count = count;
```
