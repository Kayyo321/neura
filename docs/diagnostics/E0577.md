# E0577: ambiguous static requirement

`T.name(...)` calls the static requirement `name` of the bounds of the type parameter `T`. When two bounds require a function of that name with the same signature, they are one requirement; with different signatures, the call cannot choose.

<!-- example: error: E0577 -->
```neura
let Additive = interface<T> (
    static let zero = func() -> T;
);
let Counted = interface<T> (
    static let zero = func() -> int;
);
let start = func<T: [Additive<T>, Counted<T>]>() -> T => T.zero();
```

Call it through one bound only, or rename one of the requirements:

<!-- example: check -->
```neura
let Additive = interface<T> (
    static let zero = func() -> T;
);
let Counted = interface<T> (
    static let none = func() -> int;
);
let start = func<T: [Additive<T>, Counted<T>]>() -> T => T.zero();
```

See [Polymorphism](../lang/Polymorphism.md#static-interface-requirements).
