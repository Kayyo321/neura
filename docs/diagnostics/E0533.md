# E0533: new without the field initializers of an anonymous class

A field initializer of a fields-only anonymous class belongs to the class body where it is written, not to the type. A target-typed `new` runs the initializers of the body in the annotation of the binding it initializes. Where the type arrives without that body, as in an assignment to a binding whose body has initializers, `new` cannot tell which initializers to run.

<!-- example: error: E0533 -->
```neura
let point: class (export let x: int = 1;) = new;
let reset = func() {
    point = new;
};
```

Initialize a new binding with `new`, or write the body after `new`:

<!-- example: check -->
```neura
let point: class (export let x: int = 1;) = new;
let reset = func() {
    let fresh: class (export let x: int = 1;) = new;
    point = fresh;
    point = new class (export let x: int = 1;)();
};
```

See [Anonymous classes](../lang/Types.md#anonymous-classes).
