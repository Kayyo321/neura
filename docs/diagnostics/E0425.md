# E0425: type cannot be inferred

`nil` and an empty collection literal have no type of their own; they need a context that gives one, such as an annotation.

<!-- example: error: E0425 -->
```neura
let names = [];
```

Annotate the binding:

<!-- example: check -->
```neura
let names: string[list] = [];
```

See [Types](../lang/Types.md).
