# E0913: override of a final method

A method marked `#Final` cannot be overridden in a derived class.

<!-- example: error: E0913 -->
```neura
let Shape = class (
    #Final
    export let sides = func() -> int32 {
        return 0;
    };
);

let Square = class:Shape (
    export let.override sides = func() -> int32 {
        return 4;
    };
);
```

Leave the method alone, or give the derived method another name:

<!-- example: check -->
```neura
let Shape = class (
    #Final
    export let sides = func() -> int32 {
        return 0;
    };
);

let Square = class:Shape (
    export let corner_count = func() -> int32 {
        return 4;
    };
);
```
