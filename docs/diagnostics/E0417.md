# E0417: wrong number of type arguments

A generic declaration that is given type arguments takes exactly as many as it has type parameters, and a non-generic type or function takes none. A call of a generic function may leave all of them out, and then [infers](../lang/Polymorphism.md#type-argument-inference) them; it cannot write only some.

<!-- example: error: E0417 -->
```neura
let pair = func<A, B>(a: A, b: B) -> B => b;
let use = func() -> string {
    return pair<int32>(3, "three");
};
```

Pass every type argument, or none:

<!-- example: check -->
```neura
let pair = func<A, B>(a: A, b: B) -> B => b;
let use = func() -> string {
    return pair<int32, string>(3, "three") + pair(3, "three");
};
```

See [Polymorphism](../lang/Polymorphism.md).
