# E0417: wrong number of type arguments

A generic declaration takes exactly as many type arguments as it has type parameters, and a non-generic type or function takes none.

<!-- example: error: E0417 -->
```neura
let identity = func<T>(value: T) -> T {
    return value;
};
let use = func() -> int32 {
    return identity(3);
};
```

Pass the type arguments:

<!-- example: check -->
```neura
let identity = func<T>(value: T) -> T {
    return value;
};
let use = func() -> int32 {
    return identity<int32>(3);
};
```

See [Polymorphism](../lang/Polymorphism.md).
