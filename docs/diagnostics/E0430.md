# E0430: value is not iterable

A for-each loop iterates over an array, a list, or a value whose type implements `Iterable<T>`.

<!-- example: error: E0430 -->
```neura
let total = func(count: int32) -> int32 {
    let sum = 0;
    for (let item in count) {
        sum = sum + item;
    }
    return sum;
};
```

Iterate over a range or a collection:

<!-- example: check -->
```neura
let total = func(count: int32) -> int32 {
    let sum = 0;
    for (let item in 0 .. count) {
        sum = sum + item;
    }
    return sum;
};
```

See [Collections](../lang/Collections.md).
