# E1301: a value a Std.Reflect dynamic value cannot hold

A `Std.Reflect.Dynamic.Variant` holds a value of any type of the program, keeping a value that `any` cannot hold in a box on the heap. Three kinds of value cannot be moved there: an array, which lives in its region, and any tuple, list or enum that contains one; a scope-bound value such as a `Task` or a `Scope`; and a primitive reference `&T`. Packing one, or unpacking to one, is rejected at the call that reaches the library function, with the type it was given.

<!-- example: error: E1301 -->
```neura
let variants = import:Std.Reflect.Dynamic.Variant;

let hold = func(values: int32[]) -> bool => variants.of(values).is_nil();
```

Copy the elements into a list and reflect the list:

<!-- example: check -->
```neura
let variants = import:Std.Reflect.Dynamic.Variant;

let hold = func(values: int32[]) -> int {
    last copied: int32[list] = new;
    for (let value in values) {
        copied.append(value);
    }
    return variants.of(copied).length();
};
```

A descriptor of an array type is still available: `Std.Reflect.Type.TypeDescriptor.of<int32[]>()` describes it without holding a value. See [the reflection design](../design/Reflect030.md#dynamic-values).
