# E0268: invalid Unicode escape

A Unicode escape in a string or character literal is `\u` followed by one to six hexadecimal digits, in either case, between braces: `\u{E9}`, `\u{1F600}`. A `\u` without `{`, empty braces, more than six digits, a character that is not a hexadecimal digit, and a missing `}` are rejected. The error is at the escape.

<!-- example: error: E0268 -->
```neura
let smile = "\u1F600";
```

Put the digits between braces:

<!-- example: check -->
```neura
let smile = "\u{1F600}";
```

See [Core language](../lang/CoreLanguage.md#escapes).
