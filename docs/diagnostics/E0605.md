# E0605: scope-bound value leaves its scope

A `Task<T>` or `Scope` value is scope-bound: it cannot leave the scope that created it, so it cannot be returned, stored in a field or global, captured by a lambda, or passed to another task.

<!-- example: error: E0605 -->
```neura
let concurrent = import:Std.Concurrent.Task;
let work = func() -> int => 2;
let start = func() -> concurrent.Task<int> {
    scope {
        let task = spawn work();
        return task;
    }
};
```

Join the task inside its scope and return the result:

<!-- example: check -->
```neura
let work = func() -> int => 2;
let start = func() -> int {
    scope {
        let task = spawn work();
        return task.join();
    }
};
```

See [Concurrency](../lang/Concurrency.md).
