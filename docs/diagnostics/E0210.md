# E0210: malformed comparison chain

A comparison chain such as `x == 1 or 2 or 3` compares one value with several, joined only by `and` or only by `or`; it cannot continue with another comparison.

<!-- example: error: E0210 -->
```neura
let wrong = func(x: int, y: int) -> bool {
    return x == 0 and y == 1;
};
```

Join separate comparisons with `&&` or `||`:

<!-- example: check -->
```neura
let right = func(x: int, y: int) -> bool {
    return x == 0 && y == 1;
};
```

A chain compares one value with several:

<!-- example: check -->
```neura
let small = func(x: int) -> bool {
    return x == 1 or 2 or 3;
};
```
