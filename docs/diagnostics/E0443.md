# E0443: a closure captures a 'last' binding before it is assigned

A closure copies the locals it captures when it is created, so a closure cannot capture a deferred `last` binding before the binding is assigned on every path to the closure. In `init`, a closure cannot use a deferred `last` field before `init` assigns it, because the closure could run first.

<!-- example: error: E0443 -->
```neura
let make = func() -> int {
    last base: int;
    let read = func() -> int => base;
    base = 1;
    return read();
};
```

Assign the binding before creating the closure:

<!-- example: check -->
```neura
let make = func() -> int {
    last base: int;
    base = 1;
    let read = func() -> int => base;
    return read();
};
```

See [Core language](../lang/CoreLanguage.md#deferred-assignment).
