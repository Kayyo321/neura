# E0496: ? on a value that is not a Result

The postfix `?` takes a `Std.Core.Result<T>`: `Ok(v)` gives `v`, and `Err(e)` returns `Err(e)` from the enclosing function. It does not apply to an `Optional` or to an enum of the program. The message names the operand's type. An `Optional` can be converted with `to_result(error)` first.

<!-- example: error: E0496 -->
```neura
let.promote _ = import:Std.Core.Optional;
let.promote _ = import:Std.Core.Result;
let lookup = func(key: string) -> Optional<int> => Optional<int>.None;
let read = func(key: string) -> Result<int> => Result<int>.Ok(lookup(key)?);
```

Convert the `Optional` to a `Result` with the error to return:

<!-- example: check -->
```neura
let.promote _ = import:Std.Core.Optional;
let.promote _ = import:Std.Core.Result;
let.promote errors = import:Std.Core.Error;
let lookup = func(key: string) -> Optional<int> => Optional<int>.None;
let read = func(key: string) -> Result<int> =>
    Result<int>.Ok(to_result(lookup(key), errors.custom("missing", key))?);
```
