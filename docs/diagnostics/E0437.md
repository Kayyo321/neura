# E0437: destructuring annotation is not a tuple type

The annotation of a destructuring declaration is a tuple type in brackets with one element type for each name.

<!-- example: error: E0437 -->
```neura
let [low, high]: int = 1, 9;
```

Write one type for each name:

<!-- example: check -->
```neura
let [low, high]: [int, int] = 1, 9;
```

See [Types](../lang/Types.md#tuples).
