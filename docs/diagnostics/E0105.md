# E0105: malformed numeric literal

A numeric literal can end in a recognized numeric type suffix, and its exponent, if written, needs at least one digit.

<!-- example: error: E0105 -->
```neura
let width = 10px;
```

Keep units out of literals, and write an exponent with its digits:

<!-- example: check -->
```neura
let width_px = 10;
let large = 1e6;
```

See [Numbers](../lang/Numbers.md).
