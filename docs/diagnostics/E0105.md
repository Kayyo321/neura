# E0105: malformed numeric literal

A numeric literal is digits, an optional fraction, and an optional exponent with at least one digit; a letter cannot follow it directly.

<!-- example: error: E0105 -->
```neura
let width = 10px;
```

Keep units out of literals, and write an exponent with its digits:

<!-- example: check -->
```neura
let width_px = 10;
let large = 1e6;
```

See [Numbers](../lang/Numbers.md).
