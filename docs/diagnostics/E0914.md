# E0914: extension of a sealed type outside its module

A class or interface marked `#Sealed` is extended or implemented only inside the module that declares it, or inside its file when it is declared at the top of a file. The set of its subtypes is then known where it is declared.

<!-- example: error: E0914 -->
```neura
let Shapes = module (
    #Sealed
    export let Shape = interface (
        let area = func() -> int32;
    );
);

let Circle = class implements Shapes.Shape (
    export let.override area = func() -> int32 {
        return 3;
    };
);
```

Declare the subtype in the sealed type's module:

<!-- example: check -->
```neura
let Shapes = module (
    #Sealed
    export let Shape = interface (
        let area = func() -> int32;
    );

    export let Circle = class implements Shape (
        export let.override area = func() -> int32 {
            return 3;
        };
    );
);
```
