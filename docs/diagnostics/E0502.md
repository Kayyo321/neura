# E0502: invalid override

A member that replaces an inherited one is declared with `let.override` (or `const.override`), is exported, and matches the inherited member's kind and signature; `.override` without an inherited member is an error.

<!-- example: error: E0502 -->
```neura
let Shape = class (
    export let area = func() -> int => 0;
);
let Square = class : Shape (
    export let area = func() -> int => 4;
);
```

Declare the replacement with `let.override`:

<!-- example: check -->
```neura
let Shape = class (
    export let area = func() -> int => 0;
);
let Square = class : Shape (
    export let.override area = func() -> int => 4;
);
```

See [Polymorphism](../lang/Polymorphism.md).
