# E0706: invalid NeuraIR artifact

A NeuraIR artifact that a program imports must be a valid, readable `.nir` file whose symbols, bodies, and standard library identities are consistent.

<!-- diagnostic: not reproducible: it needs a damaged or mismatched .nir file -->

Rebuild the artifact with `neura emit-ir` from its sources, with the same standard library as the program:

<!-- example: fragment: imports an artifact built separately -->
```neura
let store = import "store.nir".Store;
```

See [NeuraIR format](../NirFormat.md).
