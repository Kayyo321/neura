# E0230: malformed match.is

A `match.is` is written `match.is (subject) { arms }`, and each arm's pattern is `_`, `nil`, a type, or `name: Type`. A subject without parentheses, an arm that begins with something other than a type, and a variant pattern such as `Light.Red(x)` are errors. The error is at the offending token.

<!-- example: error: E0230 -->
```neura
let Shape = class ( export let sides: int = 0; );
let classify = func(value: Shape) -> int => match.is value {
    _ => 1,
};
```

Write the subject in parentheses. To match the variants of an enum, use `match`:

<!-- example: check -->
```neura
let Shape = class ( export let sides: int = 0; );
let classify = func(value: Shape) -> int => match.is (value) {
    shape: Shape => shape.sides,
    _ => 0,
};
```

See [Types](../lang/Types.md#object-casts).
