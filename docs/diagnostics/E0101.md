# E0101: invalid character

A character that is not part of any token, such as `$`, `@`, or a typographic quote, cannot appear outside a string literal or a comment.

<!-- example: error: E0101 -->
```neura
let total = 1 $ 2;
```

Use an operator of the language, or put the text in a string:

<!-- example: check -->
```neura
let total = 1 + 2;
let label = "$2";
```

See [Core language](../lang/CoreLanguage.md).
