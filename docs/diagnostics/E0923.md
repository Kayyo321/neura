# E0923: #HostEffects on a function that is not a host binding without a body

`#HostEffects` declares what a call of a host binding may do. A host binding has no body, so the compiler has nothing to summarize and takes the answers from the tag. A function with a body is summarized from its body, and a function bound to a kernel from its signature, so neither takes a contract.

<!-- example: error: E0923 -->
```neura
let Effects = module (
    #HostEffects(allocates: false)
    export let double = func(x: int32) -> int32 {
        return x + x;
    };
);
```

Remove the tag. The compiler already knows what the body does:

<!-- example: check -->
```neura
let Effects = module (
    export let double = func(x: int32) -> int32 {
        return x + x;
    };
);
```
