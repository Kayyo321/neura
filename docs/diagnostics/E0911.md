# E0911: use of an internal declaration outside its library

An `#Internal` declaration is usable only inside its library. In the standard library, that is the whole standard library. Elsewhere it is the directory that holds the declaring file, with its subdirectories: the declaring module, its sibling modules, and their children. `#Internal` composes with `export`: an exported internal member is visible to the other modules of the library and hidden from the programs that use it.

<!-- diagnostic: not reproducible: the declaration and the use must be in files in different directories, which one source file cannot express; tests/ui/tags/internal-use exercises it -->

A library file, `acme/core.nra`:

<!-- example: fragment: the library half of a two-file example; acme/core.nra beside the program below -->
```neura
let Core = module (
    #Internal
    export let raw_total = func() -> int32 {
        return 1;
    };

    export let total = func() -> int32 {
        return raw_total();
    };
);
```

A program in the parent directory may use `Core.total` but not `Core.raw_total`:

<!-- example: fragment: the program half of a two-file example; it imports acme/core.nra -->
```neura
let core = import:Acme.Core;
let value: int32 = core.total();
```
