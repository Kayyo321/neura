# E0580: type is not deeply immutable

A `FrozenList<T>` and a `ui.State<T>` hold values that no code can change, so their type argument must be *deeply immutable*: `bool`, a number, `string`, a tuple or enum whose parts are deeply immutable, a class marked `#Immutable` whose fields are too, or a `FrozenList` of such values. A list, an array, a function value, an interface, and a class that is not `#Immutable` are not.

The check follows a generic function: a type parameter passed on to `FrozenList` or `ui.State` must itself be given a deeply immutable type, and the error points at the outermost type argument written.

<!-- example: error: E0580 -->
```neura
let frozen = import:Std.Collections.Frozen;

let Counter = class (
    export let count: int32 = 0;
);

let counters = frozen.empty<Counter>();
```

Mark the class `#Immutable` and declare its fields with `last`, or hold a `FrozenList` instead of a list:

<!-- example: check -->
```neura
let frozen = import:Std.Collections.Frozen;

#Immutable
let Counter = class (
    export last count: int32;

    export let init = func(count: int32) => set;
);

let counters = frozen.of<Counter>(new Counter(1), new Counter(2));
```

See [Collections](../lang/Collections.md#frozenlist) and [Tags](../lang/Tags.md#frozen).
