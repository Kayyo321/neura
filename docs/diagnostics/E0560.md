# E0560: parameter names differ from the overridden method

The parameter names of a method are part of its interface, because a call may name them. An override, or a class method that implements an interface method, keeps the names of the method it replaces, position by position. A call then means the same whatever the static type of its receiver.

<!-- example: error: E0560 -->
```neura
let Shape = class (
    export let scale = func(factor: int) -> int => factor;
);

let Square = class : Shape (
    export let.override scale = func(by: int) -> int => by * 2;
);
```

Use the base name:

<!-- example: check -->
```neura
let Shape = class (
    export let scale = func(factor: int) -> int => factor;
);

let Square = class : Shape (
    export let.override scale = func(factor: int) -> int => factor * 2;
);
```

See [Polymorphism](../lang/Polymorphism.md).
