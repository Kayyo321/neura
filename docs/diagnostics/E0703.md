# E0703: ambiguous import

An import must resolve to one module: a name found in two source roots, or an artifact found twice, is ambiguous.

<!-- diagnostic: not reproducible: it needs two source roots (-I) that both hold the module -->

Remove one of the copies, or rename one of the modules, so that each import names one file:

<!-- example: fragment: imports Shop.Cart from a source root -->
```neura
let shop = import:Shop.Cart;
```

See [Modules and imports](../lang/Modules.md).
