# E0581: frozen storage is exposed or changed

`#Frozen` belongs to the standard library: `Std.Collections.Frozen` and `Std.Ui` use it, and any other module that writes it gets this error. On a class it requires deeply immutable type arguments ([E0580](E0580.md)). On a field it marks *frozen storage*: a `last` list that the constructor assigns once, from a list the constructor created and only filled, and that the class's code afterwards reads only by index and by length. Returning it, passing it to a call, storing it elsewhere, appending to it, or assigning an element is this error, because another holder could then change a list that tasks and states share.

<!-- example: error: E0581 -->
```neura
#Frozen
let Snapshot = class (
);
```

Hold the data in a `FrozenList`, which keeps its own frozen storage:

<!-- example: check -->
```neura
let frozen = import:Std.Collections.Frozen;

#Immutable
let Snapshot = class (
    export last names: frozen.FrozenList<string>;

    export let init = func(values: string[]) {
        names = frozen.copy_of<string>(values);
    };
);
```

The exposure rules are checked in the standard library's own sources; the test `frozen-storage` runs them against fixtures in a copy of the library.

See [Collections](../lang/Collections.md#frozenlist) and [Tags](../lang/Tags.md#frozen).
