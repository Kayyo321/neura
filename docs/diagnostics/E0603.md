# E0603: invalid spawn

`spawn` starts a call, such as `spawn work(item)`, inside a `scope` block of the same function body; its callee begins with a name.

<!-- example: error: E0603 -->
```neura
let work = func(item: int) -> int => item * 2;
let run = func() {
    spawn work(1);
};
```

Spawn inside a scope, which waits for its tasks:

<!-- example: check -->
```neura
let work = func(item: int) -> int => item * 2;
let run = func() {
    scope {
        spawn work(1);
    }
};
```

See [Concurrency](../lang/Concurrency.md).
