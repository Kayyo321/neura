# E0250: malformed binding directive

Write a name and one whole-expression value for an event, property, or custom property directive.

<!-- example: error: E0250 -->
```neura
let view = html() { <button on:click="save()">Save</button> };
```

<!-- example: check -->
```neura
let ui = import:Std.Ui;
let view = html(save: func(ui.ClickEvent) -> void) { <button on:click={save}>Save</button> };
```
