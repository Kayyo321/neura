# E1006: handler does not match the event

An event handler's parameter must have the type of that event's record.

<!-- example: error: E1006 -->
```neura
let ui = import:Std.Ui;
let view = html(receive: func(ui.KeyEvent) -> void) { <button on:click={receive}>Save</button> };
```

<!-- example: check -->
```neura
let ui = import:Std.Ui;
let view = html(receive: func(ui.ClickEvent) -> void) { <button on:click={receive}>Save</button> };
```
