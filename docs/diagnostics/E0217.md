# E0217: malformed startup block

A startup block is the two words `static scope` followed by a block. It names no scope handle, takes no `export` and no tags, and has no `;` after its closing brace. `neura check --fix` removes a `;` after the block and an `export` before it.

<!-- example: error: E0217 -->
```neura
static scope {
    let ready = true;
};
```

Write the block without a `;`:

<!-- example: check -->
```neura
static scope {
    let ready = true;
}
```

See [Modules](../lang/Modules.md#startup-blocks).
