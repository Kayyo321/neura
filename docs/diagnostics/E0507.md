# E0507: inaccessible constructor

Code outside a class constructs it only through an exported constructor.

<!-- example: error: E0507 -->
```neura
let Token = class (
    let init = func() -> void {};
);
let token = new Token();
```

Export the constructor, or construct through an exported function of the class:

<!-- example: check -->
```neura
let Token = class (
    export let init = func() -> void {};
);
let token = new Token();
```

See [Object lifecycle](../lang/ObjectLifecycle.md).
