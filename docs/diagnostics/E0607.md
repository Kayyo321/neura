# E0607: scope block outside a function body

A `scope` block appears inside a function body, not in a top-level statement or an initializer.

<!-- example: error: E0607 -->
```neura
let work = func() -> int => 2;
scope {
    spawn work();
}
```

Put the scope in a function:

<!-- example: check -->
```neura
let work = func() -> int => 2;
let run = func() {
    scope {
        spawn work();
    }
};
```

See [Concurrency](../lang/Concurrency.md).
