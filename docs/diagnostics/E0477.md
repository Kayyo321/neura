# E0477: storage that cannot outlive a suspension

Every binding of a generator whose scope contains a `yield` lives in the generator's state, which outlives the frame that runs it. Storage the frame owns cannot move there: an array, a primitive reference, or a tuple or enum that contains one. Such a binding in scope at a `yield`, a generator parameter of such a type, and a primitive reference to a binding that lives across a `yield` are rejected. An array in a block that ends before the next `yield` stays in the frame and is accepted. A list is the owned alternative.

<!-- example: error: E0477 -->
```neura
let numbers = iterator() -> int {
    let buffer = [1, 2, 3];
    yield buffer[0];
};
```

Use a list:

<!-- example: check -->
```neura
let numbers = iterator() -> int {
    let buffer: int[list] = new([1, 2, 3]);
    yield buffer[0];
};
```
