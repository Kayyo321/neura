# E0921: #Synchronized on a method without a body to guard

`#Synchronized` applies to an instance method with a body. A constructor or destructor runs while no other task can reach the object, a static function has no receiver whose guard it could take, and an interface method, a bodyless requirement, or a function bound to a host service or a kernel has no body to run under the guard.

<!-- example: error: E0921 -->
```neura
let Counter = class (
    let count: int64 = 0;

    #Synchronized
    export let init = func(start: int64) {
        count = start;
    };
);
```

Synchronize the methods that other tasks call, and leave the constructor plain:

<!-- example: check -->
```neura
let Counter = class (
    let count: int64 = 0;

    export let init = func(start: int64) {
        count = start;
    };

    #Synchronized
    export let add = func(amount: int64) -> int64 {
        count = count + amount;
        return count;
    };
);
```
