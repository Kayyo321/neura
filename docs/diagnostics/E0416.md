# E0416: void in a value position

`void` is the result type of a function that returns nothing; it is not the type of a binding, a parameter, an element, a payload, or a type argument.

<!-- example: error: E0416 -->
```neura
let ignore = func(value: void) {};
```

Give the parameter a type that has values, or leave it out:

<!-- example: check -->
```neura
let ignore = func() {};
```

See [Types](../lang/Types.md).
