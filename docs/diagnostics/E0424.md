# E0424: literal out of range

A numeric literal must fit the type it takes: an integer literal the range of its integer type, a float literal the range of its format without becoming zero.

<!-- example: error: E0424 -->
```neura
let small: int8 = 300;
```

Use a type that holds the value:

<!-- example: check -->
```neura
let small: int16 = 300;
```

See [Numbers](../lang/Numbers.md).
