# E1412: proof does not establish its trap claim

A trap claim must discharge every possible outcome. Trap propositions are planned for a later release.

<!-- diagnostic: not reproducible: trap propositions are a Phase 2 feature -->

This release can prove total Boolean equalities.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```

See [the laws design](../design/Laws031.md).
