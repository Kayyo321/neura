# E0536: const field in a fields-only anonymous class

`new` gives the fields of a fields-only anonymous class their values after it allocates the object, and only a class's own field initializers can give a `const` field its value. A field of such a class is declared with `let`.

<!-- example: error: E0536 -->
```neura
let limits: class (export const most: int = 10;) = new;
```

Declare the field with `let`, or declare a named class when the field must be constant:

<!-- example: check -->
```neura
let limits: class (export let most: int = 10;) = new;
let Limits = class (
    export const most: int = 10;
);
let fixed = new Limits();
```

See [Anonymous classes](../lang/Types.md#anonymous-classes).
