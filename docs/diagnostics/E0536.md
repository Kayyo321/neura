# E0536: destructuring declared with last

`last` declares a single name. It cannot introduce a destructuring declaration, so `last [a, b] = ...;` is an error. `last` is a contextual word, and followed by `[` it would index a binding named `last`; an index never holds a `,` or is followed by `:`, so the compiler reports the destructuring instead.

<!-- example: error: E0536 -->
```neura
let bounds = func() -> int {
    last [low, high]: [int, int] = 1, 9;
    return high - low;
};
```

Destructure with `const`, which binds each name once, or give each name its own `last` binding:

<!-- example: check -->
```neura
let bounds = func() -> int {
    const [low, high]: [int, int] = 1, 9;
    last width = high - low;
    return width;
};
```
