# E1003: modifier not valid for this event

Apply each event modifier once where the event supports it.

<!-- example: error: E1003 -->
```neura
let ui = import:Std.Ui;
let view = html(receive: func(ui.InputEvent) -> void) { <input on:input.prevent_default={receive}> };
```

<!-- example: check -->
```neura
let ui = import:Std.Ui;
let view = html(receive: func(ui.InputEvent) -> void) { <input on:input={receive}> };
```
