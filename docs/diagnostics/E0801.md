# E0801: not supported by circuit conversion

IRtoNeuronConversion lowers only the operations it supports, after specialization has made every generic concrete; a NeuraIR operation it cannot lower is reported here.

<!-- diagnostic: not reproducible: checked source never reaches conversion with an unsupported operation; it needs hand-written NeuraIR -->

Build from source with `neura build`, which specializes generics before conversion:

<!-- example: check -->
```neura
let identity = func<T>(value: T) -> T => value;
let three = identity<int32>(3);
```

See [Neuron conversion](../Backend.md).
