# E0432: invalid for loop header

A for loop's initializer is a binding, an assignment, or an expression, and its step is an assignment or an expression.

<!-- example: error: E0432 -->
```neura
let count = func() {
    for (let i: int32 = 0; i < 3; break) {
    }
};
```

Advance the loop in the step, and leave it in the body:

<!-- example: check -->
```neura
let count = func() {
    for (let i: int32 = 0; i < 3; i = i + 1) {
        if (i == 2) {
            break;
        }
    }
};
```
