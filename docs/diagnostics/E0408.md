# E0408: no matching overload

A call of an overload group needs an alternative whose parameters accept the arguments.

<!-- example: error: E0408 -->
```neura
let describe = func(value: int) -> string => "number"
    or func(value: string) -> string => "text";
let kind = describe(true);
```

Pass arguments that one alternative accepts, or add an alternative for them:

<!-- example: check -->
```neura
let describe = func(value: int) -> string => "number"
    or func(value: string) -> string => "text"
    or func(value: bool) -> string => "flag";
let kind = describe(true);
```

See [Core language](../lang/CoreLanguage.md).
