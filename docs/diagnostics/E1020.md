# E1020: malformed project manifest

Use the [project TOML subset](../design/Projects030.md#the-project-manifest) in `neura.toml` and `neura.lock`. Each key or table has one definition. An array of tables can have several elements.

<!-- diagnostic: not reproducible: the project TOML reader runs in its dedicated tests until project commands are wired -->

For example, use a basic double-quoted string for the project name.

<!-- example: fragment: this belongs in a project manifest -->
```toml
[project]
name = "stock"
```
