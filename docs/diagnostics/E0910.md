# E0910: malformed tag

A tag is `#Name`, `#Name(arguments)`, or a group `#[A, B(arguments)]`. Each argument is a literal (a string, a number, `true` or `false`, a qualified name, or a bracketed list of those), optionally written `name: literal`.

<!-- example: error: E0910 -->
```neura
#Since(version: )
let count = func() -> int32 {
    return 1;
};
```

Give each argument a literal value:

<!-- example: check -->
```neura
#Since(version: "0.2.0")
let count = func() -> int32 {
    return 1;
};
```

See [Tags](../lang/Tags.md).
