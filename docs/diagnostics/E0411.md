# E0411: invalid match subject

`match` takes a value of an enum type and has at least one arm.

<!-- example: error: E0411 -->
```neura
let name = func(code: int) -> string {
    return match (code) {
        _ => "other",
    };
};
```

Compare other values with `if`, or match on an enum:

<!-- example: check -->
```neura
let name = func(code: int) -> string {
    if (code == 0) {
        return "zero";
    }
    return "other";
};
```
