# E0590: unsupported JSON codec shape

Choose a record or an enum as the root and follow the field or payload path in the diagnostic. A codec supports finite, acyclic shapes with scalar, record, tuple and enum values. A field of a record may also have type `Optional<U>`, where `U` is supported. For a recursive object graph, define an explicit wire representation using identifiers or write a codec for the graph.

<!-- example: error: E0590 -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<int>;
```

<!-- example: check -->
```neura
let json = import:Std.Encoding.Json;
let User = record (id: int, name: string);
let C = derive json.Codec<User>;
```
