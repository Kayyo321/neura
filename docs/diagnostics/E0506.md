# E0506: invalid base constructor call

A derived class's constructor starts with `super.init(...)`, called directly, once; a base class that needs arguments is initialized by an explicit constructor in each class between it and the one constructed.

<!-- example: error: E0506 -->
```neura
let Base = class ();
let Derived = class : Base (
    export let init = func() -> void {
        super.init();
        super.init();
    };
);
```

Call `super.init` once, first:

<!-- example: check -->
```neura
let Base = class ();
let Derived = class : Base (
    export let init = func() -> void {
        super.init();
    };
);
```

See [Object lifecycle](../lang/ObjectLifecycle.md).
