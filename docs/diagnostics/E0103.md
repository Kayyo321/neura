# E0103: unterminated string literal

A string literal ends with `"` on the line where it starts; a string that reaches the end of its line is unterminated.

<!-- example: error: E0103 -->
```neura
let greeting = "hello;
```

Close the string on the same line. Write a line break inside a string as `\n`:

<!-- example: check -->
```neura
let greeting = "hello";
let lines = "first\nsecond";
```

See [Core language](../lang/CoreLanguage.md).
