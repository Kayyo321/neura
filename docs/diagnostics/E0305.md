# E0305: unknown or inaccessible member

A member access names a member of the value's type that is visible from the code: outside a class or module, only its exported members are.

<!-- example: error: E0305 -->
```neura
let Box = class (
    let secret: int = 1;
    export let size: int = 2;
);
let peek = func(box: Box) -> int {
    return box.secret;
};
```

Export the member if code outside the class should use it, or use an exported member:

<!-- example: check -->
```neura
let Box = class (
    export let secret: int = 1;
    export let size: int = 2;
);
let peek = func(box: Box) -> int {
    return box.secret;
};
```
