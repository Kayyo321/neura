# E1008: value cannot be iterated by a template

Iterate an array or a FrozenList in a template loop.

<!-- example: error: E1008 -->
```neura
let view = html(items: int32[list]) { @for (let item in items; key: item) { <p>{item}</p> } };
```

<!-- example: check -->
```neura
let view = html(items: int32[]) { @for (let item in items; key: item) { <p>{item}</p> } };
```
