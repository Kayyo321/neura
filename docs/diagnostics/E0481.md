# E0481: lambda does not fit its callable context

A lambda that leaves its parameters untyped, `func(a, b) => a + b`, takes its parameter types from the function type it is expected to have: the type of the parameter it is passed to, the result type of the function it is returned from, or the type of the place it is assigned to. It must take as many parameters as that function type, and a result type it writes must be the expected one.

<!-- example: error: E0481 -->
```neura
let apply = func(f: func(int) -> int) -> int => f(1);
let one = apply(func(x, y) => x + y);
```

Take the expected parameters:

<!-- example: check -->
```neura
let apply = func(f: func(int) -> int) -> int => f(1);
let one = apply(func(x) => x + 1);
```
