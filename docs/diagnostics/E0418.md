# E0418: type argument does not satisfy its bound

A type argument satisfies the bounds of its type parameter: `T: Shape` accepts only `Shape` and the types assignable to it.

<!-- example: error: E0418 -->
```neura
let Shape = class (
    export let sides = func() -> int32 => 0;
);
let count = func<T: Shape>(item: T) -> int32 => item.sides();
let use = func() -> int32 => count<int32>(3);
```

Pass a type that satisfies the bound:

<!-- example: check -->
```neura
let Shape = class (
    export let sides = func() -> int32 => 0;
);
let count = func<T: Shape>(item: T) -> int32 => item.sides();
let use = func() -> int32 => count<Shape>(new Shape());
```

See [Polymorphism](../lang/Polymorphism.md).
