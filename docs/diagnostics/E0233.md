# E0233: malformed optional access

`?.` is followed by a member name, and an optional access gives a value, not a place: it is not the target of an assignment and takes no `++` or `--`. The error is at the `?.`.

<!-- example: error: E0233 -->
```neura
let Owner = class ( export let name: string = ""; );
let Pet = class ( export let owner: Owner = nil; );
let update = func(pet: Pet, other: Owner) {
    pet?.owner = other;
};
```

Test the receiver and assign through `.`:

<!-- example: check -->
```neura
let Owner = class ( export let name: string = ""; );
let Pet = class ( export let owner: Owner = nil; );
let update = func(pet: Pet, other: Owner) {
    if (pet != nil) {
        pet.owner = other;
    }
};
```
