# E1415: proof normalization fuel exhausted

The checker gives each law a deterministic normalization budget. The diagnostic reports the budget and the most frequently unfolded symbol when a symbol was unfolded.

<!-- diagnostic: not reproducible: requires a normalization budget chosen on the command line or a proof exceeding the default budget -->

Use a smaller intermediate lemma or rerun `neura prove` with a larger `--proof-fuel` value. This equality fits the default budget.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```

See [the laws design](../design/Laws031.md).
