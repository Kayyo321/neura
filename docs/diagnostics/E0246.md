# E0246: unknown or malformed character reference

Use a known HTML character reference followed by its semicolon.

<!-- example: error: E0246 -->
```neura
let view = html() { <p>Fish & chips</p> };
```

<!-- example: fragment: application form lowering is implemented after template parsing -->
```neura
let view = html() { <p>Fish &amp; chips</p> };
```
