# E0201: expected a semicolon

A statement and a declaration end with `;`, including a declaration whose value ends with a block, such as a function, class, or module.

<!-- example: error: E0201 -->
```neura
let limit = 10
let half = limit / 2;
```

Add the semicolon. `neura check --fix` adds a missing one where the error points:

<!-- example: check -->
```neura
let limit = 10;
let half = limit / 2;
```

See [Core language](../lang/CoreLanguage.md).
