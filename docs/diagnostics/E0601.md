# E0601: function is not task-safe

A spawned call, and the worker of a parallel map, must be task-safe: nothing it can call may use a reassignable module binding, a binding whose type is not transferable, or a native request.

<!-- example: error: E0601 -->
```neura
let counter: int = 0;
let bump = func() {
    counter = counter + 1;
};
let audit = func(entry: int) {
    bump();
};
let run = func() {
    scope {
        spawn audit(3);
    }
};
```

Pass the state the task needs and return what it computes; the parent combines the results:

<!-- example: check -->
```neura
let counter: int = 0;
let audit = func(entry: int) -> int => entry + 1;
let run = func() {
    scope {
        let task = spawn audit(3);
        counter = counter + task.join();
    }
};
```

See [Concurrency](../lang/Concurrency.md).
