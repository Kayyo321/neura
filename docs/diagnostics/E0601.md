# E0601: function is not task-safe

A spawned call and a parallel-map worker must be task-safe. They may use only constant module bindings of transferable types and cannot issue native requests. A parallel-map worker and the functions it calls may read a constant global only if its type supports copying into the worker's separate heap. A `Std.Concurrent` handle does not support copying. A function given to a guard, the initializer of `Guarded.create` or the body of `with`, must be task-safe too, whichever task calls it, so that it cannot keep or reach the guarded state through a global.

<!-- example: error: E0601 -->
```neura
let counter: int = 0;
let bump = func() {
    counter = counter + 1;
};
let audit = func(entry: int) {
    bump();
};
let run = func() {
    scope {
        spawn audit(3);
    }
};
```

Pass the state the task needs and return what it computes; the parent combines the results:

<!-- example: check -->
```neura
let counter: int = 0;
let audit = func(entry: int) -> int => entry + 1;
let run = func() {
    scope {
        let task = spawn audit(3);
        counter = counter + task.join();
    }
};
```

See [Concurrency](../lang/Concurrency.md).
