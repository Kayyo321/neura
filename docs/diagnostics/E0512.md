# E0512: invalid cast declaration

A cast `let.as T = func -> T => ...` is a class instance method with a body and no parameters, returns its target type, which is not a primitive reference, and is declared once per target.

<!-- example: error: E0512 -->
```neura
let Meters = class (
    export let value: int64 = 1;
    export let.as int64 = func -> string => "one";
);
```

Return the target type:

<!-- example: check -->
```neura
let Meters = class (
    export let value: int64 = 1;
    export let.as int64 = func -> int64 => value;
);
```
