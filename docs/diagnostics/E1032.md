# E1032: dependency not pinned or not found

An external dependency needs a directory path or vendored archive and the digest of its content. Supply the local dependency and pin the content you intend to build.

<!-- diagnostic: not reproducible: the manifest model runs in its dedicated tests until project commands are wired -->
<!-- example: fragment: this belongs in a project manifest and the digest must be the dependency's recorded pin -->
```toml
[dependencies.charts]
archive = "vendor/charts.tar.gz"
digest = "<recorded digest>"
```
