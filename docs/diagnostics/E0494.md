# E0494: optional access on a receiver that is never absent

`receiver?.member` skips the member when the receiver is nil, `None` or `Some(nil)`, so the receiver is a class or interface reference or an `Optional` of one. A scalar, a string, an enum other than `Optional`, and a module are never absent: read their members with `.`. On a `Result`, `r?.name` is optional access, not propagation; propagate first with `(r?).name`.

<!-- example: error: E0494 -->
```neura
let size = func(count: int32) => count?.abs();
```

Use `.`:

<!-- example: check -->
```neura
let size = func(count: int32) => count.abs();
```

See [Core language](../lang/CoreLanguage.md#optional-access-and-coalescing).
