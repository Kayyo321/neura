# E0414: invalid indexing

Indexing applies to an array or a list with an integer index, and to a tuple with a nonnegative integer literal within its length.

<!-- example: error: E0414 -->
```neura
let names = ["Ada", "Lin"];
let first = names["0"];
```

Index with an integer:

<!-- example: check -->
```neura
let names = ["Ada", "Lin"];
let first = names[0];
```

See [Collections](../lang/Collections.md).
