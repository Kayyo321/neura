# E0264: malformed return if

`return if (condition) -> value else -> value;` returns the value of the first arm whose condition holds. Each arm is `-> value`, a `;` may end a non-final arm, and the final `else` is required. A missing `->`, a missing final `else`, and an arm written as a block are rejected at the position where `->` or `else` was expected. Block arms that yield a value are specified and wait for the `yield` of the lifetime milestone.

<!-- example: error: E0264 -->
```neura
let pick = func(ready: bool) -> string {
    return if (ready) -> "go";
};
```

End the arms with an `else`:

<!-- example: check -->
```neura
let pick = func(ready: bool) -> string {
    return if (ready) -> "go"; else -> "wait";
};
```
