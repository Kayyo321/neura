# E1010: effect not allowed while rendering

Every expression in an HTML template runs while the view is built, and a render must not change anything that existed before it started. A hole may allocate, read bindings, fields and collections, and call functions that do the same. It may not assign a module binding, write a field or element of an object it did not create, make a host request such as printing, start or wait for tasks, or call a function value, whose effects the compiler cannot see. The error is at the hole, with the chain of calls that leads to the effect.

<!-- example: error: E1010 -->
```neura
let renders = 0;

let count_render = func() -> int {
    renders = renders + 1;
    return renders;
};

let badge = html() { <span>{ count_render() }</span> };
```

Do the work in a handler or before the render, and pass the result to the factory. A handler bound with `on:` is not called while rendering, so its body may have effects.

<!-- example: check -->
```neura
let badge = html(renders: int) { <span>{renders}</span> };
```
