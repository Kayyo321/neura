# E1031: unknown or incompatible provider

A server or desktop target lists the provider components it links in `providers`, and a bundle records in `requires` the version of every host interface and provider it needs. `neura build --target` reports `E1031` for a provider this SDK does not define or does not install, and for a web target whose browser runtime is not installed. `neura run` reports it for a bundle that requires an interface version the host does not have, naming the axis and both versions. Use a provider the SDK installs, or install the target component.
