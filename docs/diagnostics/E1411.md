# E1411: total equality uses an operation that can trap

Both sides of an equality must finish normally. The diagnostic points to an operation whose safety the proof checker cannot establish.

<!-- example: error: E1411 -->
```neura
let Example = module (
    .Pure
    let checked = func(flag: bool) -> bool {
        if (not flag) {
            trap_with_message("invalid flag");
        }
        return true;
    };

    let Total = law (
        for flag: bool;
        claim: { checked(flag) == true : bool };
    );
        | proof: {==};
);
```

Use a function that returns on every admissible path.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        for flag: bool;
        claim: { flag == flag : bool };
    );
        | proof: {==};
);
```
