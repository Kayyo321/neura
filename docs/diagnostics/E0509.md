# E0509: invalid lifecycle function

`init` and `deinit` are the lifecycle functions of a class: each has a body and no type parameters and returns `void`, `deinit` takes no parameters, and they run through `new`, `super.init`, and `destroy` rather than direct calls.

<!-- example: error: E0509 -->
```neura
let File = class (
    export let deinit = func(force: bool) -> void {};
);
```

Declare `deinit` without parameters:

<!-- example: check -->
```neura
let File = class (
    export let deinit = func() -> void {};
);
```

See [Object lifecycle](../lang/ObjectLifecycle.md).
