# E0514: invalid destroy

`destroy` takes a class instance.

<!-- example: error: E0514 -->
```neura
let count = 3;
destroy count;
```

Destroy an object; values of other types need no cleanup:

<!-- example: check -->
```neura
let Counter = class (
    export let value: int = 0;
);
let counter = new Counter();
destroy counter;
```

See [Object lifecycle](../lang/ObjectLifecycle.md).
