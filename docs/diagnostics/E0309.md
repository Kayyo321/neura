# E0309: cyclic declaration

A declaration cannot depend on itself: a binding's inferred type or value cannot need its own declaration to be resolved first.

<!-- example: error: E0309 -->
```neura
let Shop = module (
    export let first = second;
    export let second = first;
);
```

Give one of the bindings a value of its own:

<!-- example: check -->
```neura
let Shop = module (
    export let first = 1;
    export let second = first;
);
```
