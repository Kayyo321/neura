# E0709: C header or library not found

The header and the libraries of a C import must be found, relative to the importing file or in a `--c-include` directory.

<!-- example: error: E0709 -->
```neura
let mathops = import:c("missing-header.h");
```

Name a header that exists, or pass its directory with `--c-include`:

<!-- example: fragment: needs mathops.h beside the source -->
```neura
let mathops = import:c("mathops.h");
```

See [Foreign interop](../lang/ForeignInterop.md).
