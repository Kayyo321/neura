# E0221: malformed generator or yield

A generator is written `iterator(parameters) -> T { body }`: `iterator` followed by an optional type parameter list, a parameter list, and then `->` or `{` begins one, and its element type `T` is required. In its body, `yield value;` is a statement that takes exactly one value. `yield;`, `yield a, b;`, and `yield` inside an expression such as `let x = yield 1;` are rejected. A generator written in an expression takes no type parameters; declare a named generator for that.

<!-- example: error: E0221 -->
```neura
let count = iterator(limit: int) {
    yield limit;
};
```

Declare the element type:

<!-- example: check -->
```neura
let count = iterator(limit: int) -> int {
    yield limit;
};
```

See [Core language](../lang/CoreLanguage.md#generators).
