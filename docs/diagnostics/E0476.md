# E0476: yield with cleanup pending

A generator suspends at each `yield` and may never be resumed, so no exit work may be pending there: a `yield` is not inside a `scope` block, whose tasks would have to be joined across the suspension, and it does not follow a `defer` in a block that encloses it, whose call would run only when that block is left. A `defer` in an inner block that ends before the `yield` is accepted. The error labels the pending `defer` or `scope`.

<!-- example: error: E0476 -->
```neura
let cleanup = func() -> void {};
let numbers = iterator() -> int {
    defer cleanup();
    yield 1;
};
```

End the block before the `yield`:

<!-- example: check -->
```neura
let cleanup = func() -> void {};
let numbers = iterator() -> int {
    {
        defer cleanup();
    }
    yield 1;
};
```
