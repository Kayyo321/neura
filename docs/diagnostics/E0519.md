# E0519: accessor outside a class

Accessor clauses belong to the fields of a class. A module member cannot have them. An interface declares a property requirement with bodyless clauses, `let name: T;` followed by `| get;` ([Polymorphism](../lang/Polymorphism.md#interface-properties)), and a clause with a body in an interface is [E0573](E0573.md).

<!-- example: error: E0519 -->
```neura
let Settings = module (
    export let retries = 3;
        | get: retries;
);
```

Put the field in a class, or use a function in the module:

<!-- example: check -->
```neura
let Settings = module (
    let retries = 3;

    export let retry_limit = func -> int => retries;
);
```

See [Types](../lang/Types.md#accessors).
