# E0519: accessor outside a class

Accessor clauses belong to the fields of a class. A module member and an interface member cannot have them; interfaces cannot require accessors in this release.

<!-- example: error: E0519 -->
```neura
let Settings = module (
    export let retries = 3;
        | get: retries;
);
```

Put the field in a class, or use a function in the module:

<!-- example: check -->
```neura
let Settings = module (
    let retries = 3;

    export let retry_limit = func -> int => retries;
);
```

See [Types](../lang/Types.md#accessors).
