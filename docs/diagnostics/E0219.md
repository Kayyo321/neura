# E0219: malformed defer statement

`defer` followed by a name, `{`, `new` or `spawn` at the start of a statement is the keyword of a deferred call, and it takes exactly one call and a `;`. A block, a construction with `new`, a `spawn`, an optional-chained call `a?.b()`, and any expression that is not a call are rejected. A deferred call's callee, receiver and arguments are evaluated at the statement, and the call runs when the enclosing block is left.

<!-- example: error: E0219 -->
```neura
let cleanup = func() -> void {};
let work = func() -> void {
    defer { cleanup(); }
};
```

Put the statements in a function and defer a call of it:

<!-- example: check -->
```neura
let cleanup = func() -> void {};
let work = func() -> void {
    defer cleanup();
};
```

In every other position `defer` is an ordinary name, so `defer(x);` calls a function named `defer`. See [Core language](../lang/CoreLanguage.md#defer).
