# E0917: #Pure function that is not pure

A function or method marked `#Pure` must have no observable effect: it writes no module or static binding and no field or element of an object it did not allocate during the call, reads no reassignable binding and no binding of a mutable type, makes no host request, uses no scheduler operation or object identity, calls no function value, and calls only functions that are pure for the arguments it passes: a helper that writes only its parameters' objects is fine when the arguments are objects the caller allocated, and a kernel writes the list it receives for a writable view or a state, such as the list `Sorting.sort_ascending` sorts. Every function a call can run counts, including each class's implementation of an interface method and the `to_string`, `hash_code`, or `equals` of the elements of a list whose member is called. It may allocate and it may trap. The error is at the tag, with a label at each call on the way to the first operation that breaks the rule. A generic function is checked in each specialization when the program is built, and the error then has a note naming the specialization.

<!-- example: error: E0917 -->
```neura
let calls: int64 = 0;

let count_call = func() -> void {
    calls = calls + 1;
};

#Pure
let area = func(width: int64, height: int64) -> int64 {
    count_call();
    return width * height;
};
```

Leave the effect to the caller, which is not pure:

<!-- example: check -->
```neura
let calls: int64 = 0;

#Pure
let area = func(width: int64, height: int64) -> int64 {
    return width * height;
};

let measure = func(width: int64, height: int64) -> int64 {
    calls = calls + 1;
    return area(width, height);
};
```

A function of a prebuilt `.nir` module counts as pure only when it is marked `#Pure` itself, because the tag is part of the module's interface. See [Tags](../lang/Tags.md#pure).
