# E0917: #Pure function that is not pure

A function or method marked `#Pure` must have no observable effect: it writes no module or static binding and no field or element of an object it did not allocate during the call, reads no reassignable binding and no binding of a mutable type, makes no host request, uses no scheduler operation or object identity, calls no function value, and calls only pure functions. It may allocate and it may trap. The error is at the tag, with a label at each call on the way to the first operation that breaks the rule.

<!-- example: error: E0917 -->
```neura
let calls: int64 = 0;

let count_call = func() -> void {
    calls = calls + 1;
};

#Pure
let area = func(width: int64, height: int64) -> int64 {
    count_call();
    return width * height;
};
```

Leave the effect to the caller, which is not pure:

<!-- example: check -->
```neura
let calls: int64 = 0;

#Pure
let area = func(width: int64, height: int64) -> int64 {
    return width * height;
};

let measure = func(width: int64, height: int64) -> int64 {
    calls = calls + 1;
    return area(width, height);
};
```

A function of a prebuilt `.nir` module counts as pure only when it is marked `#Pure` itself, because the tag is part of the module's interface. See [Tags](../lang/Tags.md#pure).
