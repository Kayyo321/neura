# E0106: misplaced digit separator

A digit separator must be between two digits of the same integer, fractional, or exponent part of a number.

<!-- example: error: E0106 -->
```neura
let width = 10'u32;
```

Put the separator between two digits, or omit it.

<!-- example: check -->
```neura
let width = 1'000u32;
```
