# E0225: positional argument after a named argument

A call gives its positional arguments first. Once an argument is named, every later argument is named too, because a positional argument after a label would have no clear parameter.

<!-- example: error: E0225 -->
```neura
let area = func(width: int, height: int) -> int => width * height;
let size = area(width: 3, 4);
```

Name the later argument, or move it before the first named one:

<!-- example: check -->
```neura
let area = func(width: int, height: int) -> int => width * height;
let size = area(width: 3, height: 4);
let same = area(3, height: 4);
```
