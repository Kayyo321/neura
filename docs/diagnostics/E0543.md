# E0543: class hook that returns a new object

A hook's result is nil or an object of exactly the class of the reference it handles. A subclass that does not declare its own clause inherits the base's, so a clause that returns `new C(...)` would give every reference of a subclass a `C` and trap. The clause of a class that is not `#Final` cannot return a `new` expression.

<!-- example: error: E0543 -->
```neura
let Session = class (
    | get: new Session();
);
```

Mark the class `#Final`, so no subclass inherits the clause, or return an existing object:

<!-- example: check -->
```neura
#Final
let Session = class (
    | get: new Session();
);
```

See [class hooks](../design/Hooks030.md#class-hook-clauses).
