# E0602: value is not transferable

A value given to another task, as an argument or receiver of a spawned call, on a channel, or to a parallel map, has a transferable type: values, and the handles of `Std.Concurrent`, but not ordinary objects.

<!-- example: error: E0602 -->
```neura
let Tally = class (
    export let count: int = 0;
);
let record = func(tally: Tally) {};
let run = func() {
    let tally = new Tally();
    scope {
        spawn record(tally);
    }
};
```

Pass the values the task needs instead of the object:

<!-- example: check -->
```neura
let Tally = class (
    export let count: int = 0;
);
let record = func(count: int) -> int => count + 1;
let run = func() {
    let tally = new Tally();
    scope {
        let task = spawn record(tally.count);
        tally.count = task.join();
    }
};
```

See [Concurrency](../lang/Concurrency.md).
