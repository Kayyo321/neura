# E0260: character literal that is not one byte

A character literal names one byte: one printable ASCII character or one escape between single quotes. A character outside ASCII, which UTF-8 writes as two or more bytes, and a `\u{...}` escape above `\u{FF}` are rejected. The error is at the literal.

<!-- example: error: E0260 -->
```neura
let euro = '€';
```

Use `Std.Core.Character` for a Unicode code point, a string literal for text, or `\xHH` for a byte that is not a printable character:

<!-- example: check -->
```neura
let euro = "€";
let lead: byte = '\xE2';
let latin: byte = '\u{E9}';
```

See [Core language](../lang/CoreLanguage.md#character-literals).
