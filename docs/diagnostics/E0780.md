# E0780: kernel binding outside the standard library

A `kernel("name", version)` binding connects a standard library function to a built-in runtime kernel; only standard library modules declare one.

<!-- example: error: E0780 -->
```neura
export let Hashes = module (
    export let crc32 = func(bytes: uint8[list]) -> uint32 kernel("neura.digest.crc32", 1);
);
```

Call the standard library function that the kernel backs:

<!-- example: check -->
```neura
let crc32 = import:Std.Digest.Crc32;
```

See [Kernels](../runtime/Kernels.md) and [Standard library design](../lang/Stdlib.md).
