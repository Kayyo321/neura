# E0609: #ThreadSafe class whose instances cannot be shared

A class marked `#ThreadSafe` promises that tasks may share its instances, so it must be `#Immutable` or a monitor: every exported method `#Synchronized`, every exported field `last` or `const` of an immutable type or reached through accessors, every field of a transferable type, and its state reached only through the receiver of its own methods. The label names the member that breaks the rule.

<!-- example: error: E0609 -->
```neura
#ThreadSafe
let Stats = class (
    let hits: int64 = 0;

    #Synchronized
    export let record = func() -> int64 {
        hits = hits + 1;
        return hits;
    };

    export let peek = func() -> int64 => hits;
);
```

Synchronize every exported method, here by marking the class:

<!-- example: check -->
```neura
#[ThreadSafe, Synchronized]
let Stats = class (
    let hits: int64 = 0;

    export let record = func() -> int64 {
        hits = hits + 1;
        return hits;
    };

    export let peek = func() -> int64 => hits;
);
```
