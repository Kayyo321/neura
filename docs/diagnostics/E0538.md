# E0538: duplicate class hook clause

A class has at most one `get` clause and one `set` clause, in either order.

<!-- example: error: E0538 -->
```neura
let Session = class (
    | get: instance;
    | get: instance;
);
```

Keep one clause of each kind:

<!-- example: check -->
```neura
let Session = class (
    | get: instance;
    | set: value;
);
```

See [class hooks](../design/Hooks030.md#class-hook-clauses).
