# E0465: pointer constructed from a value that may be referred to elsewhere

A `SharedPointer<T>` takes ownership of its target. Its owner claims alone decide when the target expires, and no other handle may destroy it, so the target must be a value that nothing else refers to:

- a new object whose constructor does not keep its receiver;
- an array or list literal;
- a local whose only definition is one of these and whose only use is the constructor argument.

The rule checks the target itself, not what its fields refer to.

A new instance of an `#Immutable` class is accepted whatever its constructor does: an alias can neither change it nor destroy it, because the pointer keeps its own handle, so the only effect of an alias is that it is the same object.

<!-- example: error: E0465 -->
```neura
let.promote _ = import:Std.Core.Pointer;
let Node = class (
    export let value: int64 = 0;
);
let share = func(node: Node) -> SharedPointer<Node> {
    return new(node);
};
```

Construct the target where the pointer takes it:

<!-- example: check -->
```neura
let.promote _ = import:Std.Core.Pointer;
let Node = class (
    export let value: int64 = 0;
);
let share = func -> SharedPointer<Node> {
    return new(new Node());
};
```

See [Std.Core.Pointer](../lang/Neura0.3.1.md#25-sharedpointerescapetescape).
