# E1013: stylesheet import or asset cannot be resolved

A `url(...)` or `@import` in a stylesheet, or a static `src` or `poster` of a media element in a template, names a file the build copies into the bundle under its digest. The file must exist inside the source root, and stylesheets must not import each other in a cycle. A remote stylesheet or resource needs its origin listed under `style` in a project manifest; a build without a project lists none.

<!-- example: error: E1013 -->
```neura
const Page = css { body { background: url(./missing.png); } };
```

<!-- example: check -->
```neura
const Page = css { body { background: url(data:image/gif;base64,R0lGODlhAQABAAAAACw=); } };
```
