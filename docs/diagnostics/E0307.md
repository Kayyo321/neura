# E0307: ambiguous promoted name

A name that two promoted imports (`let.promote _ = import:...`) both provide is ambiguous where it is used unqualified.

<!-- example: error: E0307 -->
```neura
let.promote _ = import:Std.Time.*;
let parse_time = parse;
```

Import the module that provides the name you mean, and qualify it:

<!-- example: check -->
```neura
let instants = import:Std.Time.Instant;
let parse_time = instants.parse;
```

See [Modules and imports](../lang/Modules.md).
