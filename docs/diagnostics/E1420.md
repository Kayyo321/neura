# E1420: axiom declared outside the trusted standard library

User modules must prove their laws. The `| axiom;` attachment is restricted to the trusted standard library, and its proof axioms are planned for a later release.

<!-- example: error: E1420 -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | axiom;
);
```

Replace the axiom with a checked proof.

<!-- example: check -->
```neura
let Example = module (
    export let Reflexive = law (
        claim: { true == true : bool };
    );
        | proof: {==};
);
```

See [the laws design](../design/Laws031.md).
