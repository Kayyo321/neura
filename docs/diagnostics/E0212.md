# E0212: braces that do not enclose a range

Braces in an expression enclose a range, as in `{1 .. 4}`; any other expression in braces is an error.

<!-- example: error: E0212 -->
```neura
let numbers = {1, 2};
```

Use brackets for a collection literal, or write a range:

<!-- example: check -->
```neura
let numbers = [1, 2];
let span = {1 .. 4};
```

See [Collections](../lang/Collections.md).
