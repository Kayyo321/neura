# E0578: conformance declared by a module

A primitive conforms to a static contract only through its companion module in the standard library, which declares `module implements I<...>, ... (`. No other module may declare a conformance, and a companion may conform only to a static contract: an interface, with any parents, that has static requirements and nothing else. A class conforms to an interface by listing it after `implements`.

<!-- example: error: E0578 -->
```neura
let.promote _ = import:Std.Core.Arithmetic;
let Numbers = module implements Additive<int> (
    export let zero = func() -> int => 0;
    export let add = func(left: int, right: int) -> int => left + right;
);
```

Declare a class that implements the contract, or use the primitive's own conformance:

<!-- example: check -->
```neura
let.promote _ = import:Std.Core.Arithmetic;
let smaller = func<T: Ordered<T>>(a: T, b: T) -> T => T.compare(a, b) == T.compare(b, a) ? a : b;
let result = smaller<int>(3, 4);
```

See [the standard library](../lang/Stdlib.md#66-arithmetic).
