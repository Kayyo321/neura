# E0783: malformed kernel binding

A kernel binding is written `kernel("name", version)`: a string naming the kernel and a positive integer ABI version.

<!-- example: error: E0783 -->
```neura
export let Hashes = module (
    export let crc32 = func(bytes: uint8[list]) -> uint32 kernel(crc32, 1);
);
```

Kernel bindings belong to the standard library. A program calls the library function instead:

<!-- example: check -->
```neura
let crc32 = import:Std.Digest.Crc32;
```

See [Kernels](../runtime/Kernels.md).
