# E0912: extension of a final class

A class marked `#Final` cannot be the base of another class.

<!-- example: error: E0912 -->
```neura
#Final
let Point = class (
    export let x: int32 = 0;
);

let Point3 = class:Point (
    export let z: int32 = 0;
);
```

Hold the final class in a field instead of extending it:

<!-- example: check -->
```neura
#Final
let Point = class (
    export let x: int32 = 0;
);

let Point3 = class (
    export let flat: Point = new Point();
    export let z: int32 = 0;
);
```

See [Tags](../lang/Tags.md) and [Polymorphism](../lang/Polymorphism.md).
