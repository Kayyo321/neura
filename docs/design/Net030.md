# Neura 0.3.0: networking (`Std.Net`)

This note records the networking library of 0.3.0 as it was built: the contract tree of the owner's specification of `Std.Net` (sections 1.0 to 1.10 of the 0.3.0 standard-library specification), the Neura interfaces that express it, the eleven packages under `Std.Net`, how each item of the specification is provided (in Neura and tested, as Neura logic over a host service, or as a stub), the host services the stubs need, and what changes when the branch is merged with the `runtime-services` branch, which carries the host side. The language rules it relies on are those of [the standard library](../lang/Stdlib.md), [records](Records030.md) and [concurrency](../lang/Concurrency.md). The user-facing summary is [section 11.4 of the standard library](../lang/Stdlib.md#114-stdnet).

Status: *proposed* on 2026-11-17, and *implemented* the same day on the `std-net` branch by autonomous agents, one per package and a lead that wrote the contracts and integrated the packages. The owner was away and had asked for autonomous work toward 0.3.0, so everything here awaits the owner's confirmation, and "proposed" stays until then. A row marked "implemented, proposed" is in the library and still awaits it. The choices the agents made without the owner are listed under [Decisions taken without the owner](#decisions-taken-without-the-owner).

The work adds library modules and tests only. It changes no compiler stage, no NeuraIR or NVR format, no diagnostic code and no host service; the existing `Std.Net.TcpStream` and `Std.Net.TcpListener` keep their declarations and behavior. Every member that needs a host service the runtime of this branch lacks is a stub: its declaration carries a `/// @stub <reason>` line and its body traps with `unsupported: <Module>.<member> is not implemented in Neura 0.3.0 (<reason>)`.

Merged into the release line on 2026-11-18 together with `runtime-services` (through `sql-providers`): the 16 stubs whose host services that branch carries are bound (UDP, Unix-domain sockets, socket options, TLS streams, `send_file` and the system resolver), `Std.Net.Http.AppHandler` compiles against `Std.App` and its tests run as `tests/stdlib/net-http-app`, and loopback tests cover UDP, Unix sockets and the system resolver. The rest of this note describes the branch as built, with those changes folded in; [Merge with runtime-services](#merge-with-runtime-services) lists what was done and what is left.

For the 0.3.1 Core, DNS, Socket and TLS changes, see [the current library reference](../lang/Stdlib.md#114-stdnet) and the [host boundary](../Project.md#runtime-boundary). The following tables preserve the 0.3.0 inventory.

## Contract tree

The specification writes generics as `Foo[T]` and its contracts as traits. They are Neura interfaces with type parameters, declared one per module at the root of `Std.Net`.

let Endpoint = interface<Addr> ( let address = func -> Addr; );
let Listener = interface<Addr, Conn>:Endpoint<Addr>, Closeable ( let accept = func -> Result<Conn>; );
let Connector = interface<Addr, Conn>:Endpoint<Addr> ( let connect = func -> Result<Conn>; );
let Transport = interface<In, Out>:Closeable (
    let receive = func -> Result<Optional<In>>;
    let send = func(data: Out) -> Result<Unit>;
);
let FramedTransport = interface<Frame>:Transport<Frame, Frame> ();
let MultiplexedTransport = interface<StreamId, Frame>:FramedTransport<Frame> (
    let open_stream = func(bidirectional: bool) -> Result<StreamId>;
    let accept_stream = func -> Result<StreamId>;
    let send_on = func(stream: StreamId, frame: Frame) -> Result<Unit>;
    let receive_on = func(stream: StreamId) -> Result<Optional<Frame>>;

);
let Service = interface<Req, Resp> ( let call = func(request: Req) -> Result<Resp>; );
let Filter = interface<Req, Resp, In, Out> (
    let apply = func(request: Req, next: Service<In, Out>) -> Result<Resp>;

## API shape

The packages share these conventions:

- **Value classes.** Addresses, URIs, frames, headers of fixed meaning and configuration objects are `#Final` classes, `#Immutable` where their fields allow, with `equals`, `hash_code` and `to_string`. Mutable state (caches, decoders, connections) is `#NotThreadSafe`. A class holding secret material (a private key, a session ticket) prints a fixed placeholder.
- **Failures.** Malformed input is an `Err`: `Error.Parse` with a byte offset for text formats, `Error.Io` for host failures, and `error.custom(code, message)` with a package code (`http.status.431`, `ws.handshake`, `mesh.proxy_header_invalid`, `resilience.hedging_unsupported`) where a protocol names the failure. A trap is reserved for a programming error, such as a port outside 0 to 65,535 given to a constructor. Most packages have trap programs for such traps (the [Tests](#tests) table counts them); the Http areas have none.
- **Determinism.** Clocks (`Std.Time.Clock`, usually `FixedClock` in tests) and random sources (`Std.Random.Random.seeded(n)` in tests) are injected, so backoff, jitter, cache ages, WebSocket masks, DNS IDs, trace IDs and shadow sampling repeat for the same inputs.
- **Incremental decoders.** Every wire format that arrives in pieces (HTTP heads, chunked bodies, multipart, WebSocket frames, gRPC messages, SSE, PROXY headers, DNS over TCP) has a decoder fed with chunks that gives the same result for every split; for HTTP heads, chunked bodies, multipart and WebSocket frames the tests feed every split point, and the other decoders are tested at chosen splits.
- **Host calls.** A member that needs the host calls a private wrapper; the public API and the logic around the call are real. Where the runtime has the service the wrapper is a `host("<service>", <version>)` binding (16 of them became bindings at the merge, with nothing else changed); elsewhere its body is the stub.

`Std.App` existed only on `runtime-services`, so `stdlib/std/net/http/app-handler.nra` did not type-check on the `std-net` branch. On the release line it compiles against the real `Std.App` and `Std.Net.Internal.HttpServer`, and its tests are the area `tests/stdlib/net-http-app`.

Tensions with the approved design, each for the owner:

1. **`http.json` takes an encode function.** Backend030 passes the codec, `json(status, value, codec)`. The derived `Std.Encoding.Json.Codec<T>` of [the records design](Records030.md#the-json-codec) is not on this branch, so `json<T>(status, value, encode: func(T) -> Result<string>)` takes its `encode` and returns `Result<Response>`. When the codec lands, add an overload or keep passing `Codec.encode`.
2. **One 500 body.** A handler or middleware `Err` is answered by the router with its envelope `{"error":{"code":"internal_error","message":...,"request_id":...}}`, so `Std.App`'s `Context` sees `Ok`. At the merge the adapter was changed so a streamed body that fails while it is collected gets the same envelope and is reported to the router's `on_error` sink (`Router.report_failure`); `Std.App`'s own `{"error":"internal"}` is no longer reached through `AppHandler`. It remains the answer of a plain `Std.App.Handler` that returns an error.
3. **Host required in HTTP/1.0 requests.** Backend030 says "a missing or repeated Host (400)" with no version, so `parse_request_head` rejects an HTTP/1.0 request without Host, which is stricter than RFC 9112 section 3.2.
4. **`IoErrorKind` has no `TooLarge`.** A body over its limit is `Err(Custom "http.body_too_large")`; the runtime's code 16 maps to `Other` until the kind exists.

## Tiers

One row for each item of the specification, sections 1.1 to 1.10. The tiers:

- **Implemented and tested.** Written in Neura and covered by tests that run on this branch.
- **Logic over host services.** Neura code around a host call that the runtime provides today.
- **Stub.** The member traps as unsupported; its API, and any logic around the trapping host call, exist.

A row that is partly one tier and partly another is split. The rows of `Std.Net.Core`'s URI modules, `Std.Net.Resilience` and the contracts rest on the ctest runs of `stdlib-net-uri`, `stdlib-net-resilience` and `stdlib-net-contracts`, since those packages have no package notes; every other row comes from the package agents' notes and was checked against the code where cheap.

## Stubs and runtime needs

The library has 90 `@stub` lines under `stdlib/std/net`, each with exactly one trap (`grep -rn '/// @stub' stdlib/std/net` and `grep -rn 'trap_with_message("unsupported' stdlib/std/net` both count 90; the `std-net` branch had 106, and the merge bound 16). A private host wrapper carries the stub line itself; the public member that reaches it is named in the trap test.

Defaults for every host service below, unless the row says otherwise: version 1; errors are the `uint32` codes of [section 4.5 of the standard library](../lang/Stdlib.md#45-host-services), mapped to `IoErrorKind` by `Std.Core.Internal.HostError` (12 `TimedOut`, 13 `Unsupported`, 14 `CapabilityDenied`, 15 `Cancelled`); capability group network (`--allow-net`); not overlapping and not cancellable, as the `runtime-services` socket services are, with an overlapping and cancellable version 2 of each waiting call to follow; recorded per call and replayed without the host; host IDs are opaque `int64` values. "Binding exists on runtime-services" means that `Std.Net.Internal.Sockets` on that branch binds the service with the same signature and outcome shape, so the merge replaces the wrapper's body and nothing else. "Library work" means no host service is needed.

## Edge cases

1. `Ipv6Addr` equality, hash and order include the zone; a `::ffff:a.b.c.d` address stays IPv6 and is not equal to the IPv4 address, does not match an IPv4 `CidrBlock`, and prints in the mapped form.
2. `SocketAddr.parse` requires brackets around IPv6 (`[fe80::1%eth0]:80`) and rejects leading zeros in the port.
3. `CidrBlock.parse` rejects set host bits and zones; `parse_lenient` clears and drops them; the constructor traps.
4. An `IoSlice` does not snapshot its list: shrinking the list under a view makes a later read trap.
5. A DNS compression pointer must point strictly before the label run it ends, which rejects forward pointers and every loop; a CNAME chain of more than 8 links fails.
6. An HTTP head with a bare CR is 400; a bare LF ends a line unless `Limits.allow_bare_lf` is false; chunk lines, trailers and multipart heads always need CRLF.
7. `Transfer-Encoding: gzip, chunked` in a request is 501; TE with Content-Length is 400 in requests and responses.
8. `GET /parts/new` with only `GET /parts/{id}` and `POST /parts/new` registered reaches the GET parameter route, not 405.
9. A WebSocket frame with a non-minimal length or the top bit of a 64-bit length set fails with 1002; the end of the stream without a close frame fails with 1006; close codes outside RFC 6455 section 7.4 (including 1012 to 1014) are rejected.
10. A `grpc-encoding` other than identity is answered UNIMPLEMENTED rather than reaching the DEFLATE stub, so no client input traps.
11. A `traceparent` of a later version is parsed by the forward-compatibility rules and always written as version 00; an invalid one restarts the trace and drops `tracestate`.
12. A PROXY v2 header with a bad CRC32C, an unterminated Unix path or a short length closes the connection with `mesh.proxy_header_invalid`; the decoder never reads past the header.
13. CUBIC's window arithmetic is integral: K is floored to whole milliseconds, the cubic term rounds toward zero, and windows are capped at 10^9 bytes.
14. Cache arithmetic saturates at ±2^31 seconds, so a year-9999 `Expires` or a 30-digit `Age` cannot trap.

## Decisions taken without the owner

Contracts (lead):

1. **`Listener<Addr, Conn>` and `Connector<Addr, Conn>`** instead of the specification's `Listener[Conn]` and `Connector[Conn]`: both are endpoints, and `Endpoint<Addr>` needs the address type, which a Neura interface cannot leave open.
2. **A filter is not a service.** `Filter` is its own interface, as in Finagle; `Filter.bind(filter, service)` turns a filter and a service into a service, and `compose` and `FilterChain` combine filters.
3. **`Transport.receive` returns `Result<Optional<In>>`**: `None` is the end of the stream, distinct from an error. `send` sends a whole unit or fails.
4. **"Zero-copy" and "zero-allocation" are not provided by this runtime.** Classes are heap objects under a tracing collector, not reference-counted values; an `IoSlice` is a view over one backing list, which is as close as the runtime comes. The doc comments say so.
5. **SHA-1 is implemented inside the WebSocket package** (`Std.Net.Realtime.Ws.Internal.Sha1`, exposed as `Handshake.sha1`) because `Std.Digest` has none; it serves only the opening handshake.
6. **The dependency order** of [section 4.3 of the standard library](../lang/Stdlib.md#43-dependency-order) is extended: `Std.Net.Http` imports `Std.Log` (for `request_log`) and `Std.Net.Http.AppHandler` imports `Std.App`, both below `Std.Net` in that order; no cycle forms because `Std.Log` imports no `Std.Net` module and `Std.App` only the internal `Std.Net.Internal.HttpServer`.
7. **Host wrappers.** A host-dependent member keeps its full API and logic and calls a private wrapper whose body is the stub, so the merge changes one body per service.

Core:

8. Address types are `#Final` and `#Immutable` classes. `Ipv4Addr.parse` is strict (no leading zeros, no `inet_aton` shorthands). IPv6 documentation addresses are `2001:db8::/32` only. `UnixAddr` rejects empty names (no autobind) and NUL in paths. `PrefixTrie.remove` does not prune nodes. `ByteRing`, `IoSlice` and `PrefixTrie` are not synchronized.
9. `write_gather`'s writer must take 1 to the offered number of bytes; anything else is an `Io` error of kind `Other`.
10. `Idna.to_ascii` requires input already mapped by UTS 46 (lowercase, NFC) and rejects the scalars it can identify as unmapped; `map_uts46` is a stub because the mapping table and NFC data are not in the library.

Socket, TLS, QUIC:

11. Socket options are given at creation (`connect_with`, `bind_with`), because `SO_REUSEADDR`, `SO_REUSEPORT` and `TCP_FASTOPEN` must precede bind. Keepalive limits are those of Linux `tcp(7)`.
12. `StreamSocket.peer_address` is `Optional` (the host's accept reports no address), and `Datagram.sender` is `Optional` (unnamed Unix senders).
13. `TcpSocket.send_file` takes a path and opens it through its own binding of `neura.fs.open`, since `Std.Fs.File` keeps its host ID private.
14. A client certificate or a TLS version range other than 1.2 to 1.3 needs version 2 of the TLS services, because version 1 takes neither. SNI accepts ASCII LDH labels only and rejects IP literals (RFC 6066).
15. SPIFFE IDs: the scheme is matched case-insensitively, an uppercase trust domain is rejected, IDs over 2,048 bytes are rejected.
16. CUBIC and LEDBAT use integer arithmetic with the caps listed under edge cases; the replay filter hashes with SHA-256 double hashing over two generations.
17. The event-loop availability table (io_uring from Linux 5.1, epoll on Linux, kqueue on macOS and the BSDs, poll except on Windows) is from general knowledge, not a fetched source.

DNS:

18. `DnsTransport` is message-level (`exchange(Message) -> Result<Message>`). Hosts are consulted before the cache and the network, for A and AAAA only. Negative answers are cached per RFC 2308 and only with an SOA; positive TTLs are clamped to one day by default. The EDNS payload offered is 1,232 bytes.
19. Search-list results follow glibc: the first answer with records wins, else the first NODATA, else the last NXDOMAIN. A truncated answer without a stream fallback is the error `dns.truncated`.
20. DoH and DoQ send ID 0 and restore the caller's ID on the response; DoT sets no ALPN; NAPTR REGEXP fields are returned but not evaluated.

HTTP:

21. Method matching is per method before literal preference; `Allow` lists GET, HEAD, POST, PUT, PATCH, DELETE, then others; router-level middleware also wraps 404 and 405 answers.
22. Registration never traps: invalid patterns and duplicates are reported by `check()` and never match.
23. Path parameters match raw segments and are decoded for the handler; a trailing slash is an empty segment and never matches a parameter. The "radix tree" is a trie of whole segments.
24. `same_origin` decides by `Sec-Fetch-Site` when present, else by `Origin` against scheme and Host; `cors` refuses a preflight from an unadmitted origin with 403; `CorsPolicy` traps on `*` and `null`.
25. The pool has no waiting queue: an origin at its limit fails at once; reset, timeout and 502, 503, 504 are retried only for idempotent requests or with `Idempotency-Key`; 429 only with `Retry-After`.
26. RFC 9111: whole-second arithmetic saturating at ±2^31; an invalid `Expires` means expired; only GET and HEAD are stored; `Lookup.Fresh` includes stale responses allowed by `max-stale`; LRU eviction.
27. HPACK and QPACK stay stubs, skipped for the release deadline although everything they depend on was finished.
28. `Std.Net.Core.Uri` is not used by `Std.Net.Http` yet: `path` and `query` are strings.

RPC:

29. `Status.to_http` follows `google/rpc/code.proto`; a malformed `grpc-timeout` is answered INTERNAL; the default maximum message size is 4 MiB.
30. Bidirectional streaming is half-duplex in memory; full duplex needs stream-level host services.
31. `MappedJsonCodec<T>` stands in for the derived `Json.Codec<T>`, which is not on this branch.
32. The Health `Watch` RPC and the reflection `ServerReflectionInfo` RPC are not registered (they need live streams and descriptors).

Realtime:

33. `WebSocket` negotiates no extensions; a read timeout is returned with the connection left open; `close` waits for the peer's close frame.
34. Heartbeat: any frame counts as activity, one ping per interval, and a dead peer is final.
35. WebTransport codepoints are those of draft-ietf-webtrans-http3-14, which may change.
36. SSE: `retry` saturates at 10^12 ms, the default reconnection time is 3,000 ms, and backoff and an attempt limit are opt-in.

Resilience:

37. Every limiter, breaker and balancer reads an injected clock; hedging needs a `SpawnableService` as the next service (any other is `resilience.hedging_unsupported`), so the hedging filter is last in a chain.
38. The distributed GCRA hook is the `RateStore` interface with an atomic compare-and-set; only the in-memory store is provided.

Mesh:

39. A malformed `tracestate` or `baggage` drops that header whole; a restarted trace sets the random-trace-ID flag; `inject` always writes all three headers so stale ones are removed.
40. `ShadowFilter` samples in basis points with one draw per request and comes in two forms, because a filter cannot start a task that outlives its call.
41. The eBPF validation limits (names of 1 to 15 bytes, at most 1,000,000 instructions, key sizes) are not from a fetched source; the runtime work should check them against `bpf(2)`.

## Open risks

- **Untested host paths.** TLS streams have no round-trip test in the library (see the merge list), and `UdpDnsTransport`, `DotTransport`, `TcpDnsTransport.exchange` and `TcpSocket.send_file` have not run against a real peer. TLS works only in builds configured with `NEURA_ENABLE_SERVER_TLS`, which the release archives are not.
- **QUIC names.** Three spellings of the QUIC services were proposed by different packages (above); one must be chosen with the runtime work.
- **Speed.** The language has no bulk list copy, so codecs copy byte by byte: a 70,000-byte WebSocket message costs about 2.5 million steps and a 1 MiB chunked or multipart body several passes. Correct, but slow for bulk data.
- **Strict parsing.** Alt-Svc errors reject the whole header, the HTTP date parser checks the weekday, and WebSocket close codes 1012 to 1014 are refused; real peers are sometimes sloppier.
- **Shared mutable state.** `Cache` lookups return the stored response (callers must copy before changing it), `RequestHead.headers` is a shared map, and an `IoSlice` sees changes to its list.
- **API to settle before 0.3.0 freezes it.** `Cache.refusal` returns strings, `CacheControl.mark_malformed` and `append_directive` are exported only for the parser, and `Std.Net.Socket.Internal.HostCalls` duplicates the runtime-services binding module.
- **No interoperability tests** against a real gRPC peer, a real QUIC stack or a real DNS server.

## Compiler issue found

An overloaded `init` (`export let init = func(...) or func(...)`) in a generic class fails NeuraIR verification with `E0899` ("invalid overload group reference"). `HttpRequest<Body>` and `HttpResponse<Body>` therefore have one constructor each, and the other generic classes of `Std.Net` were written with one. The issue belongs to the compiler lane: it needs a reduced reproducer and a fix in NeuraIR lowering of overload groups for specialized classes.
