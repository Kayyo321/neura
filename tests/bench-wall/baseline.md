# Neura 0.3.1 performance baseline

Measured merge base `d287b7dd617a028c1da88ebc9bd4b8dadbe6adb8` with Clang 19.1.7 in a Linux x86-64 Release build.
The reference CPU is AMD Ryzen 7 9800X3D 8-Core Processor with the performance governor and affinity on cores 4–7.
Kernel 7.1.13+deb13-amd64. Each program uses its declared full input size.

- Neura 0.3.0-dev. JDK 21 21.0.13.1 and JDK 25 25.0.5.1.
- .NET 10 SDK 10.0.404 with workstation, nonconcurrent GC. Each JDK has one default-GC and one Serial GC column.
- Three measured samples per workload and configuration. The warmed track uses three full invocations before sampling in each fresh process.
- Cells show median wall / process CPU milliseconds. The adjacent range covers the observed Neura wall times.
- Cold instruction counts come from separate `perf stat -e instructions:u` runs in millions of user-mode instructions. Warmed measurement uses an in-process timer.
- Every managed output matched Neura byte for byte. The untimed text cases also verified leading and trailing empty fields, no separator, and a multibyte separator.
- Individual times, managed spreads, build times, diagnostics, counters, and memory samples are in the local `build/m2/g0-*` reports.
